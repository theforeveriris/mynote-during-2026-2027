# 数据通信与网络基础课程笔记

## 1.数据通信概念

*   **通信定义**：是指人与人、人与物、物与物之间通过某种媒介和行为进行的信息传递与交流。
*   **通信目的**：通信的目的就是传递**信息**。
*   **相关术语**：
    *   **信息**与**消息**：信息通过消息表现出来。
    *   **信息**与**数据**：数据是信息的内涵表现形式。
    *   **数据**与**信号**：信号是数据的传输载体。信号分为**模拟信号**与**数字信号**。
    *   图示关系：信息（表现形式）-> 数据（传输载体）-> 信号（分为模拟信号、数字信号）；信息（内涵）-> 数据；信息 -> 消息。

## 2.通信系统的模型

*   **通信系统定义**：实现信息传递所需的一切技术设备和传输介质的总和称为通信系统。
*   **模拟通信系统模型**：
    *   模拟信源 -> 调制器 -> 信道 -> 解调器 -> 信宿。
    *   噪声源作用于信道。
*   **数字通信系统模型**：
    *   信源 -> 信源编码 -> 加密 -> 信道编码 -> 调制 -> 信道 -> 解调 -> 信道译码 -> 解密 -> 信源译码 -> 信宿。
    *   噪声源作用于信道。
    *   同步模块作用于解调与信道译码之间。
    *   （图示标注）完成信息传输的通道。

## 3.通信系统的分类

*   **按传输介质分类**：有线通信系统、无线通信系统。
*   **按信号特征分类**：模拟信号、数字信号。
*   **按工作波段分类**：长波通信系统、中波通信系统、短波通信系统、远红外线通信系统。
*   **按传送方式分类**：基带传输系统、带通（频带或调制）传输系统。
*   **按信号复用方式分类**：频分复用、时分复用、码分复用。

## 4.按传输介质分类

*   有线传输介质主要有：**同轴电缆**、**双绞线**和**光纤**。
*   无线传输介质分为：**微波**（300MHz~300GHz）、**红外线**、**激光**。
*   **同轴电缆结构**：绝缘保护套层、外导体屏蔽层、绝缘层、内导体。
*   **双绞线结构**：
    *   无屏蔽双绞线 UTP：聚氯乙烯套层、绝缘层、铜线。
    *   屏蔽双绞线 STP：聚氯乙烯套层、屏蔽层、绝缘层、铜线。

## 5.双绞线的线序

*   **RJ45连插头与双绞线端接有T568A或T568B两种结构**。
    *   **T568A**：白绿、绿、白橙、蓝、白蓝、橙、白棕、棕。
    *   **T568B**：白橙、橙、白绿、蓝、白蓝、绿、白棕、棕。
*   **百兆网络管脚用途**：
    *   1：发送 +，颜色：白色和绿色。
    *   2：发送 -，颜色：绿色。
    *   3：接收 +，颜色：白色和橘黄色。
    *   4：不被使用，颜色：蓝色。
    *   5：不被使用，颜色：白色和蓝色。
    *   6：接收 -，颜色：橘黄色。
    *   7：不被使用，颜色：白色和棕色。
    *   8：不被使用，颜色：棕色。
*   **双绞线结构图标注**：无氧铜、抗拉绳、品质绝缘体、PVC护套。

## 7.光纤概述

*   **原理**：利用光的**全反射**原理传输光信号。
*   **特点**：重量轻、体积小、传输远（衰减小）、容量大、抗电磁干扰。
*   **光纤结构**：纤芯、包层、保护套。
*   **光缆**：一般由多芯光纤和塑料保护套管以及塑料外皮组成。

## 8.光纤分类

*   **单模光纤**：
    *   发射源：**激光LD**。
    *   纤芯直径：小，光信号接近**直线传播**。
    *   特点：传播距离长，可达几km甚至几十km，适合远程通讯。
    *   手写批注：8.3μm，1310nm。
*   **多模光纤**：
    *   发射源：**LED**。
    *   纤芯直径：大，适合多种模式的光信号，全反射传播。
    *   特点：最大距离为550m。
    *   手写批注：62.5，8（对应纤芯直径规格）。
    *   标注：渐变型的啊。

## 11.按信号复用方式分类

*   **频分复用（FDM）**：按频率来划分信道的复用方式。
*   **时分复用（TDM）**：以信道的传输时间作为分割对象（划分时间片）来实现的复用，并且可以根据时间片是否固定分配，分为同步时分复用技术和统计时分复用技术。
*   **码分复用（CDM）**：利用不同的码序列来区分不同的用户信号的复用技术。
*   **多路复用技术**：
    *   是把多个低速信道组合成一个高速信道的技术，可以有效的提高数据链路的利用率。
    *   图示：复用 -> 共享信道 -> 分用。

*   **E1/T1载波**：

## 14.通信方式

*   **按消息的方向与时间分类**：
    *   **a) 单工**：发送端 -> 信道 -> 接收端。
    *   **b) 半双工**：发送端与接收端均连接至信道，信道双向，但同一时刻只能单向传输。
    *   **c) 全双工**：发送端与接收端通过两条信道（或信道容量划分）同时进行双向传输。
*   **其他类别**：
    *   按同步方式分：**异步传输**、**同步传输**。
    *   按数字信号排序分类：并行传输、串行传输。

## 15.交换方式

*   **数据交换技术有3种**：电路交换、报文交换和分组交换。
*   **对比表**：
    | 对比 | 电路交换 | 分组交换-虚电路 | 分组交换-数据报 |
    | :--- | :--- | :--- | :--- |
    | 消息传递单位 | 时隙 | 分组 | 分组 |
    | 工作方式 | 面向连接（物理） | 面向连接（逻辑） | 无连接 |
    | 典型网络代表 | PSTN、ISDN | X.25、ATM、帧中继 | 因特网 |
    | 特点 | 实时交换，线路利用率不高，适合按时间收费 | 适合交互式通信 | 不可靠，高效 |
    *   标注：分组交换中的虚电路是要建立连接的。
    *   手写批注：报文交换。
