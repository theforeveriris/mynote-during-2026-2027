## 1.选择题

### 1.1 第1题（单选题）

**题目**：对一个非实时操作系统而言，采用（）的进程调动方式,可以兼顾效率和公平。


- A. 优先级调度
- B. 最短作业优先
- C. 时间片轮转
- D. 先来先服务

**答案**：C

**解析**：时间片轮转让每个就绪进程轮流获得一个时间片，响应快且各进程机会均等，因此在非实时系统中兼顾效率与公平。优先级调度易使低优先级进程饥饿，最短作业优先需预知运行时间且长作业易饿死，先来先服务对短作业不利、平均周转时间长。

**考点**：进程调度算法；时间片轮转

### 1.2 第2题（单选题）

**题目**：路由协议的主要作用是（ ）。


- A. 实现物理地址和IP地址的互相转换
- B. 交换网络拓扑信息，确定数据传输的最佳路径
- C. 保障数据的高可靠传输
- D. 将多个可网管的二层交换机连接，组成一个局域网

**答案**：B

**解析**：路由协议让路由器之间交换拓扑或可达性信息，运行选路算法生成无环的最佳路径并写入路由表，这正是"选路"的本质。A 是 ARP 的地址解析，C 是 TCP 等传输层机制，D 是二层交换机组网（STP/堆叠）的职责。

**考点**：路由协议作用；路由表生成

### 1.3 第3题（单选题）

**题目**：某公司的WEB服务器经常被攻击者利用未修复的Struts2漏洞发起远程攻击，可以部署（ ）设备有效阻断该类攻击。


- A. WEB防火墙
- B. 防火墙
- C. 漏洞扫描系统
- D. 入侵防御系统

**答案**：A

**解析**：WAF 工作在应用层，能对 HTTP 请求做报文级特征与语义检测，在业务系统尚未打补丁时以"虚拟补丁"方式阻断 Struts2 这类 Web 漏洞利用。普通防火墙只按五元组过滤，漏洞扫描系统只发现不阻断，IPS 偏通用攻击特征、对具体 Web 业务漏洞的识别与虚拟补丁能力不如 WAF 精准。

**考点**：WAF；Web 应用防护

### 1.4 第4题（单选题）

**题目**：物联卡是为智能终端设备提供联网等功能的一种SIM卡，在共享单车、移动支付等领域有广泛的应用。下面对物联卡的描述中正确的是（）。


- A. 物联卡为智能终端设备提供定位、联网等功能
- B. 物联卡仅可以进行单向通信
- C. 任何个人、企业用户均可不受限制的购买、使用物联卡
- D. 物联卡可以作为手机SIM卡进行语音通话

**答案**：A

**解析**：物联卡面向物联网终端，提供联网以及（部分卡具备的）定位等通信服务，通常配定向、低速流量套餐。物联卡支持双向通信（B 错）；按规定须实名登记、不得随意向个人销售（C 错）；物联卡一般关闭语音功能，不能当手机 SIM 卡打电话（D 错）。

**考点**：物联网；物联卡特性

### 1.5 第5题（单选题）

**题目**：网络工程师在交换机上配置如下命令: interface GigabitEthernet0/0/5 port link-type accessport default vlan 100port-security enableport-securitymax mac-num 关于上述配置，下列说法中正确的是 （ ）


- A. 该端口类型配置为access，表示仅可以接入交换机或路由器
- B. 该端口启用端口安全，并配置学习到的MAC地址最大保存时间为1小时
- C. 该端口收到无vlan标签的数据帧会打上vlan 100标签在交换机内部转发和处理
- D. 该端口收到带有vlan 100标签的数据中会剥离vlan Tag在交换机内部转发和处理

**答案**：C

**解析**：access 口只属于一个 VLAN，收到无标签帧时按 port default vlan 100 打上 VLAN 100 的 Tag 再在交换机内部转发，故 C 对。access 口用于接终端而非只接交换机/路由器（A 错）；max mac-num 限制的是可学习的 MAC 地址数量，不是老化时间（B 错）；access 口是"入打标、出剥标"，D 把方向说反了。

**考点**：Access 端口；VLAN 标签处理

- A. 按照网络安全事件应急预案采取补救措施，并查明原因，再视情况决定是否上报
- B. 制定网络安全事件应急预案，并定期组织应急演练，发生网络安全事件时，应立即启动预案，按照预案进行处置并按规定上报

- D. 按照网络安全事件应急预案采取补救措施，并在行业内部进行安全风险预警

### 1.7 第7题（单选题）

**题目**：SDN的灵活性可以帮助实现（ ）。


- A. 彻底消除网络延迟
- B. 限制用户的网络访问
- C. 减少基础设施投资
- D. 快速配置和动态调整网络资源

**答案**：D

**考点**：SDN；控制转发分离

- C. 发现邻居并维护邻居关系

### 1.12 第12题（单选题）

- A. 降低数据传输的复杂性
- B. 提高信号的带宽利用率
- C. 增强数据的压缩效率

### 1.15 第15题（单选题）

**题目**：网络工程师在交换机上配置如下命令: interface Vlanif10 ip address 172.16.10.1 255.255.255.0 关于上述配置，下列说法正确的是（ ）。


- A. 配置该交换机所有access接口默认为vlan10
- B. 创建逻辑接口并配置IP地址
- C. 配置该交换机下所有接入终端的默认网关

### 1.18 第18题（单选题）

**题目**：IPv6报文首部中的NEXT HEADER字段作用是（ ）。


- A. 描述服务类型
- B. 描述扩展首部类型
- C. 描述Payload协议类型
- D. 描述报文首部的下一个字段

**答案**：D

**考点**：IPv6 首部；Next Header

### 1.19 第19题（单选题）

**题目**：在交换机上将两条物理链路配置为一个链路聚合组,流量在这两条物理链路上如何实现负载均衡?（ ） 。


- A. 配置负载均衡策略，根据策略将流量发送到不同的物理链路
- B. 配置链路优先级，流量优先发送到优先级别高的物理链路
- C. 配置MSTP 协议，设置一套链路为主，另外一条为备，实现链路冗余

**答案**：A

**考点**：链路聚合；负载分担

**题目**：在TCP三次握手中，客户端发送的第一个SYN报文中的序列号字段是（ ）。

### 1.23 第23题（单选题）

**题目**：某办公终端无法访问互联网网页，经检查，该终端通过DHCP获取IP地址，获取的IP地址为 169.254.58.22，子网掩码为255.255.0.0，办公室其他终端均可正常访问互联网，导致此故障的原因可能是（ ）。


- A. 与 DHCP服务器通信异常，无法获取到IP地址
- B. 子网掩码配置错误，应该配置为255.255.255.0
- C. 互联网出口网关设备配置访问控制策略，阻断该终端访问互联网网页
- D. 互联网出口网关设备故障

**答案**：A

**解析**：169.254.0.0/16 是链路本地地址（APIPA），终端在 DHCP 请求超时未获响应时会自动启用，掩码固定 255.255.0.0，说明故障出在 DHCP 交互环节。该掩码是自动生成的而非配错（B 错）；若是网关 ACL 或网关故障，终端应已拿到正常地址且往往影响其他终端（C、D 错）。

**考点**：DHCP 故障；169.254 链路本地地址

**题目**：某TCP连接初始阈值为16KB、采用慢启动（slow start）阶段每RTT窗口翻倍，经过3个 RTT后，拥塞窗口大小为（）


- A. 32KB
- B. 128KB
- C. 16KB
- D. 64KB

**答案**：B [答案存疑] 原站答案 C，按原理应为 B，理由：慢启动每经过一个 RTT 拥塞窗口翻倍，16KB→32KB→64KB→128KB，3 个 RTT 后为 128KB；选 C 等于窗口始终未增长，与慢启动机制矛盾。

**解析**：慢启动阶段每收到一个 ACK 窗口增加 1 个 MSS，效果是每个 RTT 窗口翻倍，按题意逐轮计算：第 1 个 RTT 后 32KB，第 2 个 64KB，第 3 个 128KB。选 16KB 意味着窗口三个 RTT 都没有增长，等价于把慢启动当成了拥塞避免之外的静止状态，与机制矛盾。

**考点**：TCP 慢启动；拥塞窗口

### 2.2 高频易错点

1. **VLAN 标签方向记反**：access 口是"入打标、出剥标"；trunk 口收到无 Tag 帧按 PVID 打标转发，不是丢弃。
2. **子网划分两个反向坑**：由主机数求最长掩码（10000 台 → /18，不是 /19）；由地址求网络号（按块大小对齐，215/27 → .192）。
3. **慢启动不是每 RTT 加 1 MSS**：窗口每 RTT 翻倍，3 个 RTT 后是初始值的 8 倍（16KB → 128KB）。
4. **iptables 顺序匹配**：无条件的 `-j DROP` 放在前面会让后面所有 ACCEPT 失效；`-P` 默认策略只作用于未匹配任何规则的流量。
5. **STP 30 秒收敛**：解法是边缘端口（portfast），改端口优先级、改 trunk、禁用 STP 都不解决或带来风险。
6. **OSPF 报文分工**：Hello 只负责发现与维护邻居；链路状态同步靠 DD/LSR/LSU；华为把接口加入区域用接口下 `ospf enable`，不是在区域视图写 `network`。
7. **VRRP 抢占看参数**：`preempt-mode` 与 delay 决定是否/何时抢占，150 是优先级不是秒数。
8. **RAID 选型要三方权衡**：RAID 10 = 50% 利用率 + 高读写性能；RAID 5 利用率更高但写惩罚重、重建风险大。
9. **DNS 正查与反查**："能查过去不能查回来"就是 PTR 记录缺失，不是 A 记录问题。
10. **169.254.x.x 不是配错掩码**：这是 DHCP 失败后自动生成的链路本地地址，掩码必然是 255.255.0.0。
11. **BGP 聚合要带 as-set**：只有保留明细路由的 AS 集合才能用于环路检测；选路顺序中 AS_PATH 排在 Local Preference 之后、Origin/MED 之前。
12. **SNMP 两处易错**：SNMPv3 靠 USM 实现认证加密（不是 TLS）；GetBulk 是 v2c 新增的高效批取操作。
