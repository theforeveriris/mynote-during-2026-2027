## 1.选择题

### 1.1 第1题（单选题）

**题目**：微机系统中，( )不属于CPU的运算器组成部件。


- A. 程序计数器
- B. 累加寄存器
- C. 多路转换器
- D. ALU单元

**答案**：A [正确]

**解析**：运算器由 ALU、累加寄存器、多路转换器等组成，负责算术与逻辑运算；程序计数器（PC）属于控制器，用于存放将要执行的下一条指令的地址。

**考点**：计算机组成原理；CPU 结构

### 1.32 第36题（单选题）

**题目**：Windows中，在命令行输入( )命令可以得到如下的回显。  Server: UnKnown  Adress: 159.47.11.80  xxx.edu.cn  primary name server = nsl.xxx.edu.cn  responsible mail addr = mailxxx.edu.cn  serial = 2020061746  refresh= 1200(20 mins)  retry= 7200(2 hours)  expire = 3600(1 hour)  default TTL = 3600(1 hour)


- A. nslookup -type=A xxx.edu.cn
- B. nslookup -type=CNAME xxx.edu.cn
- C. nslookup -type=NS xxx.edu.cn
- D. nslookup -type=PTR xxx.edu.cn

**答案**：C [答案存疑] 回显字段属于 SOA 记录，选项中没有 SOA

**解析**：回显中的 primary name server、responsible mail addr、serial、refresh、retry、expire、default TTL 都是 SOA（授权开始）记录的字段，只有 nslookup -type=SOA 才会返回这些内容；-type=NS 仅列出名称服务器，-type=A、CNAME、PTR 分别查询地址、别名和反向记录。原答案 C 与回显不符，但选项未提供 SOA，故保留原答案字母并标记存疑。

### 2.2 高频易错点

1. **路由协议分类**：RIPv2 仍是距离矢量协议，IS-IS 是链路状态协议；OSPF 是 IGP，不能用于自治系统之间；BGP 支持路由聚合。
2. **子网划分**：先由掩码确定块大小和网络地址，再排除网络地址与广播地址；/21 的第三字节以 8 为块，/25 把第四字节分为 0～127 和 128～255。
3. **常用端口**：Telnet 23、SMTP 25、POP3 110、IMAP 143、HTTPS 443、BGP 179、SNMP 161/162，注意区分邮件协议端口与 Telnet 端口。
4. **防火墙方向**：outbound 是高优先级区域到低优先级区域；Trust→Local 属于访问防火墙自身，为 inbound。
5. **WLAN 参数**：802.11b/g 工作在 2.4 GHz，802.11a 在 5 GHz；Wi-Fi 6 对应 802.11ax 且支持多频段；漫游由客户端发起；AP 通过 DHCP Option 43 发现 AC。
6. **Linux/Windows 命令**：cp -p 保留权限，chmod 777 为全权限，/etc/hosts 负责本地域名映射，iptables -P 设置默认策略，ipconfig /registerdns 重新注册 DNS。
7. **CSMA/CD**：冲突检测只能减少冲突后的信道浪费，不能降低冲突概率；连续冲突 3 次后的退避时隙数为 2³=8，再次冲突概率为 1/8。
8. **DNS 资源记录**：A 查地址、CNAME 查别名、NS 查名称服务器、PTR 做反向解析、SOA 返回主名称服务器与序列号等授权信息，nslookup 回显中的 serial、refresh、retry、expire 是 SOA 的典型字段。
9. **测试类型**：白盒测试关注程序内部路径与逻辑，功能错误要靠黑盒测试对照需求发现；系统测试目标来自需求分析。
10. **HDLC 帧结构**：帧编号 N(S) 和应答号 N(R) 位于控制字段，不要与地址字段、FCS 混淆。
