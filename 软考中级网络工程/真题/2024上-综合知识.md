## 1.选择题

### 1.1 第1题

**题目**：1、以下不属于5G网络优点的是( )

- A. 传输过程中消耗的资源少，对设备的电池更友好 [正确]
- B. 支持大规模物联网，能够连接大量低功耗设备，提供更高效的管理 [错误]
- C. 引入了网络切片技术，允许将物理网络划分为多个虚拟网络 [错误]
- D. 更好的安全性，采用更强大的加密和身份认证技术 [错误]

**答案**：A

**解析**：5G 的三大场景是 eMBB（增强移动宽带）、mMTC（海量机器通信）、uRLLC（低时延高可靠），带宽提升与天线阵列、高频段使用使终端射频与基带功耗明显高于 4G，"消耗资源少、对电池更友好"是物联网低功耗技术（如 NB-IoT）的追求，不是 5G 的优点。B 对应 mMTC，C 对应网络切片，D 对应 5G 的 SUCI、256 位加密等增强安全机制，均属 5G 特征。

**考点**：5G 三大应用场景；5G 关键技术（网络切片、增强安全）

### 1.2 第2题

**题目**：关于BGP协议描述不正确的是( )

- A. BGP协议计算路由的过程会暴露AS内部的网络拓扑 [正确]
- B. BGP协议用于实现不同AS之间的路由可达 [错误]
- C. BGP是—种距离矢量路由协议，在设计上就避免了环路的发生 [错误]
- D. BGP协议是基于TCP的路由协议 [错误]

**答案**：A

**解析**：BGP 是路径矢量协议，只在 AS 之间传递目的网络前缀与 AS_PATH、NEXT_HOP 等属性，不描述 AS 内部路由器与链路，正是"隐藏内部拓扑、只宣告可达前缀"这一特点使它取代了早期的 EGP，因此 A 的表述是错的（本题选"不正确"）。B 说明 BGP 的用途，C 中路径矢量属于距离矢量类、靠 AS_PATH 天然防环，D 中 BGP 用 TCP 179 端口建立可靠连接，三句都成立。

**考点**：BGP 的路径矢量特性与 AS_PATH 防环；IGP/EGP 的分工

### 1.3 第3题

**题目**：当VLAN数据帧通过trunk链路转发时加入的802.1q标识位于原始以太网帧的( ).

- A. 源MAC地址后 [正确]
- B. FCS前 [错误]
- C. 目的MAC地址后 [错误]
- D. TYPB后 [错误]

**答案**：A

**解析**：802.1Q 标签为 4 字节（TPID 0x8100 + TCI），插入位置在源 MAC 地址之后、类型/长度字段之前，因此帧长由 1518 字节变为 1522 字节。目的 MAC 之后紧跟源 MAC，类型字段之后是数据，FCS 前是数据末尾，B、C、D 三个位置都不对。

**考点**：802.1Q 标签结构与插入位置；Trunk 链路的帧封装

### 1.4 第4题

**题目**：计算机网络的编码与传输过程中，校验码主要用于( ).

- A. 流量控制 [错误]
- B. 分组分类 [错误]
- C. 拥塞控制 [错误]
- D. 差错检测 [正确]

**答案**：D

**解析**：校验码（奇偶校验、CRC 等）通过在数据后附加冗余位，让接收方验证数据在传输中是否发生比特错误，属于差错检测。流量控制与拥塞控制是调节发送速率的机制，分组分类依据报文头字段（如五元组、DSCP），与冗余校验位无关。

**考点**：差错检测与校验码；流量控制、拥塞控制的区别

### 1.5 第5题

**题目**：拥塞控制的最终目标是( )

- A. 最小化延迟 [错误]
- B. 最小化丢包率 [错误]
- C. 最大化带宽利用率 [错误]
- D. 防止过多数据注入网络 [正确]

**答案**：D

**解析**：拥塞控制的本质是让发送方根据网络承载能力调整注入速率，使网络中的流量不超过路由器缓存与链路带宽，从而避免全局性拥塞崩溃。时延、丢包率、带宽利用率是衡量拥塞程度的指标，不是控制的最终目标；一味追求带宽利用率反而会加剧拥塞。

**考点**：拥塞控制的定义与目标；时延、吞吐量、丢包率的权衡

### 1.6 第6题

**题目**：PON网络中的OLT是什么( )的简称

- A. 光线路接入 [错误]
- B. 光网络接入 [错误]
- C. 光网络终端 [错误]
- D. 光线路终端 [正确]

**答案**：D

**解析**：OLT 是 Optical Line Terminal（光线路终端），部署在局端机房，向上连接城域网/核心网，向下经 ODN（分光器与光纤）连接用户侧设备。ONU 为光网络单元、ONT 为光网络终端，二者在用户侧，A、B 不是标准术语。

**考点**：PON 组成（OLT、ODN、ONU/ONT）；光纤接入网结构

### 1.7 第7题

**题目**：( )不能提升多进程的运行效率。

- A. 使用更高主频的CPU [错误]
- B. 使用更高电压的电源 [正确]
- C. 使用GPU处理并行计算 [错误]
- D. 使用更多核的CPU [错误]

**答案**：B

**解析**：多进程/多线程的并行效率取决于可用的计算资源：主频决定单核速度，核数决定并行度，GPU 适合大规模数据并行，内存容量与带宽决定能否同时容纳更多进程。电源电压只影响供电质量与整机功耗、发热，不改变算力，因此不能提升运行效率。

**考点**：CPU 主频、核心数与并行计算；GPU 通用计算

### 1.8 第8题

**题目**：netstat命令中的( )选项可以用于显示网络接口的IP地址和MAC地址

- A. -e [错误]
- B. -i [正确]
- C. -a [错误]
- D. -n [错误]

**答案**：B [存疑]

**解析**：netstat 的 `-i` 用于显示网络接口表（接口名、MTU、收发报文统计），在 Linux 下配合 `-e` 才能展开出接口的 inet 地址与 ether（MAC）地址，因此本题按"接口信息 → -i"作答，属于题库的简化口径。`-a` 显示所有连接与监听端口，`-n` 以数字形式显示地址与端口，`-e` 单独使用时只是显示以太网/扩展统计。

**考点**：netstat 常用选项；网络接口信息查看（对照 ipconfig /all、ip addr）

### 1.9 第9题

**题目**：下列关于干线子系统的说法中错误的是( )

- A. 大楼施工时应为干线子系统预埋暗管 [正确]
- B. 干线子系统连接大楼的设备间和各楼层的配线间 [错误]
- C. 干线子系统是建筑物的垂直主干线缆 [错误]
- D. 干线子系统通常采用光纤作为传输介质 [错误]

**答案**：A

**解析**：干线（垂直）子系统连接设备间与各楼层配线间，沿弱电竖井敷设，通常走桥架或线槽，介质多为光缆或大对数铜缆，B、C、D 均正确。"预埋暗管"是水平子系统与工作区布线的施工方式，干线因为线缆粗、数量多且需扩容，不做暗管预埋，故 A 是错误说法。

**考点**：综合布线六大子系统；干线子系统与水平子系统的施工差异

### 1.10 第10题

**题目**：32位操作系统理论上支持的最大内存空间容量为( )

- A. 4GB [正确]
- B. 16GB [错误]
- C. 1GB [错误]
- D. 2GB [错误]

**答案**：A

**解析**：32 位地址总线可产生 2^32 个地址，按字节编址即 2^32 B = 4GB，这是理论寻址上限。实际 32 位 Windows 还会因内核与设备地址预留只能用 3.2GB 左右，但题目问的是理论值。

**考点**：地址总线宽度与寻址空间；32/64 位系统内存上限

### 1.11 第11题

**题目**：SYN泛洪攻击主要利用的是TCP协议的( )过程。

- A. 数据传输 [错误]
- B. 连接建立 [正确]
- C. 连接释放 [错误]
- D. 序列号校验 [错误]

**答案**：B

**解析**：攻击者伪造源地址大量发送 SYN，服务器回 SYN+ACK 后进入半连接队列等待最后一个 ACK，握手永远无法完成，队列被占满后正常用户无法建连，利用的正是三次握手（连接建立）过程。防御手段包括 SYN Cookie、缩短半连接超时、SYN 代理与流量清洗。

**考点**：TCP 三次握手与半连接队列；SYN Flood 原理与防御

### 1.12 第12题

**题目**：CSMA/CD的具体作用是( )

- A. 用于监测网络带宽的利用率 [错误]
- B. 用于检查数据包的完整性 [错误]
- C. 用于检测网络中的冲突和碰撞 [正确]
- D. 用于检查网络连接的状态 [错误]

**答案**：C

**解析**：CSMA/CD 即载波监听多路访问/冲突检测：发送前先监听信道，空闲则发送，发送过程中继续检测冲突，一旦检测到碰撞就停止发送、发强化干扰信号并随机退避重发。它的核心作用是解决共享介质上的冲突，不负责完整性校验（由 FCS 完成）或带宽统计。

**考点**：CSMA/CD 工作机制；共享式以太网与交换式以太网的区别

### 1.13 第13题

**题目**：关于VLAN说法错误的是( )

- A. 缺省的VLAN名是系统根据VLANID自动生成的 [错误]
- B. IEEE802.1q标准规定，用于标识VLAN的VLANID用10bit [正确]
- C. VLAN工作在OSI参考模型的第二层 [错误]
- D. 每一个VLAN是一个独立的广播域 [错误]

**答案**：B

**解析**：802.1Q 的 TCI 中 VID 字段为 12 位，可表示 4096 个 VLAN（可用范围 1–4094，0 与 4095 保留），所以说 10bit 是错的。缺省 VLAN 名由系统按 ID 生成（如 VLAN0010）、VLAN 属于二层技术、每个 VLAN 是一个广播域，A、C、D 都正确。

**考点**：802.1Q 标签字段（PRI/CFI/VID）；VLAN 与广播域

### 1.14 第14题

**题目**：当( )时不应该发送ICMP差错报文。

- A. 改变路由（重定向），路由器改变了路由报文 [错误]
- B. 终点不可达，路由器或主机不能交付数据报 [错误]
- C. 参数问题，路由器或目的主机收到的数据报的首部中有的字段的值不正确 [错误]
- D. 组播报文，报文从一个源发出,被转发到—组特定的接收者 [正确]

**答案**：D

**解析**：RFC 792 规定，对组播/广播地址的数据报、非首片分片、ICMP 差错报文本身以及源地址非单播的报文都不发送 ICMP 差错报文，否则会造成差错报文风暴，故 D 正确。重定向、终点不可达、参数问题、源抑制、超时都是差错报文的正式类型。

**考点**：ICMP 差错报文类型；不发送差错报文的例外情形

### 1.15 第15题

**题目**：VxLAN与QinQ相比，说法错误的是( ).

- A. 通过MAC-in-UDP封装数据包 [错误]
- B. 增加VLANID数量 [正确]
- C. 其工作层具有更高的可扩展性，适应云计算要求 [错误]
- D. 技术更昂贵，更复杂，不是所有交换机支持 [错误]

**答案**：B

**解析**：QinQ 用内外两层 802.1Q 标签，标识空间已达 4094×4094（约 1600 万），与 VxLAN 的 24 位 VNI 处于同一量级，所以"增加 VLAN ID 数量"并不是 VxLAN 相对 QinQ 的改进点。VxLAN 真正的变化是用 MAC-in-UDP 封装、以 VNI 代替 VLAN ID，可跨三层网络组网、突破 4094 与二层域限制，但需要支持 VTEP 的设备，成本和复杂度更高。

**考点**：VxLAN 封装与 VNI；QinQ 双层标签与二者对比

### 1.16 第16题

**题目**：根据《中华人民共和国数据安全法》，各地区、各部门应当按照数据( )制度，确定本地区、本部门以及相关行业、领域的重要数据具体目录，对列入目录的数据进行重点保护。

- A. 谁收集谁负责 [错误]
- B. 安全监管协调 [错误]
- C. 分类分级保护 [正确]
- D. 谁公开谁负责 [错误]

**答案**：C

**考点**：《数据安全法》分类分级保护制度；重要数据目录

### 1.17 第30题

**题目**：下列层次化网络设计的说法中正确的是( )

- A. 核心层作为流量汇聚处，应设计数据包过滤功能,提供可管理性 [错误]
- B. 汇聚层向核心层进行路由宣告时一般不做子网聚合 [错误]
- C. —般设计3个层次即可，过多的层次会降低网络整体性能 [正确]
- D. 接入层实现用户接入和策略路由等功能 [错误]

**答案**：C

**解析**：层次化设计通常分为接入、汇聚、核心三层，层次越多经过的设备与跳数越多，时延和故障点随之增加，故 C 正确。核心层要求高速无阻塞转发，包过滤与策略应下移到汇聚层（A 错）；汇聚层向核心层宣告路由时应做子网聚合以缩小路由表（B 错）；策略路由属于汇聚/核心的职责，接入层只负责终端接入与二层隔离（D 错）。

**考点**：三层层次化网络模型各层职责；路由聚合与策略部署位置

### 1.18 第31题

**题目**：在Linux系统将所有的外部设备均作为文件统—进行管理，默认情况下，外部设备文件的目录是( )

- A. /1ib [错误]
- B. /bin [错误]
- C. /etc [错误]
- D. /dev [正确]

**答案**：D

**考点**：Linux 目录结构；设备文件与 /dev

### 1.19 第32题

**题目**：在Windows下，可以在开始菜单的“运行”窗口中键入( )命令，可运行Microsoft管理控制台。

- A. TTY [错误]
- B. CMD [错误]
- C. MMC [正确]

### 1.20 第33题

### 1.21 第34题

**题目**：下列工具中可以对Web表单进行暴力破解的是( )

- B. Nmap [错误]
- C. SQLMap [错误]

### 1.22 第35题

**题目**：在域名解析过程中，通常主机会首先查找( )

- A. 辅域名服务器 [错误]
- B. 缓存域名服务器 [错误]
- C. 转发域名服务器 [错误]
- D. 主域名服务器 [正确]

**答案**：D

**解析**：主机解析域名时先查本地 hosts 与 DNS 缓存，未命中就向配置的本地域名服务器发起递归查询，而这个本地服务器通常就是本区域的主域名服务器；只有主服务器不可达或拒绝服务时才转向辅助域名服务器。缓存服务器、转发服务器是部署形态（只缓存或只转发），不是主机首选查询对象。

**考点**：DNS 递归查询与迭代查询；主/辅/缓存/转发域名服务器的角色

**解析**：Trap 是代理在接口 up/down、阈值越限等事件发生时，不等管理站轮询就主动向管理站 162 端口上报，属于事件驱动的告警机制。获取信息用 Get/GetNext，向设备下发配置用 Set，Trap 是单向上报而非广播。

**考点**：SNMP Trap 机制；轮询与事件上报的互补

### 1.49 第62题

**题目**：在交换机上执行display this interface命令，CRC错包呈现出不断上涨的趋势，可以初步排除的是( )

- A. 端口状态异常 [错误]
- B. 物理链路故障 [错误]
- C. 电磁干扰 [错误]
- D. 病毒攻击 [正确]

**答案**：D

**解析**：CRC 校验错包持续增长说明帧在链路上被破坏，常见原因是网线/光纤质量差、接头氧化、距离超限、电磁干扰、端口或光模块故障、双工不匹配，与病毒攻击没有直接因果关系，故可初步排除 D。其余三项都会直接造成 CRC 错包。

**考点**：CRC 错包故障定位；物理层与链路层故障排查思路

### 1.50 第63题

**题目**：下列网络工程项目需求管理应遵循的原则中，不正确的是( )

- A. 需求变更不需评估 [正确]
- B. 需求要分类管理 [错误]
- C. 需求要分优先级 [错误]
- D. 需求要有文档记录 [错误]

**答案**：A

**解析**：需求变更必须经过影响分析（范围、工期、成本、风险）与变更审批后才能实施，直接接受变更会导致范围蔓延与项目失控，故 A 错误。分类管理、优先级排序、文档化与基线化都是需求管理的基本做法。

**考点**：需求管理与变更控制；范围蔓延

### 1.51 第64题

**题目**：以下不属于光纤通信的特点是( )

- A. 抗雷电和电磁干扰性能好，在有大电流脉冲干扰的环境下通讯效果良好 [错误]
- B. 在有效距离内，设备无须对准某个方向，就能进行通讯 [正确]
- C. 传输损耗小，中继距离长，对远距离传输特别经济 [错误]
- D. 无串音干扰，保密性好，也不易被窃听或者截取数据 [错误]

**答案**：B

**解析**：光纤是波导介质，光信号被束缚在纤芯内传输，连接时必须保证纤芯对准（熔接、法兰盘、连接器），弯曲半径与端面清洁都有要求；"无须对准方向即可通信"是无线电、红外等自由空间传播方式的特征，不属于光纤。A、C、D 分别是光纤的抗电磁干扰、低损耗长中继、无串音易保密等优点。

**考点**：光纤通信的特点；有线介质与无线介质的传播差异

### 1.52 第65题

**题目**：某系统按照RAID6冗余设计，要求2个独立的RAID组，且配备1块全局热备盘，该存储系统至少要购置( )块磁盘。

- A. 10 [错误]
- B. 9 [正确]
- C. 7 [错误]
- D. 8 [错误]

**答案**：B

**解析**：RAID6 采用双校验，每组最少 4 块盘（2 块数据 + 2 块校验），2 个独立 RAID 组需要 8 块。全局热备盘不参与任何 RAID 组、单独待命，需再加 1 块，合计 9 块。

**考点**：RAID6 双校验与最小盘数；全局热备与专用热备

### 1.53 第66题

**题目**：RSA加密算法的安全性依赖于( )困难性假设。

- A. 二次剩余 [错误]
- B. 大整数分解 [正确]
- C. 椭圆曲线高散对数 [错误]
- D. 离散对数 [错误]

**答案**：B

**解析**：RSA 的公钥 n 是两个大素数的乘积，公开 n 而隐藏因子，其安全性建立在"大整数分解困难"之上。椭圆曲线离散对数对应 ECC，有限域离散对数对应 DSA、ElGamal、DH，二次剩余是另一类数论难题。

**考点**：非对称加密的数学基础（RSA、ECC、DH）

### 1.54 第67题

**题目**：根据《中华人民共和国个人信息保护法》，个人信息处理者在( )时不需要事前进行个人信息保护影响评估并对处理情况进行记录

- A. 利用匿名化的个人信息进行数据统计 [正确]
- B. 处理敏感个人信息 [错误]
- C. 向境外提供个人信息 [错误]
- D. 进行对个人权益有重大影响的个人信息处理活动 [错误]

**答案**：A

**解析**：个保法第五十五条规定，处理敏感个人信息、利用个人信息进行自动化决策、委托处理或向境外提供、以及其它对个人权益有重大影响的处理活动，都应事前做个人信息保护影响评估并记录。匿名化处理后信息无法识别到特定个人，已不属于个人信息，其统计利用不触发该义务。

**考点**：《个人信息保护法》影响评估（PIA）适用情形；匿名化与去标识化

### 1.55 第68题

**题目**：系统维护的功能不包括( )

- A. 清除异常任务 [错误]
- B. 更新口令 [错误]
- C. 数据备份 [错误]
- D. 定期更换CPU [正确]

**答案**：D

**解析**：系统日常维护包括清理异常进程/任务、账户与口令管理、数据备份与恢复、日志检查、补丁升级等软件与数据层面的工作。CPU 属于硬件，按需更换或升级，不存在"定期更换"的维护规程，故 D 不属于维护功能。

**考点**：系统运行维护内容；硬件维护与软件维护的区分

### 1.56 第69题

**题目**：TCP协议与UDP协议工作在( )

- A. 数据链路层 [错误]
- B. 传输层 [正确]
- C. 物理层 [错误]
- D. 网络层 [错误]

**答案**：B

**解析**：TCP 与 UDP 都是传输层协议，通过端口号区分应用进程，TCP 提供面向连接、可靠、字节流服务，UDP 提供无连接、不可靠的数据报服务。数据链路层对应以太网、PPP，网络层对应 IP、ICMP，物理层对应传输介质与信号。

**考点**：TCP/UDP 在 OSI 与 TCP/IP 模型中的层次；端口与复用

### 1.57 第70题

**题目**：在Linux系统中，使用Apache作为Web服务器时其默认的目录是( )。

- A. /etc/httpd [正确]
- B. /home/httpd [错误]
- C. /etc/home [错误]
- D. /var/log/httpd [错误]

**答案**：A

**解析**：在 RHEL/CentOS 系列中，Apache（httpd）的配置文件与主配置目录为 `/etc/httpd`，其下 `conf/httpd.conf` 是主配置文件；网站根目录默认 `/var/www/html`，日志目录为 `/var/log/httpd`。B、C 不是标准路径，D 只是日志目录。

**考点**：Apache 目录结构（配置、站点根目录、日志）；Linux 服务部署路径

### 1.58 第71题

**题目**：若在光纤通信系统中使用100mW的激光器，当其发射波长为1550m时，其光功率为( )

- A. 40dBm [错误]
- B. 20dBm [正确]
- C. 10dBm [错误]
- D. 30dBm [错误]

**答案**：B

**解析**：dBm 是以 1mW 为基准的对数功率单位，P(dBm)=10lg(P/1mW)=10lg100=20dBm。波长（题中应为 1550nm）只影响光纤衰减系数与色散，不参与功率换算，属于干扰条件。

**考点**：dBm 与 mW 的换算；光纤链路功率预算

### 1.59 第72题

**题目**：下列IP地址( )不属于子网172.16.24.0/21

- A. 172.16.30.4 [错误]
- B. 172.16.32.56 [正确]
- C. 172.16.28.12 [错误]
- D. 172.16.26.251 [错误]

**答案**：B

**解析**：/21 的掩码是 255.255.248.0，第三个字节的块大小为 8，因此 172.16.24.0/21 覆盖 172.16.24.0–172.16.31.255。A、C、D 的第三字节分别为 30、28、26，都落在该区间内；172.16.32.56 已进入下一个子网 172.16.32.0/21，故不属于本子网。

**考点**：子网划分与地址范围计算；CIDR 块大小

### 1.60 第73题

**题目**：在Linux系统中，鼠标、键盘等以字节为单位进行输入输出的设备属于( )

- A. 虚拟设备 [错误]
- B. 块设备 [错误]
- C. 网络设备 [错误]
- D. 字符设备 [正确]

**答案**：D

**解析**：Linux 把设备分为字符设备与块设备：字符设备按字节流顺序读写、通常不支持随机访问，如键盘、鼠标、串口、终端（/dev/tty*）；块设备以数据块为单位随机读写并带缓冲，如硬盘（/dev/sda）。网络设备通过套接字访问，不以设备文件方式读写。

**考点**：Linux 字符设备与块设备；设备文件类型

### 1.61 第74题

**题目**：下列关于自治系统（AS）的措述中正确的是( )。

- A. 自治系统是一个独立的网络管理实体，由-组IP地址块及相关路由策略组成。 [正确]
- B. 自治系统是一个唯一的IP地址块，由一个网络运营商管理。 [错误]
- C. 自治系统是一个独立的网络管理实体，由多个互联的计算机组成。 [错误]
- D. 自治系统是一个由互联的计算机组成的局城网。 [错误]

**答案**：A

**解析**：自治系统是在单一机构管理下、采用统一路由策略的一组网络与路由器的集合，通常由一组 IP 前缀和路由策略构成，并以 AS 号在全球范围内唯一标识。B 把它窄化为单个地址块，C、D 把它说成计算机的集合或局域网，都没有体现"统一路由策略"这一本质。

**考点**：自治系统（AS）与 AS 号；域内路由与域间路由

### 1.62 第75题

**题目**：IPv6地址通常以十六进制数字表示，4个数字为一组用冒号分隔，下面对IPv6地址FE80:0000:0000:0000:004B:EAO0:008E:D426正确的简化的写法是( )。

- A. FE80::004B:EAO0:008E:D426 [错误]
- B. FE8::4B:EAO0:8E:D426 [错误]
- C. FE80::4B:EAO0:8E:D426 [正确]
- D. FE80::4B:EA::8E:D426 [错误]

**答案**：C

**解析**：IPv6 简化规则有两条：每组内的前导零可省略，连续的全零组可用一对冒号 `::` 替代且只能出现一次。原地址前三组为零，压缩后得 FE80::4B:EA00:8E:D426；A 没有去掉组内前导零（004B、008E），B 把首组 FE80 截成了 FE8（组内只能省略前导零，不能把整组截短），D 出现了两个 `::`，均不合法。

**考点**：IPv6 地址压缩规则；IPv6 地址格式与类型

### 2.2 高频易错点

- **否定式题干看反**：第1、2、13、15、38、48、57、58、63 等题问的是"不属于/错误的是"，应选项本身是一个错误表述，选项后的 `[正确]` 只表示"本题选它"，不代表这句话成立。
- **标签与字段的位数**：802.1Q 的 VID 是 12 位（第13题），WPA/TKIP 的 IV 是 48 位而非 32 位（第38题），32 位地址空间是 4GB（第10题），IPv6 每组 16 位。位数题一旦记混就必错。
- **封装位置与顺序**：802.1Q 标签插在源 MAC 之后、类型字段之前（第3题）；VxLAN 是 MAC-in-UDP（第15题）；PPPoE 是 PPP over Ethernet（第56题）。记"谁套在谁外面"比记名词有效。
- **相似协议的角色**：主/辅/缓存/转发域名服务器（第35题）、NS 与 MX 记录（第40题）、Get 与 GetResponse（第49题）、GetNext 的遍历用途，都是"名字相近、职责不同"的典型陷阱。
- **二层与三层的职责边界**：核心层不做包过滤、汇聚层要做路由聚合、接入层不做策略路由（第30题）；STP 解决二层环路、RIP 是三层协议（第39题）。
- **RAID 最小盘数与热备**：RAID6 双校验，每组最少 4 块，热备盘不参与 RAID 组（第65题：2×4+1=9）。
- **单位换算**：dBm=10lg(mW)，100mW 即 20dBm（第71题）；10BASE-T 用曼彻斯特编码，波特率是数据率的两倍（第46题）；采样频率不低于最高频率的 2 倍（第59题）。
- **"可靠传输"不是万金油**：FCS 只做差错检测、出错丢帧，重传与确认才提供可靠传输（第44题）；CSMA/CD 只解决冲突（第12题）。
- **存储与掉电特性**：寄存器、Cache、内存易失，闪存非易失（第60题）；硬盘是外存（第36题）；字符设备按字节流、块设备按块（第73题）。
- **法规只考适用情形**：数据安全法对应"分类分级保护"（第16题），个保法影响评估的豁免是匿名化信息（第67题），不要与"谁收集谁负责"等监管口号混淆。
- **答案处理说明**：第44题（FCS 作用）与第49题（SNMP 获取操作）的站点标注与知识点不符，已按判断订正并标 `[答案存疑]`；第8题（netstat 的 `-i` 与 `-e`）按题库口径保留 `-i`，但实际需 `-i -e` 才能同时看到 IP 与 MAC，标 `[存疑]`。复习时以解析中的原理为准。
