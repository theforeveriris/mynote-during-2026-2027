## 1.静态路由

本部分共 11 题，核心是静态路由的默认优先级、默认路由写法、`preference` 参数、最长掩码匹配、浮动静态路由、等价路由与 `undo` 删除操作。

### 1.1 第1题 华为静态路由的默认优先级

![华为静态路由默认优先级为 60](image/17.1-软考选择题真题解析（二）/slide_0001.jpg)

**【题目】** 华为静态路由的默认优先级是？

**【选项】**

| 选项 | 内容 |
| ---- | ---- |
| A | 0 [错误] |
| B | 1 [错误] |
| C | 60 [正确] |
| D | 100 [错误] |

**【答案】** C

**【解析】**

华为与 H3C 的静态路由默认外部优先级 `Preference` 为 **60**。优先级数值越小越优：直连路由为 0，OSPF 为 10，IS-IS 为 15，静态路由为 60，RIP 为 100，BGP 为 255。配置时可用 `preference` 参数修改，例如 `ip route-static 192.168.2.0 24 10.1.1.1 preference 100`。

**【考点】** 路由协议默认优先级；`Preference` 数值与优先级高低的关系。

### 1.2 第2题 默认路由的正确配置命令

![默认路由配置命令](image/17.1-软考选择题真题解析（二）/slide_0002.jpg)

**【题目】** 华为/H3C 配置默认路由的正确命令是？

**【选项】**

| 选项 | 内容 |
| ---- | ---- |
| A | `ip route-static 0.0.0.0 0.0.0.0 10.1.1.1` [正确] |
| B | `ip route-static default 10.1.1.1` [错误] |
| C | `ip route 0.0.0.0 255.255.255.255 10.1.1.1` [错误] |
| D | `ip default-gateway 10.1.1.1` [错误] |

**【答案】** A

**【解析】**

默认路由的目的网段为 `0.0.0.0/0`，华为使用 `ip route-static` 命令，目的地址与掩码写为 `0.0.0.0 0.0.0.0`。掩码部分也可简写为一个 `0`，即 `ip route-static 0.0.0.0 0 10.1.1.1`，但目的地址必须写全四个 0。B 中的 `default` 不是华为关键字；C 是 Cisco 风格命令；D 是主机默认网关命令，不是路由配置。

**【考点】** 默认路由的匹配条件与华为命令格式。

### 1.3 第3题 指定目标网段与下一跳的静态路由

![静态路由目标网段与下一跳](image/17.1-软考选择题真题解析（二）/slide_0003.jpg)

**【题目】** 需要到达目标网段 `192.168.2.0/24`，下一跳为 `10.1.1.1`，正确的命令是？

**【选项】**

| 选项 | 内容 |
| ---- | ---- |
| A | `ip route-static 192.168.2.0 24 10.1.1.1` [正确] |
| B | `ip route-static 192.168.2.0 255.255.255.0 10.1.1.1` [正确] |
| C | `ip route-static 192.168.2.0/24 10.1.1.1` [错误] |
| D | `route add 192.168.2.0 mask 255.255.255.0 10.1.1.1` [错误] |

**【答案】** A、B（两条命令等价，均可配置成功）[存疑]

**【解析】**

华为静态路由的掩码既可以用掩码长度 `24`，也可以写完整点分十进制 `255.255.255.0`，两条命令含义完全一致。C 把 CIDR 斜杠写法直接放进命令，VRP 不识别；D 是 Windows 主机的路由命令。若考试为单选题，通常以 A 为标准答案；本题课件明确演示两条命令均可下发，故此处并列。

**【考点】** 静态路由命令的掩码参数写法。

### 1.4 第4题 静态路由优先级参数

![静态路由 preference 参数](image/17.1-软考选择题真题解析（二）/slide_0004.jpg)

**【题目】** 为静态路由配置优先级为 100 的命令是？

**【选项】**

| 选项 | 内容 |
| ---- | ---- |
| A | `cost 100` [错误] |
| B | `preference 100` [正确] |
| C | `priority 100` [错误] |
| D | `distance 100` [错误] |

**【答案】** B

**【解析】**

华为使用 `preference` 表示路由优先级，追加在静态路由命令末尾；`cost` 表示度量值；`priority` 常用于 STP 端口优先级等场景；`distance` 是 Cisco 的管理距离。三者含义不同，不能混用。

**【考点】** `preference`、`cost`、`priority`、`distance` 的区分。

### 1.5 第5题 静态路由的特性

![静态路由特性](image/17.1-软考选择题真题解析（二）/slide_0005.jpg)

**【题目】** 静态路由支持以下哪种特性？

**【选项】**

| 选项 | 内容 |
| ---- | ---- |
| A | 自动适应拓扑变化 [错误] |
| B | 基于链路状态计算路径 [错误] |
| C | 手动指定精确路径 [正确] |
| D | 动态负载均衡 [错误] |

**【答案】** C

**【解析】**

静态路由由管理员逐条手工配置，不运行路由协议，不能自动发现邻居或适应拓扑变化，也不会基于链路状态计算路径。其优点是可控、精确、开销小；缺点是新旧路径切换需要人工干预。静态路由可以配置等价路由实现负载分担，但这是静态配置的结果，不是“动态负载均衡”。

**【考点】** 静态路由与动态路由的差异。

### 1.6 第6题 同一目标网段、不同优先级的静态路由

![两条静态路由优先级比较](image/17.1-软考选择题真题解析（二）/slide_0006.jpg)

**【题目】** 两条静态路由指向同一目标网段，优先级不同的情况下？

**【选项】**

| 选项 | 内容 |
| ---- | ---- |
| A | 同时生效负载均衡 [错误] |
| B | 优先级高的生效 [正确] |
| C | 优先级低的生效 [错误] |
| D | 路由表拒绝添加 [错误] |

**【答案】** B

**【解析】**

同一目的网段存在多条路由时，先比较优先级，`Preference` 数值越小优先级越高，只有最优路由进入路由表并参与转发。优先级较低的路由不会删除，可作为备份，主路由失效后接管，这就是浮动静态路由。若两条路由优先级相同，才会形成等价路由并负载分担。

**【考点】** 路由选路顺序；浮动静态路由的形成条件。

### 1.7 第7题 最长掩码匹配

![最长掩码匹配验证](image/17.1-软考选择题真题解析（二）/slide_0007.jpg)

**【题目】** 目标地址为 `172.16.1.0/24` 的报文，匹配哪条路由？

**【选项】**

| 选项 | 内容 |
| ---- | ---- |
| A | `ip route-static 172.16.0.0 255.255.0.0 ...` [错误] |
| B | `ip route-static 172.16.1.0 255.255.255.0 ...` [正确] |
| C | `ip route-static 0.0.0.0 0.0.0.0 ...` [错误] |
| D | [文字被遮挡，课件仅见 A~C 三项] |

**【答案】** B

**【解析】**

路由表查找遵循**最长掩码匹配**原则：目的地址同时命中多条路由时，选择掩码最长、最精确的一条。A 为 `/16`，覆盖 `172.16.0.0/16`；B 为 `/24`，只覆盖 `172.16.1.0/24`；C 为默认路由 `/0`，最不精确。因此 B 最优。实验中写入三条路由后查询 `172.16.1.100`，下一跳为 `64.1.1.20`，验证了最长掩码优先。

**【考点】** 最长前缀匹配；路由表查询。

### 1.8 第8题 浮动静态路由的关键

![浮动静态路由配置](image/17.1-软考选择题真题解析（二）/slide_0008.jpg)

**【题目】** 配置浮动静态路由（备份路由）的关键是？

**【选项】**

| 选项 | 内容 |
| ---- | ---- |
| A | 指定不同出接口 [错误] |
| B | 设置更高优先级（如 `preference 100`） [错误] |
| C | 设置更低优先级（如 `preference 100`） [正确] |
| D | 使用不同下一跳 [错误] |

**【答案】** C

**【解析】**

浮动静态路由的做法是：主路由保持默认优先级 60，备份路由设置一个**更大的** `preference` 值（数值更大表示优先级更低），例如 100。这样备份路由平时不进路由表，只有当主路由失效时才浮出并接管流量。B 的“更高优先级”与 `preference 100` 自相矛盾：100 大于 60，实际是更低优先级。

**【考点】** 浮动静态路由；`preference` 数值方向。

### 1.9 第9题 等价静态路由与负载均衡

![等价静态路由](image/17.1-软考选择题真题解析（二）/slide_0009.jpg)

**【题目】** 配置等价静态路由实现负载均衡的命令是？

**【选项】**

| 选项 | 内容 |
| ---- | ---- |
| A | 重复添加两条相同路由 [正确] |
| B | 指定 `load-balance` 参数 [错误] |
| C | 两条路由优先级相同 [错误] |
| D | 使用 `ip route-static multi-path` [错误] |

**【答案】** A

**【解析】**

华为设备上，为同一目的网段配置两条**优先级相同、下一跳不同**的静态路由，即可形成等价路由，流量按哈希算法在多条链路上分担。命令层面就是重复添加两条相同目的网段的路由，不需要额外的 `load-balance` 或 `multi-path` 参数。C 只是等价路由成立的条件之一，不是命令。

**【考点】** 等价路由；负载分担。

### 1.10 第10题 两条静态路由的生效结果

![两条静态路由的生效结果](image/17.1-软考选择题真题解析（二）/slide_0010.jpg)

**【题目】** 某路由器配置了：

```text
ip route-static 192.168.1.0 255.255.255.0 10.1.1.1
ip route-static 192.168.1.0 255.255.255.0 10.1.1.2 preference 70
```

生效的路由是？

**【选项】**

| 选项 | 内容 |
| ---- | ---- |
| A | 两条形成负载均衡 [错误] |
| B | 下一跳 `10.1.1.1` 的路由 [正确] |
| C | 下一跳 `10.1.1.2` 的路由 [错误] |
| D | 路由冲突报错 [错误] |

**【答案】** B

**【解析】**

第一条未指定优先级，取默认值 60；第二条指定 70。60 小于 70，第一条优先级更高，只有下一跳 `10.1.1.1` 的路由进入路由表。第二条作为备份保留，不会报错。若要让两条形成负载均衡，必须把两条的 `preference` 配成相同值。

**【考点】** 默认优先级与显式优先级的比较。

### 1.11 第11题 删除静态路由的命令

## 2.VLAN 与三层交换

本部分共 7 题，覆盖 VLAN 间通信方案、Eth-Trunk 配置、VLANIF 网关、Cisco 三层交换机默认路由功能、Trunk/Hybrid 承载多 VLAN、出口默认路由以及聚合口状态查看。

### 2.1 第1题 不同 VLAN 间主机通信的常用方案

![不同 VLAN 间通信方案](image/17.1-软考选择题真题解析（二）/slide_0014.jpg)

**【题目】** 若要实现不同 VLAN 间的主机相互通信，以下哪种技术方案是最常用且适用于中小型网络的？

**【选项】**

| 选项 | 内容 |
| ---- | ---- |
| A | 仅在接入层交换机配置 VLAN 划分 [错误] |
| B | 在核心层路由器上配置单臂路由 [错误] |
| C | 在汇聚层交换机上开启三层功能并配置 VLANIF 接口 [正确] |
| D | 无需任何额外配置，VLAN 间默认可通信 [错误] |

**【答案】** C

**【解析】**

中小型网络最常用的做法是使用三层交换机，为每个 VLAN 创建 VLANIF 接口并配置网关 IP，实现 VLAN 间受控转发。接入层交换机通常只做二层接入和 VLAN 划分，不能承担网关；单臂路由虽然也能实现 VLAN 间通信，但链路带宽容易成为瓶颈，现网已较少使用；VLAN 默认相互隔离，必须配置三层网关才能互通。

**【考点】** VLAN 间路由；三层交换机与 VLANIF。

### 2.2 第2题 将端口加入 Eth-Trunk 的正确命令

![Eth-Trunk 成员口配置命令](image/17.1-软考选择题真题解析（二）/slide_0015.jpg)

**【题目】** 华为交换机上，若要将端口 `G0/0/1` 和 `G0/0/2` 加入 `Eth-Trunk 1` 接口，以下哪个配置命令是正确的？

**【选项】**

| 选项 | 内容 |
| ---- | ---- |
| A | `[Huawei] interface Eth-Trunk 1`；`[Huawei-Eth-Trunk1] trunkport GigabitEthernet 0/0/1 0/0/2` [错误] |
| B | `[Huawei] trunkport GigabitEthernet 0/0/1 0/0/2 to Eth-Trunk 1` [错误] |
| C | `[Huawei-GigabitEthernet0/0/1] eth-trunk 1`；`[Huawei-GigabitEthernet0/0/2] eth-trunk 1` [正确] |
| D | `[Huawei] interface GigabitEthernet 0/0/1`；`[Huawei-GigabitEthernet0/0/1] trunk eth-trunk 1` [错误] |

**【答案】** C

**【解析】**

华为有两种合法配置方式：其一，在 Eth-Trunk 视图下使用 `trunkport GigabitEthernet 0/0/1 to GigabitEthernet 0/0/2`（必须有 `to`）；其二，分别进入成员口，在接口视图下执行 `eth-trunk 1`。A 的 `trunkport` 缺少 `to`，命令不完整；B 在系统视图直接使用 `trunkport`，视图和语法都不对；D 的 `trunk eth-trunk` 不存在。

**【考点】** Eth-Trunk 成员口加入方式。

### 2.3 第3题 VLANIF 接口实现 VLAN 间通信

![VLANIF 接口配置](image/17.1-软考选择题真题解析（二）/slide_0016.jpg)

**【题目】** 华为三层交换机上已创建 VLAN 10 和 VLAN 20，若要实现 VLAN 10 和 VLAN 20 间通信，需至少配置以下哪项？

**【选项】**

| 选项 | 内容 |
| ---- | ---- |
| A | 为 VLAN 10 和 VLAN 20 分别创建 VLANIF 接口，并配置各自的 IP 地址 [正确] |
| B | 在交换机上配置静态路由，指向对方 VLAN 的网段 [错误] |
| C | 将连接两个 VLAN 主机的端口配置为 Trunk 模式 [错误] |
| D | 在交换机上开启 DHCP 服务，为两个 VLAN 的主机分配 IP 地址 [错误] |

**【答案】** A

**【解析】**

三层交换机跨 VLAN 转发依赖 VLANIF 接口：VLAN 10 的主机把网关指向 VLANIF 10 的地址，VLAN 20 的主机把网关指向 VLANIF 20 的地址，交换机查路由表完成三层转发。两个 VLAN 都属于同一台三层交换机的直连网段，不需要额外静态路由；连接主机的接入口仍配置为 Access；DHCP 只负责分配地址，不负责跨网段转发。

**【考点】** VLANIF 网关；直连网段与静态路由的适用边界。

### 2.4 第4题 主机无法通信的最可能原因

![主机无法通信的原因分析](image/17.1-软考选择题真题解析（二）/slide_0017.jpg)

**【题目】** 三层交换机上，若 VLAN 10 的 VLANIF 10 接口 IP 地址配置为 `192.168.10.1/24`，VLAN 20 的 VLANIF 20 接口 IP 地址配置为 `192.168.20.1/24`，VLAN 10 内的主机 IP 为 `192.168.10.10/24`、网关为 `192.168.10.1`，VLAN 20 内的主机 IP 为 `192.168.20.10/24`、网关为 `192.168.20.1`，此时两个主机之间无法通信，最可能的原因是？

**【选项】**

| 选项 | 内容 |
| ---- | ---- |
| A | 两个 VLANIF 接口未开启 [错误] |
| B | 主机 IP 地址配置错误 [错误] |
| C | 网关配置错误 [错误] |
| D | 交换机未开启三层路由功能 [正确] |

**【答案】** D

**【解析】**

题干没有说明是华为设备，而 Cisco 三层交换机默认**未开启**三层路由功能，必须在全局视图执行 `ip routing`，才能在不同网段之间转发。华为、H3C、锐捷等设备默认开启该功能，所以同样的配置在华为上可直接通信。VLANIF 接口配置 IP 后即具备转发条件（还需 VLAN 内有处于 up 状态的成员口），A 不对；按题干给出的地址与网关，B、C 也均正确。

**【考点】** Cisco 三层交换机 `ip routing` 默认关闭；厂商默认行为差异。

### 3.4 第4题 PAT 的 ACL 匹配规则

**【选项】**

| 选项 | 内容 |
| ---- | ---- |
| A | 允许 VLAN 10 的私网流量通过，作为 PAT 的匹配条件 [正确] |

### 3.6 第6题 ACL 规则冲突与匹配顺序

![ACL 规则冲突结果](image/17.1-软考选择题真题解析（二）/slide_0029.jpg)

**【题目】** 华为设备上，若 ACL 规则存在冲突（如先配置“拒绝所有 IP 流量”，再配置“允许 `192.168.1.0/24` 流量”），会导致什么结果？

**【选项】**

| 选项 | 内容 |
| ---- | ---- |
| A | 系统自动优先执行“允许”规则，`192.168.1.0/24` 流量可通过 [错误] |
| B | 规则按配置顺序执行，先拒绝所有流量，后续“允许”规则无效 [正确] |
| C | 系统提示规则冲突，自动删除后配置的“允许”规则 [错误] |
| D | 系统自动调整规则顺序，将“允许”规则放在前面 [错误] |

**【答案】** B

**【解析】**

ACL 按规则编号从小到大逐条匹配，命中即停止，不会继续向下查找。华为默认步长为 5，第一条规则编号为 5，第二条为 10。先配置 `rule deny ip` 会拒绝所有流量，后面编号为 10 的 `permit` 永远不会被命中。正确做法是把精确的允许规则放在前面，末尾再显式拒绝其余流量。实验中加入 `rule 5 deny` 后业务立即中断，`undo rule 5` 后恢复。

**【考点】** ACL 匹配顺序；默认步长 5；隐式拒绝。

### 3.7 第7题 禁止访问外部 80 端口的 ACL 类型

![高级 ACL 禁止 80 端口](image/17.1-软考选择题真题解析（二）/slide_0030.jpg)

**【题目】** 华为路由器上，若要禁止内部主机访问外部的 80 端口（HTTP 服务），应使用以下哪种 ACL 类型并配置对应规则？

**【选项】**

| 选项 | 内容 |
| ---- | ---- |
| A | 基本 ACL（2000~2999），规则：拒绝源 IP 为内部网段，目的端口 80 [错误] |
| B | 高级 ACL（3000~3999），规则：拒绝 TCP 协议，目的端口 80 [正确] |
| C | 二层 ACL（4000~4999），规则：拒绝目的 MAC 地址对应外部 HTTP 服务器 [错误] |

**【答案】** A

**【解析】**

边缘端口在接口视图下配置：`stp edged-port enable`。配置后端口不参与生成树计算，链路 up 后立即进入转发状态，避免终端接入等待约 30 秒，也避免终端在等待期间错过 DHCP 请求。批量配置可用 `interface range` 进入多个接口后统一执行。生产环境建议同时配置 BPDU 保护，防止边缘端口接入交换机形成环路。

**【考点】** 边缘端口；`stp edged-port enable`；终端接入优化。

### 6.5 第5题 查看指定端口的 STP 详细信息

![查看指定端口 STP 状态](image/17.1-软考选择题真题解析（二）/slide_0054.jpg)

**【题目】** 华为交换机上，若要查看指定端口 `G0/0/2` 的 STP 状态（如端口角色、状态、路径开销等），可使用以下哪个命令？

**【选项】**

| 选项 | 内容 |
| ---- | ---- |
| A | `display stp interface GigabitEthernet 0/0/2` [正确] |
| B | `show stp port GigabitEthernet 0/0/2 status` [错误] |
| C | `display stp port 0/0/2 detail` [错误] |
| D | `show stp interface GigabitEthernet 0/0/2 info` [错误] |

**【答案】** A

**【解析】**

`display stp interface GigabitEthernet 0/0/2` 输出该端口的详细 STP 信息，包括端口角色、状态、路径开销、优先级、指定桥等；若只看摘要，用 `display stp brief`。B、D 为 `show` 风格；C 的命令参数不符合华为 VRP。

**【考点】** STP 接口详情查看；`display stp interface`。

### 6.6 第6题 根桥选举的比较依据

![根桥选举依据](image/17.1-软考选择题真题解析（二）/slide_0055.jpg)

**【题目】** 根桥选举中，若所有交换机优先级相同，则依据什么决定根桥？

**【选项】**

| 选项 | 内容 |
| ---- | ---- |
| A | IP 地址最小 [错误] |
| B | MAC 地址最小 [正确] |
| C | 端口 ID 最小 [错误] |
| D | 系统序列号最小 [错误] |

**【答案】** B

**【解析】**

根桥选举先比较桥 ID，桥 ID 由桥优先级和桥 MAC 地址组成，先比优先级（越小越优），优先级相同再比 MAC 地址（越小越优）。IP 地址、端口 ID、系统序列号都不参与根桥比较；端口 ID 用于在非根桥上选举根端口和在各链路上选举指定端口。

**【考点】** 桥 ID；根桥选举顺序。

### 6.7 第7题 RSTP 中 Alternate 端口的作用

![RSTP Alternate 端口](image/17.1-软考选择题真题解析（二）/slide_0056.jpg)

**【题目】** RSTP 中的“Alternate 端口”作用是？

**【选项】**

| 选项 | 内容 |
| ---- | ---- |
| A | 直接连接终端设备 [错误] |
| B | 提供到达根桥的备份路径 [正确] |
| C | 转发所有流量 [错误] |
| D | 阻塞 BPDU 报文 [错误] |

**【答案】** B

**【解析】**

Alternate 端口是根端口的备份，提供另一条到达根桥的路径，处于 Discarding 状态；当根端口故障时，Alternate 端口可快速切换为新的根端口。直接连接终端的是边缘端口；Backup 端口是指定端口的备份；Alternate 端口并不转发用户流量，也不是“阻塞 BPDU”。

**【考点】** RSTP 端口角色；Alternate 与 Backup 的区别。

### 6.8 第8题 三交换机环网的阻塞端口判断

![三交换机 STP 拓扑与题目](image/17.1-软考选择题真题解析（二）/slide_0057.jpg)

![三交换机 STP 阻塞端口选项](image/17.1-软考选择题真题解析（二）/slide_0058.jpg)

**【题目】** 如图，三台交换机仅开启生成树，没做任何配置，会堵塞哪个接口？

**【选项】**

| 选项 | 内容 |
| ---- | ---- |
| A | `SW2` 的 `g0/0/2` 口 [正确] |
| B | `SW1` 的 `g0/0/1` 口 [错误] |
| C | `SW3` 的 `g0/0/2` 口 [错误] |
| D | `SW2` 的 `g0/0/1` 口 [错误] |

**【答案】** A

**【解析】**

三台交换机优先级均为默认 32768，比较 MAC 地址：

| 交换机 | 桥 MAC | 比较结果 |
| ------ | ------ | -------- |
| LSW1 | `4c1f-cc5f-01f9` | 最小，选为根桥 |
| LSW3 | `4c1f-ccf1-386c` | 次小 |
| LSW2 | `4c1f-ccf3-62ae` | 最大 |

LSW1 为根桥，其两个端口均为指定端口并转发。LSW2 与 LSW3 各自到 LSW1 的端口为根端口。LSW2 与 LSW3 之间的链路上，二者到达根桥的路径开销相同，继续比较发送网桥 ID：LSW3 的 MAC 更小，因此 LSW3 的 `g0/0/1` 为指定端口并转发，LSW2 的 `g0/0/2` 落选为 Alternate 端口并阻塞。实验中在 LSW2 上查看，`G0/0/2` 的状态为 `DISCARDING`，与推理一致。

**【考点】** STP 选举顺序：先选根桥，再选根端口、指定端口，最后确定阻塞端口；桥 MAC 比较。

## 7.本章小结

### 7.1 高频考点

| 模块 | 高频考点 | 关键结论 |
| ---- | -------- | -------- |
| 静态路由 | 默认优先级、默认路由、`preference`、最长掩码、浮动路由、等价路由、`undo` | 静态路由默认 `Preference 60`；默认路由 `0.0.0.0/0`；数值越小越优；最长掩码优先；`undo` 删除 |
| VLAN 与三层交换 | VLANIF、Eth-Trunk、Trunk/Hybrid、出口默认路由 | 跨 VLAN 用三层交换机 + VLANIF；Eth-Trunk 成员口用 `eth-trunk 1` 或 `trunkport ... to ...`；出口需默认路由 |
| ACL | 基本/高级/二层 ACL、通配符掩码、接口调用、匹配顺序 | 基本 ACL 只匹配源 IP；高级 ACL 可匹配五元组；`traffic-filter outbound acl 3000`；ACL 自上而下命中即停 |
| NAT | 静态 NAT、PAT | `nat static global ... inside ...`；PAT 用 ACL 匹配内网源地址，出口 `nat outbound` |
| AAA 与设备管理 | 本地用户、VTY、DHCP 地址池、计费 | `aaa` 视图建用户；Telnet 认证在 VTY 视图；`ip pool` + `network` + `gateway-list` + `dns-list` |
| DHCP | 静态绑定、租约、中继、客户端信息 | `static-bind` 绑定 MAC；`lease day/hour/minute`；中继用 `dhcp select relay` + `dhcp relay server-ip` |
| 网络管理 | SNMP、Ping、FTP | SNMP 监控告警；Ping 基于 ICMP；FTP 客户端 `put` 上传、`get` 下载 |
| 生成树 | 桥优先级、边缘端口、RSTP 角色、根桥选举 | 优先级 4096 步长；`stp edged-port enable`；根桥先比优先级再比 MAC；Alternate 是根端口备份 |

### 7.2 易错点

1. **优先级方向**：华为 `Preference` 数值越小越优；静态路由默认 60，改成 100 是降低优先级，用于浮动备份。
2. **掩码写法**：华为静态路由支持掩码长度（`24`）和点分十进制（`255.255.255.0`），但不支持把 `192.168.2.0/24` 直接写进命令。
3. **`display` 与 `show`**：华为、H3C 用 `display`；Cisco、迈普、烽火等用 `show`。
4. **ACL 通配符掩码**：`/24` 对应 `0.0.0.255`，不是 `255.255.255.0`。
5. **ACL 顺序**：先配置的规则先匹配，`deny all` 放在前面会使后续 `permit` 全部失效。
6. **基本 ACL 的能力边界**：基本 ACL 只能匹配源 IP，不能匹配目的 IP、协议和端口；禁止 80 端口必须用高级 ACL。
7. **Cisco 三层交换机**：默认未开启 `ip routing`，华为/H3C/锐捷默认开启。
8. **Trunk 与 Hybrid**：二者都能承载多个 VLAN；Access 只能属于一个 VLAN。
9. **边缘端口命令**：华为正确关键字是 `stp edged-port enable`，配置在接口视图。
10. **根桥选举**：先比桥优先级，再比桥 MAC；不是比 IP、端口 ID 或系统序列号。
