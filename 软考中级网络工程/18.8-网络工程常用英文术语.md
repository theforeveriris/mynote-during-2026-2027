# 网络工程常用英文术语 · 完整笔记

---

> 内容来源：《网工常见英文手册整理 v4》（华为 肖哥）。原稿是“看懂设备回显与配置”的词汇表，夹杂大量 PC 操作词（安装向导、开始菜单、键盘鼠标、WinPE 等）。
>
> 整理原则：保留网络工程师**考试与工程实践**常见项，按主题重组；剔除与网络无关的桌面操作词（开始菜单、键盘鼠标、WinPE 等）；原稿中的 `dispaly`、`DCHP` 等拼写错误已校正；补入同主题下配置与回显必见的少量术语。全称列写 `—` 表示该词本身即为完整单词，不是缩写。

## 1.使用说明

### 1.1 为什么网络工程师要背英文

| 场景 | 表现 | 对应能力 |
| ---- | ---- | -------- |
| 看配置 | `display current-configuration` 全是英文关键字 | 认出 `interface`、`ip address`、`undo`、`preference` |
| 看回显 | `Error: Unrecognized command`、`administratively down` | 判断是命令错、接口被关还是链路故障 |
| 看日志 | `Warning`、`Session`、`ESTABLISHED` | 区分告警、会话状态与正常信息 |
| 考试 | 题干给英文缩写或英文命令 | 把缩写还原为全称，理解参数含义 |

### 1.2 成对记忆

| 词对 | 含义 | 典型位置 |
| ---- | ---- | -------- |
| enable / disable | 启用 / 禁用 | 全局、接口、功能开关 |
| permit / deny | 允许 / 拒绝 | ACL 规则 |
| source / destination | 源 / 目的 | ACL、NAT、路由、抓包 |
| local / remote | 本端 / 对端 | 隧道、AAA、端口镜像 |
| primary / backup | 主 / 备 | VRRP、主备链路 |
| tag / untag | 打标签 / 去标签 | VLAN、QinQ |
| inbound / outbound | 入方向 / 出方向 | ACL、流量统计 |
| transmit / receive | 发送 / 接收 | 接口统计、光模块 |
| request / reply | 请求 / 应答 | 协议报文 |
| valid / invalid | 有效 / 无效 | 路由、证书、会话 |
| allocated / unallocated | 已分配 / 未分配 | 磁盘、地址池 |
| used / idle / free | 已用 / 空闲 / 空闲 | 地址池、内存、磁盘 |
| include / exclude | 包含 / 排除 | 地址池、过滤 |

### 1.3 构词规律

| 规律 | 例子 | 含义 |
| ---- | ---- | ---- |
| `un-` 表示否定 | undo、unassigned、unavailable、unlimited | 取消、未分配、不可用、不限制 |
| `dis-` 表示否定/分离 | disable、disconnect、discard | 禁用、断开、丢弃 |
| `re-` 表示再次/回 | reset、reboot、reload、restart、reply | 重置、重启、重载、重启、回复 |
| `sub-` 表示子级 | sub-interface、sub-vlan、sub-option | 子接口、子 VLAN、子选项 |
| `inter-` / `intra-` | inter-ac、intra-ac | AC 间 / AC 内 |
| `-tion` / `-ment` 名词化 | authentication、encryption、assignment、agreement | 认证、加密、分配、协议 |
| 截短词 | config、info、stat、admin、max、min | configuration、information、statistics、administrator |
| 首字母缩写 | AAA、ACL、VLAN、CAPWAP | 取各词首字母 |
| 组合缩写 | Vlanif = VLAN interface、VTY = Virtual Teletype Terminal | 接口名、终端类型 |

## 11.本章小结

| 知识点 | 核心内容 |
| ------ | -------- |
| 1. 学习方法 | 成对记（enable/disable、permit/deny、source/destination）、按主题记、在回显里记 |
| 2. 网络基础 | host/server/client、packet/frame/payload、source/destination、inbound/outbound |
| 3. 交换 | VLAN、Vlanif、tag/untag、PVID、trunk/access/hybrid、Eth-Trunk、STP/MSTP |
| 4. 路由 | route-static、preference、cost/metric、process、area、import、route-policy |
| 5. 安全 | AAA、ACL、permit/deny、wildcard、cipher/simple、RADIUS、802.1X、WEP/WPA/WPA2 |
| 6. 无线 | AP/AC、FAT/FIT、BSS/ESS/SSID/BSSID、VAP、CAPWAP、PoE、EIRP、漫游 |
| 7. 存储硬件 | memory/cache/buffer、disk/partition/image、module/slot、fan/power |
| 8. 管理运维 | display/undo/commit/save、current-configuration、log/info-center、status/state |
| 9. 回显判读 | `Unrecognized command` 命令错、`administratively down` 被 shutdown、`ESTABLISHED` 已建立 |
| 10. 接口命名 | E/GE/XGE、MEth、Vlanif、Eth-Trunk、Serial、LoopBack |

考试重点：

1. **成对词先记**：enable/disable、permit/deny、source/destination、local/remote、primary/backup、tag/untag。
2. **preference 与 priority 不是一回事**：前者是路由优先级（华为越小越优），后者是 VRRP/QoS 优先级。
3. **cost 与 metric**：cost 是接口/路径开销，metric 是协议选路的度量值总称。
4. **simple 与 cipher**：`password simple` 明文保存，`password cipher` 密文保存，考试常考安全性判断。
5. **VLAN 相关**：tag/untag、PVID、trunk/access/hybrid，以及“华为 Trunk 是端口类型、链路聚合叫 Eth-Trunk”。
6. **无线缩写**：AP、AC、STA、BSS、ESS、SSID、BSSID、VAP、CAPWAP、PoE、EIRP。
7. **AAA**：Authentication（认证）、Authorization（授权）、Accounting（计费/审计），三者顺序固定。
8. **回显关键词**：`Unrecognized command` 是命令或视图错误；`administratively down` 是接口被关闭；`ESTABLISHED` 表示连接已建立。
9. **接口命名**：E=百兆、GE=千兆、XGE=万兆、MEth=管理口、Vlanif=VLAN 三层接口。
10. **命令动词**：`display` 查看、`undo` 撤销、`commit` 提交、`save` 保存、`reset` 重置。
