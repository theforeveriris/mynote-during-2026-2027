## 2.计算机网络定义

### 2.1 定义

计算机网络是指将地理位置不同、具有独立功能的多台计算机（或设备），通过通信线路和通信设备互连起来，并在网络协议和网络软件的管理下，实现资源共享和信息传递的系统。

定义包含三个要素：

| 要素 | 含义 |
|------|------|
| 独立自治的计算机 | 每台计算机具有独立的操作系统和处理能力，不是主从控制关系 |
| 通信线路与设备互连 | 通过双绞线、光纤、无线等介质实现物理连接 |
| 网络协议 | 通信双方必须遵循共同的规则，否则无法交换数据 |

### 2.2 网络协议的三要素

网络协议的三要素：

| 要素 | 含义 |
|------|------|
| 语法 | 数据与控制信息的结构或格式，如帧格式、字段顺序 |
| 语义 | 需要发出何种控制信息、完成何种动作以及做出何种响应 |
| 时序 | 事件实现顺序的详细说明，如握手顺序、超时重传 |

### 2.3 功能

| 功能 | 说明 |
|------|------|
| 资源共享 | 包括硬件共享、软件共享和数据（信息）共享，是网络最主要的功能 |
| 数据通信 | 实现计算机之间信息的传输与交换，是网络的基础功能 |
| 集中管理 | 对分散的资源、用户和权限进行统一管理 |
| 分布式处理 | 将大型任务分解到多台计算机上并行处理 |
| 负载均衡 | 将业务流量分摊到多台服务器或链路，提高整体处理能力 |
| 提高可靠性 | 通过冗余链路和冗余设备，在单点故障时仍可通信 |

## 3.计算机网络分类

### 3.1 按覆盖范围分类

| 分类 | 个域网 PAN | 局域网 LAN | 城域网 MAN | 广域网 WAN |
|------|-----------|-----------|-----------|-----------|
| 地理范围 | 一般10~20m内 | 大楼内、园区内部 | 建筑物之间，城区内 | 国内、国际 |
| 特点 | 低功耗、低传输速率、短距离 | 覆盖范围窄、用户数少、配置容易、连接速率高 | 介于局域网和广域网之间 | 距离较远，信息衰减比较严重 |
| 典型案例 | 蓝牙、家庭WiFi | 校园网、企业内部网络 | 教育城域网、运营商城域网 | 运营商骨干网 |

### 3.2 按交换技术分类

| 交换方式 | 是否建立连接 | 传输单位 | 时延 | 线路利用率 | 典型应用 |
|---------|------------|---------|------|-----------|---------|
| 电路交换 | 需要，独占物理线路 | 比特流 | 建立连接后时延小且固定 | 低 | 电话网PSTN、ISDN |
| 报文交换 | 不需要 | 整个报文 | 较大，存储转发 | 较高 | 早期电报、长报文文件传送 |
| 分组交换 | 数据报不需要，虚电路需要 | 分组（Packet） | 较小，存储转发 | 高 | Internet、X.25、帧中继、ATM |

分组交换是现代计算机网络的核心技术，其优点是线路利用率高、支持突发业务、便于差错控制和路由选择；缺点是需要存储转发，可能产生排队时延和抖动。ATM采用固定53字节的信元（5字节首部+48字节数据），可视为分组交换的一种特殊形式。

### 3.3 按拓扑结构分类

| 拓扑 | 结构特点 | 优点 | 缺点 |
|------|---------|------|------|
| 总线型 | 所有节点共享一条总线 | 布线简单、成本低 | 冲突多，故障点难以定位 |
| 星型 | 所有节点连接到中心设备 | 易于管理，单点故障易隔离 | 依赖中心节点，中心故障导致全网瘫痪 |
| 环型 | 节点首尾相连成环 | 无冲突，时延确定 | 单点故障影响全网，扩容不便 |
| 树型 | 星型的分级组合 | 层次清晰，便于扩展 | 根节点是关键点 |
| 网状型 | 节点之间有多条链路 | 可靠性高，冗余路径多 | 成本高，路由复杂 |

## 4.计算机网络性能参数

### 4.1 速率与带宽

| 参数 | 含义 | 单位 |
|------|------|------|
| 速率（数据率） | 单位时间内传输的比特数 | bit/s，即bps |
| 带宽（模拟） | 信道能通过的信号频率范围，等于最高频率与最低频率之差 | Hz |
| 带宽（数字） | 网络中某链路所能达到的最高数据率 | bit/s |

常用换算：1kbps=10^3bps，1Mbps=10^6bps，1Gbps=10^9bps，1Tbps=10^12bps。注意存储容量换算用1024，而速率换算用1000。

### 4.2 时延

| 时延类型 | 公式或说明 |
|---------|----------|
| 发送时延（传输时延） | 数据帧长度（bit）/ 发送速率（bit/s） |
| 传播时延 | 信道长度（m）/ 电磁波在信道中的传播速率（m/s） |
| 处理时延 | 节点检查首部、查找路由、差错检测所需时间 |
| 排队时延 | 数据在节点输出队列中等待发送的时间 |

总时延 = 发送时延 + 传播时延 + 处理时延 + 排队时延。

关键常数：

| 介质 | 传播速率 |
|------|---------|
| 铜缆、光纤 | 约2×10^8 m/s，即200 m/μs、200 km/ms |
| 无线电波（真空） | 3×10^8 m/s |
| 地球同步卫星 | 地球站—卫星—地球站单跳约270ms（教材口径；单程约120ms） |

发送时延与传播时延的区别：发送时延取决于数据长度和发送速率，与链路长度无关；传播时延取决于链路长度和传播速率，与数据长度无关。

### 4.3 其他性能参数

| 参数 | 定义 | 公式或说明 |
|------|------|-----------|
| 时延带宽积 | 链路上“正在传播”的比特数，又称以比特为单位的链路长度 | 传播时延 × 带宽 |
| 往返时间RTT | 从发送方发出数据到收到对方确认所经历的时间 | 通常包含往返传播时延和中间节点处理时延 |
| 吞吐量 | 单位时间内通过某个网络或信道的数据量 | 受瓶颈链路带宽限制，≤ 最小链路带宽 |
| 信道利用率 | 信道有数据通过的时间占总时间的比例 | 有数据通过的时间 / 总时间 |

信道利用率并非越高越好：利用率接近100%时，排队时延会急剧增大。

## 5.OSI/RM 七层模型

### 5.1 为什么要分层

- 通信的双方需要“讲”相同的语言，即遵循相同的协议。
- 网络通信过程复杂，分层可以降低复杂性，使各层相对独立。
- 分层便于标准化，任一层的变化不影响其他层的实现。
- 1977年ISO开始制定开放系统互连参考模型，1984年10月发布ISO 7498（即OSI/RM）。

### 5.2 OSI七层模型结构

| 层号 | 名称 | 英文 | 数据单位 |
|------|------|------|---------|
| 7 | 应用层 | Application Layer | 报文（Message），OSI称APDU |
| 6 | 表示层 | Presentation Layer | 报文，OSI称PPDU |
| 5 | 会话层 | Session Layer | 报文，OSI称SPDU |
| 4 | 传输层 | Transport Layer | 报文段（Segment），OSI称TPDU |
| 3 | 网络层 | Network Layer | 分组/包（Packet） |
| 2 | 数据链路层 | Data Link Layer | 帧（Frame） |
| 1 | 物理层 | Physical Layer | 比特（Bit） |

记忆口诀：应表会传网数物（从上到下）。

### 5.3 各层功能详解

| 层 | 功能 | 典型协议或设备 |
|---|------|---------------|
| 应用层 | 为应用程序提供访问网络的接口，直接面向用户业务 | HTTP、FTP、SMTP、DNS、DHCP |
| 表示层 | 进行数据格式转换、加密解密、压缩解压缩，确保一个系统生成的数据能被另一个系统识别 | JPEG、ASCII、SSL/TLS（部分教材归入表示层） |
| 会话层 | 在通信双方之间建立、管理和终止会话，提供同步点 | RPC、NetBIOS |
| 传输层 | 建立、维护和取消端到端的数据传输；进行流量控制、差错控制、分段与重组 | TCP、UDP |
| 网络层 | 定义逻辑地址，进行路由选择，实现数据从源到目的地的转发 | IP、ICMP、IGMP、ARP、路由器 |
| 数据链路层 | 将分组封装成帧；实现点到点或点到多点的直接通信；差错检测与流量控制 | Ethernet、PPP、HDLC、交换机 |
| 物理层 | 在媒介上传输比特流；提供机械、电气、功能和规程特性 | RJ45、光纤、集线器、中继器 |

### 5.4 类比记忆

| 层 | 类比角色 | 职责 |
|---|---------|------|
| 应用层、表示层、会话层 | 领导A | 提出通信需求，决定“说什么” |
| 传输层 | 秘书A | 负责端到端的可靠交付，相当于“门到门” |
| 网络层、数据链路层 | 邮递员A | 负责选择路径并逐站转发，相当于“站到站” |
| 物理层 | 邮政车 | 负责在介质上实际运送比特 |

## 6.TCP/IP 参考模型

### 6.1 概述

TCP/IP协议簇是现代Internet的核心协议，是事实上的工业标准。TCP/IP标准模型为4层，教学中也常用5层（对等模型）。

### 6.2 三种模型对比

```mermaid
flowchart LR
    subgraph M7["OSI 七层模型"]
        direction TB
        O7["7 应用层"] --> O6["6 表示层"] --> O5["5 会话层"] --> O4["4 传输层"] --> O3["3 网络层"] --> O2["2 数据链路层"] --> O1["1 物理层"]
    end

    subgraph M4["TCP/IP 四层模型"]
        direction TB
        T4["应用层"] --> T3["传输层"] --> T2["网际层"] --> T1["网络接口层"]
    end

    O7 -.-> T4
    O6 -.-> T4
    O5 -.-> T4
    O4 -.-> T3
    O3 -.-> T2
    O2 -.-> T1
    O1 -.-> T1
```

核心对应关系：

| TCP/IP模型 | 对应OSI模型 | 主要功能 |
|-----------|------------|---------|
| 应用层 | 应用层 + 表示层 + 会话层 | 面向具体应用，处理数据表示与会话 |
| 传输层 | 传输层 | 端到端的数据传输与控制 |
| 网际层（Internet层） | 网络层 | 逻辑寻址、路由选择、分组转发 |
| 网络接口层 | 数据链路层 + 物理层 | 介质访问、成帧、比特传输 |

TCP/IP五层模型就是把网络接口层拆成数据链路层和物理层，其余与四层模型相同。

## 7.TCP/IP 常见协议与端口

### 7.1 协议栈总览

| 层次 | 主要协议 |
|------|---------|
| 应用层 | HTTP、HTTPS、FTP、TFTP、SMTP、POP3、IMAP4、Telnet、SSH、DNS、DHCP、SNMP、NTP、BGP、RIP、NFS |
| 传输层 | TCP、UDP |
| 网际层 | IP、ICMP、IGMP、ARP、RARP、OSPF |
| 网络接口层 | Ethernet（CSMA/CD）、PPP、HDLC、Frame Relay、ATM |

说明：BGP使用TCP、RIP使用UDP，二者属于应用层协议；OSPF直接封装在IP中（IP协议号89），通常归入网络层。它们的作用都是为网络层提供路由信息。

### 7.2 常用协议与端口号

| 协议 | 端口号 | 传输层 | 说明 |
|------|-------|--------|------|
| FTP | 21（控制）、20（数据） | TCP | 文件传输协议，主动模式下20端口传数据 |
| SSH | 22 | TCP | 安全远程登录 |
| Telnet | 23 | TCP | 远程登录，明文传输 |
| SMTP | 25 | TCP | 简单邮件传输协议，发送邮件 |
| DNS | 53 | UDP（查询）、TCP（区域传送） | 域名解析 |

## 8.发送方数据封装过程

### 8.1 封装与解封装流程

```mermaid
flowchart TB
    A["应用层：DATA"] --> B["传输层：加TCP首部，组成段 Segment"]
    B --> C["网络层：加IP首部，组成包 Packet"]
    C --> D["数据链路层：加帧头与帧尾FCS，组成帧 Frame"]
    D --> E["物理层：转换为比特流 Bit"]
    E --> F["传输介质"]
```

封装顺序（从上到下）：数据 → 段 → 包 → 帧 → 比特。

解封装顺序（从下到上）：比特 → 帧 → 包 → 段 → 数据。

### 8.2 各层首部与数据单位

| 层次 | 增加的首部 | 首部长度 | 主要字段 | 数据单位 |
|------|-----------|---------|---------|---------|
| 传输层 | TCP首部 | 20字节起，最长60字节 | 源端口、目的端口、序号、确认号、标志位、窗口、校验和 | 报文段（Segment） |
| 传输层 | UDP首部 | 8字节 | 源端口、目的端口、长度、校验和 | 用户数据报 |
| 网络层 | IPv4首部 | 20字节起，最长60字节 | 版本、首部长度、总长度、标识、标志、片偏移、TTL、协议、校验和、源IP、目的IP | 分组（Packet） |
| 数据链路层 | 帧头 + 帧尾 | 以太网14字节帧头 + 4字节FCS | 目的MAC、源MAC、类型、FCS | 帧（Frame） |
| 物理层 | 无首部 | — | 前导码、SFD、比特流编码 | 比特（Bit） |

### 8.3 以太网Ⅱ帧格式

| 字段 | 长度 | 作用 |
|------|------|------|
| 前导码 | 7字节 | 收发双方时钟同步，属于物理层 |
| 帧起始定界符SFD | 1字节 | 取值10101011，标志帧的开始 |
| 目的MAC地址 | 6字节 | 接收方硬件地址 |
| 源MAC地址 | 6字节 | 发送方硬件地址 |
| 类型/长度 | 2字节 | 大于0x0600表示上层协议类型，如0x0800为IPv4、0x0806为ARP、0x86DD为IPv6 |
| 数据 | 46~1500字节 | 上层数据；不足46字节时填充 |
| 帧检验序列FCS | 4字节 | CRC-32校验，属于帧尾 |

最小帧长为64字节（不含前导码与SFD），最大为1518字节；插入802.1Q标签后最大为1522字节。

### 8.4 IPv4首部字段

| 字段 | 长度 | 说明 |
|------|------|------|
| 版本 | 4位 | 取值4表示IPv4 |
| 首部长度 | 4位 | 以4字节为单位，最小5即20字节 |
| 区分服务 | 8位 | 服务类型/区分服务，用于QoS |
| 总长度 | 16位 | 首部加数据的总长度，最大65535字节 |
| 标识 | 16位 | 分片时用于识别同一数据报 |
| 标志 | 3位 | DF禁止分片、MF还有分片 |
| 片偏移 | 13位 | 以8字节为单位，指明分片在原数据报中的位置 |
| 生存时间TTL | 8位 | 每经过一个路由器减1，为0时丢弃 |
| 协议 | 8位 | 上层协议号：ICMP为1、IGMP为2、TCP为6、UDP为17、OSPF为89 |
| 首部校验和 | 16位 | 只校验首部，不校验数据 |
| 源IP地址 | 32位 | 发送方地址 |
| 目的IP地址 | 32位 | 接收方地址 |
| 选项与填充 | 可变 | 用于记录路由、时间戳等，填充保证首部为4字节整数倍 |

### 8.5 TCP首部字段

| 字段 | 长度 | 说明 |
|------|------|------|
| 源端口 | 16位 | 发送方端口号 |
| 目的端口 | 16位 | 接收方端口号 |
| 序号 | 32位 | 本报文段数据第一个字节的编号 |
| 确认号 | 32位 | 期望收到的下一个字节编号 |
| 数据偏移 | 4位 | 以4字节为单位，最小5即20字节 |
| 保留 | 4位 | 保留待用，置0 |
| 标志位 | 8位 | CWR、ECE、URG、ACK、PSH、RST、SYN、FIN |
| 窗口 | 16位 | 接收窗口大小，用于流量控制 |
| 校验和 | 16位 | 覆盖首部、数据和伪首部 |
| 紧急指针 | 16位 | URG置1时有效 |
| 选项与填充 | 可变 | MSS、窗口扩大、时间戳、SACK等 |

### 8.6 UDP首部字段

| 字段 | 长度 | 说明 |
|------|------|------|
| 源端口 | 16位 | 发送方端口号 |
| 目的端口 | 16位 | 接收方端口号 |
| 长度 | 16位 | 首部加数据的总长度，最小8字节 |
| 校验和 | 16位 | 覆盖首部、数据和伪首部，IPv4中可置0表示不校验 |

## 10.课堂习题巩固

### 10.1 习题1

无线个域网的蓝牙技术采用802.15.1标准。与无线宽带网络相比，无线个域网具有：低功耗、低传输速率和短距离的特点。

### 10.2 习题2

网络应用需要考虑实时性，以下网络服务中实时性要求最高的是（B）

- A. 基于SNMP协议的网管服务
- B. 视频点播服务 [正确]
- C. 邮件服务
- D. Web服务

解析：视频点播对时延和抖动敏感，需要连续传输；邮件、网管、Web对实时性要求较低。

### 10.3 习题3

在地面上相距1000公里的两地之间通过电缆传输电磁信号，其延迟时间是（C）

- A. 5μs
- B. 10μs
- C. 5ms [正确]
- D. 10ms

计算：传播时延 = 1000km ÷ 200km/ms = 5ms。

### 10.4 习题4

下面的选项中，属于OSI传输层功能的是（A）

- A. 通过流量控制发送数据 [正确]
- B. 提供传输数据的最佳路径（网络层功能）
- C. 提供网络寻址功能（网络层功能）
- D. 允许网络分层

### 10.5 习题5

在OSI参考模型中，（B）在物理线路上提供可靠的数据传输服务。

- A. 物理层
- B. 数据链路层 [正确]
- C. 网络层
- D. 传输层

解析：数据链路层通过帧同步、差错检测和重传，在相邻节点之间提供可靠传输；传输层提供的是端到端的可靠传输。

### 10.6 习题6

在OSI参考模型中，传输层处理的数据单位是（D）

- A. 比特
- B. 帧
- C. 分组
- D. 报文 [正确]

解析：传输层的数据单位在OSI中称报文段（Segment），部分教材统称报文；本题选项中只有“报文”符合。

### 10.7 习题7

TCP/IP协议中传输层的协议有（A），数据从上到下封装的格式为（B）。

- （1）A. TCP [正确]（FTP是应用层，ICMP、IGMP是网际层）
- （2）B. 数据 → 段 → 包 → 帧 → 比特 [正确]
