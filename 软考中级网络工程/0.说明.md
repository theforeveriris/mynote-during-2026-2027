### 2.生产流程

1. **转写**：`course2md` 把视频转成 `course.md`（逐段时间戳 + 逐句文字），产物留在 `C:\Lefts Workspace\创意\wk\notes\`
2. **整理**：按 v1.0 的五条原则重写，但图示改用 Mermaid 重绘，文档中不再出现图片引用
3. **核对**：公式、命令、协议参数、标准编号一律联网核实，课件与标准冲突时按标准写并括注课程口径
4. **两轮校验**：
   - 第一轮：分组审校，逐条核对可验证点，只改确定错误
   - 第二轮：先复核第一轮的修改本身（防止「改对了又改错」），再查跨文件一致性（同一知识点在 18.x、11.x、4.1、19.0 间是否互相矛盾）
5. **索引与提交**：`scripts/build-file-tree.js` 重建站点导航，git 提交推送

### 3.标注约定

| 标注 | 含义 |
| ---- | ---- |
| `[正确]` / `[错误]` | 判断题结论，替代任何图形符号 |
| `[存疑]` | 存在版本差异或资料冲突，未强行定论 |
| `[答案存疑]` | 题库答案与原理判断不符，附原答案与理由 |
| `[原文为图/表，需对照原卷]` | 原始材料为图片，文字无法还原，给出解题方法而非编造数据 |
| `[手写批注]` | 课件上的手写内容，单独标记 |
| `[文字被遮挡]` | 原文被字幕或页边界遮挡，按可见范围记录 |

每份笔记（18.x 起）文末附 `## N.校验记录`，逐条列出「位置 / 原文 / 改为 / 依据」，二轮修改标注「二轮」，可回溯每一次改动。
