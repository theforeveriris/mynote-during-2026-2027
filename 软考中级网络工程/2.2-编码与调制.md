# 编码与调制 · 完整笔记

---

## 1.本节定位与知识框架

编码与调制是「数据通信基础」的第三个板块，排在**通信系统概述**与**信道特性**之后、**差错控制**之前。

在学习之前必须先明确一个问题：**为什么要学编码与调制？**

- 上一节信道容量的最后一道例题已经说明，编码与调制与**信道容量的计算息息相关**，其核心正是**码元种类数与每码元比特数之间的关系**。
- 编码的另一作用是对信号进行变更与转换，以便**适配信道特性的传输**：模拟信号可能需要转换成数字信号后在数字信道中传输，数字信号也可能需要转换成模拟信号后在模拟信道中传输，这一过程会涉及 **A/D 转换**。信号在传输前不断被加工与变换，目的都是更好地完成传输工作。

因此本节只需要抓住两条主线：**一是什么样的编码/调制方式，二是一种方式能承载多少比特（码元种类数）**。

本节的知识框架如下：

| 板块 | 数据与信号的对应 | 核心内容 | 考试地位 |
| ---- | ---------------- | -------- | -------- |
| 数据编码 | 数字数据 → 数字信号 | 曼彻斯特、差分曼彻斯特、RZ/NRZ、MLT-3、mB/nB | 重点，波形判读与效率比较均考 |
| 脉冲编码调制 PCM | 模拟数据 → 数字信号（A/D 转换） | 采样、量化、编码；采样定理 | 计算题常考 |
| 数字调制技术 | 数字数据 → 模拟信号 | ASK、FSK、PSK、DPSK、QPSK、QAM | 重点，码元种类数必考 |

其中「数据编码」「数字调制技术」两处为本节重点；上述框架中标注为高频考点的是「通信系统的分类」「信道容量计算」「数据编码」「数字调制技术」「CRC」。

## 2.数据编码基础

### 2.1 曼彻斯特编码

曼彻斯特编码与差分曼彻斯特编码都属于**双相码**，是常规考试中最常出现的两类编码。

**基本思想**：不用电平的高低直接表示 0 和 1，而是用**码元中间的电平跳变**来表示比特。

曼彻斯特编码存在**两套并行的定义标准**，两种标准的跳变方向恰好相反：

| 标准 | 提出者 / 出处 | 比特 0 | 比特 1 |
| ---- | ------------- | ------ | ------ |
| 标准曼彻斯特编码 | 由 G.E. Thomas 提出 | 低电平 → 高电平 | 高电平 → 低电平 |
| 曼彻斯特编码（以太网标准） | IEEE 802.3 规定 | 高电平 → 低电平 | 低电平 → 高电平 |

两套约定本质上是**互为反相**：把其中一套的波形整体取反，就得到另一套。因此只看波形无法确定比特串，必须先确认采用的是哪一套标准。

以比特串 `1 0 1 1` 为例，两套标准的电平规则如下（每比特分为前半、后半两个电平，中点必跳变）：

| 标准 | 第 1 位（1） | 第 2 位（0） | 第 3 位（1） | 第 4 位（1） |
| ---- | ------------ | ------------ | ------------ | ------------ |
| IEEE 802.3（0 高→低，1 低→高） | 低 → 高 | 高 → 低 | 低 → 高 | 低 → 高 |
| Thomas（0 低→高，1 高→低） | 高 → 低 | 低 → 高 | 高 → 低 | 高 → 低 |
| 中点跳变方向 | 上升 | 下降 | 上升 | 上升 |

结论：

- 曼彻斯特编码**依靠电平跳变表示比特**，但**跳变方向并不唯一**，取决于采用哪一套标准。
- 正因为存在两套标准，单独给出一段曼彻斯特波形**无法唯一确定**比特串，考试中必须借助差分曼彻斯特编码配合判断。
- 每个码元的中点必定发生一次跳变，因此编码自带时钟信息，可**自同步**。
- 每个比特固定用两个电平（两个码元）表示，故**波特率 = 2 × 比特率**，编码效率为 **50%**；同时高低电平各占一半，**无直流分量**。

### 2.2 差分曼彻斯特编码

差分曼彻斯特编码不看比特对应哪一种电平状态，而是看**每个比特前沿（码元起始处）是否发生电平跳变**：

| 判据 | 规则 |
| ---- | ---- |
| 比特前沿**不跳变** | 表示比特 **1** |
| 比特前沿**发生跳变** | 表示比特 **0** |

即口诀：**遇 0 翻转，遇 1 不变**。（无论比特为何值，码元中点仍必定跳变一次，用于同步。）

需要注意，差分曼彻斯特同样存在两套相反的约定：

| 约定 | 比特 0 | 比特 1 | 常见出处 |
| ---- | ------ | ------ | -------- |
| 约定一（本节采用） | 前沿跳变 | 前沿不跳变 | IEEE 802.5 令牌环 |
| 约定二 | 前沿不跳变 | 前沿跳变 | 部分教材 |

考试中若题干给出了参考波形或已判定出一位，就按波形实际跳变判断，不要死记某一套；两种约定都保持「中点必跳变」。

以课件波形（待传送比特为 `1 0 1 1`，起始参考电平为低电平）为例：

| 码元 | 比特 | 前沿是否跳变 | 码元起始电平 | 中点跳变后电平 |
| ---- | ---- | ------------ | ------------ | -------------- |
| 第 1 位 | 1 | 不跳变 | 低 | 高 |
| 第 2 位 | 0 | 跳变 | 低（由高翻下） | 高 |
| 第 3 位 | 1 | 不跳变 | 高 | 低 |
| 第 4 位 | 1 | 不跳变 | 低 | 高 |

课件在第 4 位处留下问号要求补全波形：第 4 位为 1，与上一码元末尾电平相同，**前沿不跳变**，沿用原有电平并在中点跳变一次即可。

判断波形的通用方法：

1. 从**第 2 位**开始逐位判断，因为第 1 位前面没有参照码元，无法判断。
2. 比较当前码元前沿与前一码元末尾：电平不同即「有跳变」，电平相同即「无跳变」。
3. 有跳变为 0，无跳变为 1。

### 2.3 归零码与不归零码

两者的区别在于**码元中间是否回到零电平**：

| 编码 | 特征 | 电平约定 | 优缺点 |
| ---- | ---- | -------- | ------ |
| 归零码（RZ） | 码元中间信号**回归到 0 电平** | 本课件约定：正极表示 0，负极表示 1 | 自带电平跳变、可自同步；占用带宽大 |
| 不归零码（NRZ） | 码元中间**不回归 0 电平**，直接保持到码元结束 | 见下 | 带宽利用率高；不能自同步，长串 0 或 1 时失去定时 |

归零码的极性约定并不唯一：本课件取「正 = 0、负 = 1」，多数教材取「正 = 1、负 = 0」，做题时以题干给出的波形或约定为准，关键是「码元中间必须回到 0」。

以比特串 `1 0 1 1` 为例，三种编码的逐位电平如下（每个比特分为前半、后半）：

| 编码 | 第 1 位（1） | 第 2 位（0） | 第 3 位（1） | 第 4 位（1） |
| ---- | ------------ | ------------ | ------------ | ------------ |
| RZ（通用约定 1 = +V、0 = −V） | +V，0 | −V，0 | +V，0 | +V，0 |
| NRZ-L（1 = 高，0 = 低） | 高，高 | 低，低 | 高，高 | 高，高 |
| NRZ-I（遇 1 翻转，初始为低） | 高，高 | 高，高 | 低，低 | 高，高 |

通俗理解：归零码像「站起来打招呼后又坐下」，打完招呼必须回到原位；不归零码则是「站起来后一直不坐下」，电平保持到下一个码元。

不归零码在发展过程中形成两类，需注意区分：

| 类型 | 名称 | 规则 |
| ---- | ---- | ---- |
| NRZ-I | 翻转不归零码（Invert） | **遇 1 电平翻转，遇 0 电平不翻转** |
| NRZ-L | 电平不归零码（Level） | **低电平表示 0，高电平表示 1** |

- NRZ-I 的判断依据是「相对上一个状态是否翻转」，与绝对电平无关。
- 4B/5B 编码在实现时，正是与 **NRZ-I** 配合使用。

### 2.4 MLT-3 编码

MLT-3 是在 NRZ-I 基础上进一步变化而来的编码，其电平在 **+V、0、−V 三个级别**之间跳转，因此判断规则比 NRZ-I 更复杂。

编码规则：

- 如果下一比特是 **0**，则输出值与前面的值**相同**；
- 如果下一比特是 **1**，则输出值**必须发生转变**，具体分为两种情况：
  - 如果前面输出的值是 **+V 或 −V**，则下一输出为 **0**；
  - 如果前面输出的值是 **0**，则下一输出的值与**上一个非 0 值符号相反**。

也就是说，遇到 1 时要「多看一眼」：前值非零则回到零，前值为零则要看更前面那个非零值的符号，取相反方向。可概括为「一步三回头」。

**逐位演算示例**：设初始电平为 0，此前最近一个非零电平为 −V，待传送比特为 `1 0 1 1 0`：

| 比特 | 规则运用 | 输出电平 |
| ---- | -------- | -------- |
| 1 | 前值为 0，取上一非零值（−V）的相反符号 | +V |
| 0 | 遇 0 不变化 | +V |
| 1 | 前值为 +V，回到零 | 0 |
| 1 | 前值为 0，取上一非零值（+V）的相反符号 | −V |
| 0 | 遇 0 不变化 | −V |

即波形依次为 `+V、+V、0、−V、−V`。

补充：

- MLT-3 每个码元只承载 1 bit，本身编码效率为 **100%**；在 100Base-TX 中它与 4B/5B 串联使用（4 bit → 5 个 MLT-3 码元），整体效率为 **80%**。
- 由于电平在 +V、0、−V 之间循环跳变，信号能量集中在较低频率，最高基频约为比特率的 1/4，可减少铜缆上的高频损耗与电磁干扰，这是它用于 100Base-TX 的原因。

### 2.5 mB/nB 编码

mB/nB 编码是一类**分组编码**：把 m 位有效信息映射为 n 位（或 n 个）线路码元后再传输，多出的部分用于同步、控制或直流平衡。

编码效率的通用定义：

```
编码效率 = 有效信息位数 ÷ 线路码元所占的位数（或符号携带的信息量）
```

**4B/5B**：

- 用 **5 位代码表示 4 位有效信息**。
- 编码效率 = 4 ÷ 5 = **80%**。
- 与**不归零编码（NRZ-I）配合使用**，用于 100Base-FX、100Base-TX 与 FDDI。

可以这样理解：一个包裹里只有 4 件物品是真正有用的，另 1 位相当于保护措施或控制信息。

**8B/10B**：

- 用 **10 位代码表示 8 位有效信息**。
- 编码效率 = 8 ÷ 10 = **80%**。
- 用于 **1000BASE-X**（1000BASE-SX/LX/CX）、10GBASE-X、光纤通道，以及 PCIe、SATA、USB 3.0 等高速串行接口。
- 注意：**1000BASE-T 与 1000BASE-TX 采用 4D-PAM5，不使用 8B/10B**，这是常见混淆点。

**8B/6T**：

- 用 **6 个三进制码元表示 8 位有效信息**（3⁶ = 729 > 2⁸ = 256，冗余码组可用于同步与直流平衡）。
- 每个三进制码元携带 log₂3 ≈ 1.585 bit，6 个码元共可承载约 9.51 bit，故编码效率 = 8 ÷ (6 × log₂3) ≈ **84%**。
- 用于 **100Base-T4**，了解即可。

### 2.6 各类编码方式及其效率汇总

| 编码方案 | 说明 | 效率 | 典型应用 |
| -------- | ---- | ---- | -------- |
| 曼码 | 每 1 bit 用 2 个码元（前半、后半电平）表示，波特率 = 2 × 比特率，可自同步、无直流分量 | 50% | 10M 以太网（10BASE-T） |
| 差分曼码 | 同样每 1 bit 用 2 个码元，判据是码元前沿是否跳变 | 50% | 令牌环网 |
| **mB/nB 编码：4B/5B** | 用 5 位代码表示 4 位有效信息；与不归零编码（NRZ-I）配合使用 | 80% | 100Base-FX、100Base-TX（MLT-3）、FDDI |
| **mB/nB 编码：8B/10B** | 用 10 位代码表示 8 位有效信息 | 80% | 1000BASE-X、10GBASE-X、光纤通道 |
| **mB/nB 编码：8B/6T** | 用 6 个三进制码元表示 8 位有效信息（3⁶ = 729 种组合，选用 256 种） | 约 84% | 100Base-T4 |

补充说明：

- 曼码效率为 50% 的由来：每传输 1 bit 需要占用 2 个码元（前半比特与后半比特各一个电平），波特率是比特率的 2 倍，故效率为 1/2。
- 4B/5B 效率为 80% 的由来：4 位有效信息 / 5 位总长。
- 8B/10B 的编码效率与 4B/5B 同为 80%（10 位代码中 8 位为有效信息）。
- 考试中**只需关注编码效率与典型应用**，不需要判断这些编码的波形。考查频度集中在表格的前三行（曼码、差分曼码、4B/5B）。

**关于典型应用的命名规则**：`100Base-FX` 这一名称本身由三部分组成——**速率**（100 表示 100 Mbps）、**传输方式**（Base 表示基带传输）、**传输介质**（FX 表示光纤、TX 表示双绞线）。因此后续局域网章节中，同一类名称既可能考查编码方式，也可能考查传输介质、传输速率。

**百兆以太网内部的编码区别（重点）**：

| 标准系列 | 编码流程 |
| -------- | -------- |
| 100Base-FX 等（X 系列） | 先做 **4B/5B** 编码，再进行 **NRZ-I** 编码 |
| 100Base-TX 等（TX 系列） | 先做 **4B/5B** 编码，再进行 **MLT-3** 编码 |

二者的差别仅在第二步的线路编码方式，这一对比在题型中曾经出现，需要重点记忆。

## 3.数据编码习题

### 3.1 习题1：由波形判读比特串

**题干**：某段数据同时采用曼彻斯特编码和差分曼彻斯特编码传输，其中差分曼码各位前沿与前一码元交界处的跳变情况见下表，实际传送的比特串为（ ）。

- A、10101100
- B、01110010
- C、01010011
- D、10001101

**解题思路**：

曼彻斯特编码存在两套定义标准，单看曼码波形无法唯一确定比特串，因此必须以**差分曼彻斯特编码**为主要判断依据。

差分曼码的规则是**遇 0 翻转、遇 1 不变**，即看每个码元前沿与前一码元末尾之间是否跳变。第 1 位前面没有参照码元，无法判断，从第 2 位开始逐位判断：

| 码元位次 | 与前一码元交界处 | 判定结果 |
| -------- | ---------------- | -------- |
| 第 1 位 | 无前一位可参照 | 暂不能判定 |
| 第 2 位 | 无跳变 | 1 |
| 第 3 位 | 有跳变 | 0 |
| 第 4 位 | 无跳变 | 1 |
| 第 5 位 | 有跳变 | 0 |
| 第 6 位 | 有跳变 | 0 |
| 第 7 位 | 无跳变 | 1 |
| 第 8 位 | 无跳变 | 1 |

于是得到 `?1010011`，与选项逐位比对，只有 **C、01010011** 符合（即第 1 位为 0）。

**答案：C**

**延伸结论**：确定比特串后，再回看曼彻斯特编码波形——第 1 位为 0 时波形由高电平跳变到低电平，可知本题采用的是 **IEEE 802.3 的规定：0 为高→低、1 为低→高**。因此两类波形结合判断，可以同时确定比特串与曼码所采用的标准。

### 3.2 习题2：10BASE-T 的编码方式

**题干**：以太网 10BASE-T 采用的编码方式是（ ）。

- A、差分曼彻斯特编码
- B、4B/5B 编码
- C、归零编码
- D、曼彻斯特编码

**解析**：按各编码的典型应用逐一排除：

| 编码 | 典型应用 |
| ---- | -------- |
| 曼彻斯特编码 | 10M 以太网（10BASE-T） |
| 差分曼彻斯特编码 | 令牌环网 |
| 4B/5B | 百兆以太网（100Base-FX、100Base-TX 等） |
| 8B/10B | 千兆以太网 |

此外，4B/5B 属于 mB/nB 分组编码，需与不归零编码（NRZ-I）配合使用，与「归零编码」无关。

**答案：D**

### 3.3 习题3：编码效率的比较

**题干**：以下编码中，编码效率最高的是（ ）。（2021 年上半年真题）

- A、BAMI
- B、曼彻斯特编码
- C、4B5B
- D、NRZI

**解析**：编码效率即「有效信息位数 ÷ 码元占用的位数」。

| 编码 | 效率 | 说明 |
| ---- | ---- | ---- |
| 曼彻斯特编码 | 50% | 1 bit 需要 2 次电平状态变化 |
| 4B/5B | 80% | 4 位有效信息占用 5 位 |
| NRZI（不归零编码） | **100%** | 一个电平状态对应一个比特，一对一，全部为有效数据 |

易错点：看到 4B/5B 的 80% 容易直接选 C，但 NRZI 的效率为 100%，高于 80%。

补充：BAMI（双极性交替传导反转，即 AMI）同样是 1 比特对应 1 个码元，按定义效率也是 100%。本题为早年真题，标准答案取 NRZI；应试时按「曼码 50%、4B/5B 80%、NRZI 100%」这一组结论记忆即可。

**答案：D**

### 3.4 习题4：MLT-3 波形判读

**题干**：某段 100BASE-TX 标准中 MLT-3 编码的波形，7 个码元区间的电平依次为 `−、0、+、0、−、0、+`，其传送的信息编码为（ ）。

- A、1111111
- B、0000000
- C、0101010
- D、1010101

**解题思路**：

MLT-3 的规则是：遇 0 电平不变，遇 1 电平必变（前值非零则回到 0，前值为 0 则取上一非零值的相反符号）。因此**判断依据是相邻码元的电平是否发生变化**：变化对应 1，不变化对应 0。

波形在 7 个码元区间上的电平依次为：`−、0、+、0、−、0、+`。

| 码元位次 | 电平 | 与前一码元相比 | 判定结果 |
| -------- | ---- | -------------- | -------- |
| 第 1 位 | − | 无前一参考电平 | 暂不能判定 |
| 第 2 位 | 0 | 变化 | 1 |
| 第 3 位 | + | 变化 | 1 |
| 第 4 位 | 0 | 变化 | 1 |
| 第 5 位 | − | 变化 | 1 |
| 第 6 位 | 0 | 变化 | 1 |
| 第 7 位 | + | 变化 | 1 |

每一个码元都与前一码元电平不同，即一直是「遇 1 跳变」的状态，故全部为 1。第 1 位虽无法单独判定，但四个选项中只有 A 满足后 6 位全为 1。

**答案：A**

## 4.脉冲编码调制（PCM）

### 4.1 基本概念与三个步骤

PCM（Pulse Code Modulation，脉冲编码调制）严格来说是一种**调制**技术，但在功能上属于**信源编码**手段，其作用是把**模拟信号转换成数字信号**，即完成 **A/D 转换**（A 为 Analog，D 为 Digital）。

原始的模拟信号在时间和幅度上都是连续的，要变成离散的数字形式，需要依次完成三个步骤：

| 步骤 | 作用 | 说明 |
| ---- | ---- | ---- |
| **采样（抽样）** | 在时间上离散化 | 每隔相同的时间间隔取一个点，该间隔称为**采样间隔** |
| **量化** | 在幅度上离散化 | 把采样得到的连续数值按等级取整（四舍五入），**必然产生误差** |
| **编码** | 变成二进制码组 | 把量化后的等级值用二进制码组表示，输出 0/1 序列 |

三个步骤的先后关系与数据形态变化：

```mermaid
flowchart LR
    A["模拟信号：时间连续、幅度连续"] --> B["采样：时间离散化"]
    B --> C["量化：幅度离散化，产生量化误差"]
    C --> D["编码：每个样本转为 n 位二进制码组"]
    D --> E["PCM 信号：数字信号送入信道"]
```

课件示例：原始波形上按等间隔采得 3.2、3.9、2.8、1.2、3.4 等值；量化后取整为 3、4、3、1、3；再编码为二进制码组（如 3 → `011`、4 → `100`、1 → `001`），即可送入数字信道传输。

### 4.2 采样定理

采样间隔决定了接收端能否**有效还原**原来的模拟信号。

如果采样间隔过大，采样点过于稀疏，接收端只能把相邻采样点直接相连，还原出的波形将严重失真（峰值与低谷都可能消失），无法恢复原始信号。

因此采样必须满足**奈奎斯特采样定理**：

```
采样频率 fs ≥ 2 × 模拟信号的最高频率 fmax
```

- 采样频率即采样间隔的倒数：`fs = 1 / T`。
- 只要采样频率不低于最高频率的 2 倍，样本就能无失真地恢复原信号。
- 注意：判据是**最高频率**，不是频率范围的上、下限之差。
- 说明：以上是软考采用的**低通采样定理**。若信号是严格限带的带通信号（如 4 ~ 8 MHz），理论上可用带通采样把所需频率降到 2 倍带宽，但软考不考这一情形，答题一律以 `2 × fmax` 为准。

### 4.3 量化与编码

- 量化把幅度上连续的采样值映射到有限个离散等级，等级数记为 N，通常取 2 的整数次幂；相邻等级之差称为**量化间隔（量化台阶）**。
- 每个样本需要编码的比特数为：

```
每样本比特数 n = log₂N
```

| 量化方式 | 做法 | 特点 |
| -------- | ---- | ---- |
| 均匀量化 | 各量化间隔相等 | 实现简单；小信号时相对误差大、信噪比低 |
| 非均匀量化 | 大信号量化间隔大、小信号量化间隔小 | 小信号信噪比高，话音信号采用；工程上用压扩实现（我国采用 A 律 13 折线） |

- 量化级数越多，量化误差越小，但每样本所需比特数越多。
- 量化误差（量化噪声）是 PCM 固有的，只能减小、不能消除。
- 话音 PCM 采用 8 位编码：1 位极性码 + 3 位段落码 + 4 位段内码，共 2⁸ = 256 个量化级；采样频率 8 kHz 时，一路话音的 PCM 速率为 8 × 8 = **64 kb/s**。

### 4.4 PCM 系统框图

| 方向 | 处理流程 |
| ---- | -------- |
| 编码（发送端） | 模拟信号输入 → 抽样保持 → 量化 → 编码 → PCM 信号输出 |
| 译码（接收端） | PCM 信号输入 → 译码 → 低通滤波 → 模拟信号输出 |

PCM 系统的三个要点：

1. **过程**：采样、量化与编码；
2. **传输**：编码输出为数字基带信号；实际系统常再与时分复用（TDM）结合，把多路 PCM 话音装入同一帧（如 E1 的 32 个时隙）；
3. **采样频率应大于等于模拟信号最高频率的 2 倍**。

### 4.5 话音信号的 8 kHz 与 125 μs

话音信号的频率范围为 **300 Hz ~ 3400 Hz**，最高频率为 3400 Hz。按采样定理，采样频率应大于 2 × 3400 = 6800 Hz，工程上取整为 **8000 Hz（8 kHz）**。

由此得到采样间隔：

```
T = 1 / fs = 1 / 8000 s = 125 μs
```

这两个数值（**8 kHz** 与 **125 μs**）在后续计算题中反复出现，凡涉及话音模拟信号与 PCM，基本都离不开它们。

若每样本按 8 位编码，则一路话音的 PCM 速率为 `8000 × 8 = 64 kb/s`，这正是数字电话系统中一个标准话路（DS0、E1 的一个时隙）的速率。

## 5.PCM 习题

### 5.1 习题1：采样频率的取值

**题干**：假设模拟信号的频率范围为 4 ~ 8 MHz，采样频率必须大于（ ）时，才能使得得到的样本信号不失真。

- A、4 MHz
- B、8 MHz
- C、12 MHz
- D、16 MHz

**解析**：采样定理要求采样频率不低于**最高频率**的 2 倍。本题最高频率为 8 MHz，而非频率范围的宽度 4 MHz。

```
fs ≥ 2 × fmax = 2 × 8 MHz = 16 MHz
```

易错点：直接用 8 − 4 = 4 MHz 去乘以 2 得到 8 MHz，属于把「最高频率」错当成「频率范围宽度」。

**答案：D**

### 5.2 习题2：PCM 数据速率的计算

**题干**：设信道带宽为 3400 Hz，采用 PCM 编码，采样周期为 125 μs，每个样本量化为 128 个等级，则信道的数据速率为（ ）。

- A、10 Kb/s
- B、16 Kb/s
- C、56 Kb/s
- D、64 Kb/s

**解析**：本题给的是采样周期与量化等级，要求数据速率，本质仍是信道容量的计算——码元速率取采样频率，每码元比特数取 log₂N。

第一步，由采样周期求采样频率：

```
fs = 1 / T = 1 / 125 μs = 8000 Hz = 8 kHz
```

第二步，求每个样本的比特数：

```
n = log₂128 = 7 bit
```

第三步，求数据速率：

```
R = fs × n = 2W × log₂N
  = 8000 × 7
  = 56000 b/s = 56 kb/s
```

**答案：C**

## 6.数字调制技术

### 6.1 基本概念

**数字调制**：把数字数据调制成模拟信号，在模拟信道中进行数据传输。

实际信道中传输的往往是连续的正弦波，因此需要把 0/1 序列「搬移」到载波上，这一过程称为**频谱搬移**。载波是用于承载信息的高频正弦波，把基带信息搬到载波上，就实现了数字到模拟的转换。

数字调制同样考查**码元与比特数的关系**：一种调制方式能区分多少种码元形态，就决定了每个码元能携带多少比特。

### 6.2 载波的三要素

载波信号的标准表达式为：

```
c(t) = A · sin(2πf·t + φ)
```

| 参数 | 名称 | 物理含义 | 对应的调制方式 |
| ---- | ---- | -------- | -------------- |
| A | 振幅 | 波形的「高度」，取值大小决定波的幅度 | ASK |
| f | 频率 | 单位时间内波形重复的次数，决定波的疏密 | FSK |
| φ | 相位 | 波形在时间轴上的平移量（偏移） | PSK |
| t | 时间 | 横轴 | — |

三要素对应三种基本调制方式，这正是 ASK、FSK、PSK 名称的由来。

### 6.3 ASK（幅移键控）

- 用**不同的振幅**表示 0 和 1。
- 课件波形中：比特为 1 时有正弦波（有振幅），比特为 0 时振幅为零（相当于无信号）。这种「有载波 / 无载波」的形式又叫 **OOK（通断键控）**，是 2ASK 的特例。
- 特点：实现简单、**抗干扰性差**、效率低。
- 原因：只要波形稍有振动或幅度偏移，就难以判断该码元究竟是 0 还是 1。

### 6.4 FSK（频移键控）

- 用**不同的频率**表示 0 和 1。
- 课件波形中：比特为 1 时波形密集（一个码元内有多个周期），比特为 0 时波形稀疏（只有一个周期）。
- 特点：**抗干扰性较 ASK 更强，但占用带宽较大**。

### 6.5 PSK 与 DPSK（相移键控）

**PSK（相移键控）**：

- 用**不同的相位**表示 0 和 1。
- 课件的 2PSK 波形中，0 与 1 的载波相位相差 **180°**（波形上下颠倒）。
- 特点：**抗干扰性最好**，且相位的变化可以作为**定时信息来同步时钟**。

**DPSK（差分相移键控）**：

- 用**相邻码元载波相对相位是否变化**来表示比特。
- 一般规定：**1 表示相对相位改变，0 表示相对相位不改变**；反向约定（0 变、1 不变）也有教材采用，做题以题干为准。
- 与 PSK 的区别：PSK 是「固定相位对应固定比特」，DPSK 是「看变化与否」。
- 差分的好处：接收端不需要恢复载波的绝对相位，可避免相位模糊问题。

| 调制方式 | 判据 |
| -------- | ---- |
| 2PSK | 绝对相位：一种相位代表 1，另一种相位代表 0 |
| 2DPSK | 相对相位：与前一码元相比，变化为 1，不变为 0 |

### 6.6 幅度与相位的联合调制

除上述基本方式外，还有 QPSK、4DPSK、QAM 等，本质是对载波**幅度、相位（以及频率）**的不同组合：

- **4DPSK**：四差分相移键控，每 **90°** 表示一种状态，共 4 种码元。
- **QPSK**：正交相移键控，同样每 **90°** 表示一种状态，共 4 种码元。
- **QAM**：正交幅度调制，**幅度和相位同时变化**，可组合出更多码元形态，频带利用率高于同阶 PSK。
- 注意抗干扰性的正确说法：在**阶数相同**且平均功率相同的条件下，QAM 星座点的最小距离大于 PSK（如 16QAM 优于 16PSK），抗噪声性能更好；但**阶数越高、点越密，抗干扰能力越差**，所以 256QAM 只适合信噪比高的信道（如 5G、Wi-Fi 的高阶调制档位）。

可以类比穿衣搭配：只换上衣只有几种组合，上衣、裤子、配饰同时更换，组合数会成倍增加。参数组合越多，可用的码元种类越多，每个码元携带的比特也越多。

4 种码元正好对应两位二进制数的四种组合（00、01、10、11），所以 4DPSK 与 QPSK 的每码元比特数为 2。

考试中常直接给出阶数，例如 16QAM、64QAM、256QAM，此时码元种类数就是其阶数，比特数用 **2 的 n 次方**反推：

```
N = 2ⁿ，则 n = log₂N
```

| 调制方式 | 码元种类数 N | 每码元比特数 n |
| -------- | ------------ | -------------- |
| 2ASK / 2FSK / 2PSK / 2DPSK | 2 | 1 |
| 4DPSK / QPSK | 4 | 2 |
| 16QAM | 16 | 4 |
| 64QAM | 64 | 6 |
| 128QAM | 128 | 7 |
| 256QAM | 256 | 8 |

### 6.7 数字调制技术考试要点

调制技术影响**码元种类数**，进而决定**信道容量的计算**。

| 调制技术 | 说明 | 码元种类 | 比特位 |
| -------- | ---- | -------- | ------ |
| ASK | 不同的振幅来表示 0 和 1；实现简单、抗干扰性差、效率低 | 2 | 1 |
| FSK | 不同的频率来表示 0 和 1；抗干扰性较 ASK 更强，但占用带宽较大 | 2 | 1 |
| PSK | 不同的相位来表示 0 和 1；抗干扰性最好，且相位的变化可以作为定时信息来同步时钟 | 2 | 1 |
| 2DPSK | 相邻码元载波相对相位是否变化；一般 1 表示相对相位改变，0 表示相对相位不改变 | 2 | 1 |
| 4DPSK | 四差分相移键控，每 90° 表示一种状态 | 4 | 2 |
| QPSK | 正交相移键控，每 90° 表示一种状态 | 4 | 2 |
| QAM | 正交幅度调制，幅度与相位联合变化；码元种类数由阶数决定（如 16QAM 为 16 种） | 依阶数而定 | log₂N |

记忆要点：

- **基本调制方式（ASK、FSK、PSK、2DPSK）都是 2 种码元、1 比特**。
- **带「4」或「Q」的（4DPSK、QPSK）都是 4 种码元、2 比特**。
- **QAM 看阶数**：阶数就是码元种类数，比特数为其以 2 为底的对数。

## 7.数字调制习题

### 7.1 习题1：QPSK 的最大速率

**题干**：传输信道带宽为 6 MHz，采用 QPSK 调制，支持的最大速率为（ ）Mbps。

- A、12
- B、16
- C、24
- D、32

**解析**：本题考查调制方式与信道容量的结合，用奈奎斯特定理。

注：课件上该题的原始版本只给出调制方式而未给出带宽，无法求解；补上「信道带宽 6 MHz」这一条件后才可计算，因此读题时必须确认条件是否完整。

QPSK 的码元种类数 N = 4，故：

```
R = 2W · log₂N
  = 2 × 6 × log₂4
  = 2 × 6 × 2
  = 24 Mbps
```

**答案：C**

要点：QPSK 的 N 为 **4**（不是 2），log₂4 = 2，切勿把 QPSK 与 PSK 混淆。

### 7.2 习题2：异步通信中的码元速率

**题干**：在异步通信中，每个字符包含 1 位起始位、7 位数据位、1 位奇偶位和 1 位终止位，每秒钟传送 100 个字符，采用 DPSK 调制，则码元速率为（ ）。

- A、200 波特
- B、500 波特
- C、1000 波特
- D、2000 波特

**解析**：本题问的是**码元速率（波特率）**，而不是有效数据速率，因此一个字符中的 10 位全部都要计入。

第一步，求每个字符的总位数：

```
1（起始位）+ 7（数据位）+ 1（奇偶位）+ 1（终止位）= 10 bit
```

第二步，求比特率：

```
比特率 = 10 bit/字符 × 100 字符/秒 = 1000 b/s
```

第三步，把比特率换算为码元速率：

```
DPSK 的码元种类数 N = 2，每码元携带 log₂2 = 1 bit
码元速率 = 比特率 ÷ log₂N = 1000 ÷ 1 = 1000 Baud
```

**答案：C**

易错点：若按「有效数据位」计算，会用 7 × 100 = 700 b/s，既不是正确比特率，也不是本题所问；本题问的是线路上的码元速率，起始位、校验位、终止位同样要占码元。

### 7.3 习题3：256QAM 的每码元比特数

**题干**：5G 采用的正交振幅调制技术中，256QAM 的一个载波上可以调制（ ）比特信息。

- A、2
- B、4
- C、6
- D、8

**解析**：QAM 的阶数即码元种类数 N，比特数为：

```
n = log₂N = log₂256
2⁷ = 128，2⁸ = 256
n = 8
```

**答案：D**

### 7.4 习题4：由信道容量反推调制方式

**题干**：若采用 QAM 调制的无噪声理想信道带宽为 2 MHz，最大数据传输速率为 28 Mbps，则该信道采用的调制方式是（ ）。

- A、QAM-128
- B、QAM-64
- C、QAM-32
- D、QAM-16

**解析**：题干强调「无噪声理想信道」，提示使用奈奎斯特定理；已知速率与带宽，反求码元种类数。

```
R = 2W · log₂N
28 = 2 × 2 × log₂N
log₂N = 28 ÷ 4 = 7
N = 2⁷ = 128
```

即该信道采用 **QAM-128**。

**答案：A**

要点：这类题只是把公式反过来用，已知 R、W 求 N，本质仍是信道容量计算。

### 7.5 习题5：TDM 复用后的样本率与数据速率

**题干**：8 条模拟信道采用 TDM 复用成 1 条数字信道，TDM 帧的结构为 8 字节加 1 比特同步开销（每条模拟信道占 1 个字节）。若模拟信号频率范围为 10 ~ 16 kHz，样本率至少为（1）样本/秒，此时数字信道的数据速率为（2）Mbps。

（1）A、8k　B、10k　C、20k　D、32k

（2）A、0.52　B、0.65　C、130　D、2.08

**解析**：

第一步，求样本率（采样频率）。判据是最高频率 16 kHz，而不是 10 kHz，也不是范围宽度 6 kHz：

```
fs ≥ 2 × fmax = 2 × 16 kHz = 32 kHz = 32000 样本/秒
```

故（1）选 **D、32k**。

第二步，求一帧的比特数。帧内 8 个字节正好对应 8 条模拟信道各 1 字节，**不要重复乘 8**：

```
1 字节 = 8 bit
8 字节 = 64 bit
帧长 = 64 + 1（同步开销）= 65 bit
```

第三步，求数据速率。每秒 32000 个样本，每个样本（帧）携带 65 bit：

```
R = 32000 × 65 = 2 080 000 b/s = 2.08 Mbps
```

故（2）选 **D、2.08**。

**答案：（1）D　（2）D**

易错点：

- 样本率只看**最高频率**，不要用 16 − 10 = 6 kHz。
- 8 字节本身已经包含 8 条模拟信道的信息，若再乘一次 8 就会重复计算。
- 同步开销的 1 bit 不能漏掉。

## 8.本章小结

| 知识点 | 核心内容 |
| ------ | -------- |
| 1. 曼彻斯特编码 | 用码元中点的电平跳变表示比特；标准曼码（G.E. Thomas）：0 低→高、1 高→低；IEEE 802.3：0 高→低、1 低→高；效率 50%，用于 10M 以太网 |
| 2. 差分曼彻斯特编码 | 看比特前沿是否跳变：遇 0 翻转、遇 1 不变；中点仍必跳变；效率 50%，用于令牌环网 |
| 3. 归零码与不归零码 | RZ 码元中间回到 0 电平；NRZ 不回到 0；NRZ-I 遇 1 翻转遇 0 不变，NRZ-L 低电平 0 高电平 1 |
| 4. MLT-3 | 三电平（+V、0、−V）；遇 0 不变，遇 1 必变（前值非零回 0，前值为 0 则取上一非零值反号）；用于 100Base-TX |
| 5. mB/nB 编码 | 4B/5B：5 位表 4 位，效率 80%，配合 NRZ-I；8B/10B：10 位表 8 位，效率 80%，用于 1000BASE-X、10GBASE-X、光纤通道（1000BASE-T 用 4D-PAM5，不用 8B/10B）；8B/6T：6 个三进制码元表 8 位，效率约 84%，用于 100Base-T4 |
| 6. 编码的应用区分 | 100Base-FX 系列：4B/5B + NRZ-I；100Base-TX 系列：4B/5B + MLT-3 |
| 7. PCM 三步骤 | 采样（时间离散）→ 量化（幅度离散，有误差）→ 编码（二进制码组） |
| 8. 采样定理 | fs ≥ 2·fmax；判据是最高频率，不是频率范围宽度 |
| 9. 话音信号参数 | 300 ~ 3400 Hz，取 fs = 8 kHz，采样间隔 T = 125 μs |
| 10. 载波三要素 | c(t) = A·sin(2πf·t + φ)；A 对应 ASK，f 对应 FSK，φ 对应 PSK |
| 11. 基本调制方式 | ASK 抗干扰差；FSK 抗干扰较强但占带宽；PSK 抗干扰最好且可提取定时信息；DPSK 看相对相位变化（1 变、0 不变） |
| 12. 码元种类与比特 | 2ASK/2FSK/2PSK/2DPSK 为 2 种码元 1 bit；4DPSK/QPSK 为 4 种码元 2 bit；16QAM 4 bit；64QAM 6 bit；256QAM 8 bit |
| 13. 速率计算通式 | R = 2W·log₂N；PCM 中即 R = fs × log₂N |
| 14. 编码效率档位 | 曼码、差分曼码 50%；4B/5B、8B/10B 80%；8B/6T 约 84%；NRZ、NRZ-I、NRZ-L、AMI 100%；效率 = 有效信息位数 ÷ 码元占用位数 |

考试重点：

1. **两类曼码的判据必须分清**：曼码看码元中点的跳变方向（且有 Thomas 与 IEEE 802.3 两套标准）；差分曼码看码元前沿是否跳变（遇 0 翻转、遇 1 不变）。
2. **波形判读题从第 2 位开始**：第 1 位没有前一码元作参照，只能结合另一条波形或选项反推。
3. **编码效率的比较**：曼码 50%、4B/5B 与 8B/10B 为 80%、不归零编码 100%；效率最高选 NRZI 一类的 1 比特对 1 码元编码，不要误选 4B/5B。
4. **编码与应用的对应关系**：10M 以太网用曼码、令牌环用差分曼码、百兆用以 4B/5B 为基础的两类组合、千兆的 1000BASE-X 用 8B/10B（1000BASE-T 为 4D-PAM5）。
5. **百兆以太网两种编码流程的差别**：FX 系列为 4B/5B + NRZ-I，TX 系列为 4B/5B + MLT-3。
6. **采样定理只取最高频率的 2 倍**，不能误用频率范围的宽度（如 4~8 MHz 取 16 MHz，10~16 kHz 取 32 kHz）。
7. **PCM 数据速率 = 采样频率 × log₂(量化级数)**，题干若给采样周期先取倒数得采样频率。
8. **调制方式决定码元种类数**：QPSK 的 N 是 4 而不是 2，这是最常见的失分点。
9. **码元速率与比特率不是同一概念**：异步通信求码元速率时，起始位、校验位、终止位都要计入码元；求有效数据速率时才只统计数据位。
10. **TDM 复用题注意单位换算与重复计算**：1 字节 = 8 bit，帧长要加同步开销，8 字节已含 8 条信道的信息。
11. **本节所有计算最终都回到信道容量公式** `R = 2W·log₂N` 与 `C = W·log₂(1 + S/N)`，编码与调制题必须与第二章容量计算反复配合练习。
