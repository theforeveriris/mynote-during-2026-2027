
递归遍历虽然代码简洁，但存在函数调用开销，且递归深度过大时（如单支树），可能导致栈溢出。非递归遍历使用显式栈（std::stack 或数组模拟）模拟系统调用栈的行为，具有更好的稳定性和可控性。

## 1. 前序遍历(PreOrder)

访问根结点后，需优先遍历左子树，再遍历右子树。根据栈的后进先出特性，先压入右孩子，再压入左孩子，确保左孩子先出栈被访问
- 若根结点为空，直接返回。
- 初始化栈，将根结点入栈。
- 循环执行以下操作，直至栈为空：
  - 弹出栈顶结点 p，立即访问 p。
  - 若 p->rchild 非空，将其入栈。
  - 若 p->lchild 非空，将其入栈。

实现代码：

```cpp
void PreOrder(BiTree T) {
    if (T == NULL) return;
    stack<BiTNode*> st;
    st.push(T);
    while (!st.empty()) {
        BiTNode* p = st.top();
        st.pop();
        visit(p);                     // 访问根
        // 右孩子先入栈（后处理），左孩子后入栈（先处理）
        if (p->rchild != NULL) st.push(p->rchild);
        if (p->lchild != NULL) st.push(p->lchild);
    }
}
```

- 时间复杂度：O(n)，每个结点入栈、出栈各一次。
- 空间复杂度：O(h)，最坏情况（单支树）为 O(n)，最好情况（平衡树）为 O(logn)。


## 2. 中序遍历(InOrder)

中序遍历顺序为“左 -> 根 -> 右”。模拟递归过程：先一路向左走到底，将路径上所有结点入栈，然后弹出栈顶访问（即左子树为空的根），再转向处理其右子树。
- 初始化栈，指针 p = T。
- 循环执行以下操作：
    - 若 p 非空，则将 p 入栈，并令 p = p->lchild（深入左子树）。
    - 若 p 为空，且栈非空：
        - 弹出栈顶结点 top，访问 top。
        - 令 p = top->rchild（转向右子树）。
- 当 p 为空且栈为空时，遍历结束。

| 动作            | 含义                                 |
| :------------ | :--------------------------------- |
| **一路向左，沿途入栈** | "我现在还不能访问你，但我需要记住你，等我左边全处理完了再回来找你" |
| **弹出访问，转向右边** | "左边已经处理完了，现在轮到你（根）了，访问完再去处理右边"     |

代码实现：

```cpp
void InOrder(BiTree T) {
    stack<BiTNode*> st;
    BiTNode* p = T;
    while (p != NULL || !st.empty()) {
        // 1. 左路节点全部入栈
        while (p != NULL) {
            st.push(p);
            p = p->lchild;
        }
        // 2. 栈顶节点出栈并访问（左子树为空或已访问）
        if (!st.empty()) {
            p = st.top();
            st.pop();
            visit(p);
            // 3. 转向右子树
            p = p->rchild;
        }
    }
}
```

同上：时间复杂度O(n)，空间复杂度O(h)

## 3. 后序遍历(PostOrder)

后序遍历（“左 -> 右 -> 根”）是三种遍历中最复杂的，因为根结点必须在左右子树都访问完毕后才访问。提供两种经典解法。

### 3.1 双栈法

后序遍历是“左-右-根”。观察先序遍历是“根-左-右”。若修改先序遍历顺序为“根-右-左”（即访问根后，先压左孩子，再压右孩子），得到的结果序列正好是后序遍历的逆序。因此，使用一个栈（栈1）进行“根-右-左”的遍历，将访问的结点压入另一个栈（栈2），最后依次弹出栈2即为后序序列。
- 根结点入栈1。
- 循环执行，直至栈1为空：
    - 弹出栈1顶结点 p，并将 p 压入栈2。
    - 若 p->lchild 非空，将其入栈1。
    - 若 p->rchild 非空，将其入栈1。
- 遍历结束后，依次弹出栈2所有结点并访问。

代码实现：
```cpp
void PostOrder_TwoStacks(BiTree T) {
    if (T == NULL) return;
    stack<BiTNode*> st1, st2;
    st1.push(T);
    while (!st1.empty()) {
        BiTNode* p = st1.top();
        st1.pop();
        st2.push(p);                    // 压入结果栈
        // 注意：先压左再压右，则st1弹出顺序为“根-右-左”
        if (p->lchild != NULL) st1.push(p->lchild);
        if (p->rchild != NULL) st1.push(p->rchild);
    }
    while (!st2.empty()) {
        visit(st2.top());
        st2.pop();
    }
}
```

### 3.2 单栈 + 辅助指针（标准考研写法）

单栈模拟递归返回过程。关键在于判断右子树是否已被访问过，以防止循环访问右子树。使用辅助指针 prev 记录上一次访问过的结点。
- 当前栈顶结点 top，若其右孩子不存在（top->rchild == NULL）或右孩子恰好是上一次访问过的结点（top->rchild == prev），说明右子树为空或已访问完毕
    - 可以安全弹出并访问 top
    - 然后将 prev 更新为 top，
    - 同时将当前指针 p 置空（表示不再向下深入，继续处理栈顶）。
- 否则，说明右子树未被访问，需转向处理 p = top->rchild。

我们注意到这和中序遍历的单栈实现非常相似：都是先把左边整条链压进去，但后序和中序的关键差别在于 "什么时候访问根节点"

中序遍历的单栈实现：
- 一路向左，沿途入栈
- 弹出栈顶访问
- 转向右子树

后序遍历的单栈实现（prev法）：
- 一路向左，沿途入栈
- 查看栈顶（不出栈），判断右子树是否已访问
- 如果右子树已处理完，弹出访问
- 否则转向右子树

时间复杂度O(n)，空间复杂度 O(h)。方法二比双栈法节省一个栈的空间。

代码实现：
```cpp
void PostOrder_SingleStack(BiTree T) {
    if (T == NULL) return;
    stack<BiTNode*> st;
    BiTNode* p = T;
    BiTNode* prev = NULL;          // 记录上一次访问的结点
    while (p != NULL || !st.empty()) {
        // 1. 一路向左，将左孩子全部入栈
        if (p != NULL) {
            st.push(p);
            p = p->lchild;
        } else {
            // 2. 左孩子为空，查看栈顶结点
            BiTNode* top = st.top();
            // 3. 若右孩子存在且未被访问，则转向右子树
            if (top->rchild != NULL && top->rchild != prev) {
                p = top->rchild;
            } else {
                // 4. 右孩子为空或已访问，弹出并访问当前结点
                st.pop();
                visit(top);
                prev = top;          // 更新上次访问标记
                p = NULL;            // 将p置空，继续处理栈内剩余元素
            }
        }
    }
}
```

## 4.统一非递归遍历框架（标记法 / 状态法）

栈中存储 pair<BiTNode*, bool>，false 表示该结点尚未处理其子结点（需按遍历顺序反向压入子结点），true 表示该结点的左右子树均已处理，可直接访问。模拟递归调用顺序，入栈顺序需与递归调用顺序相反。
- 初始将 {T, false} 入栈。
- 循环直至栈空：
    - 弹出栈顶元素 {node, flag}。
    - 若 flag == true，直接访问 node。
    - 若 flag == false，则按照“访问顺序的逆序”将结点及其状态重新压栈：
        - 后序（左-右-根）：压入 {node, true}，压入 {node->rchild, false}，压入 {node->lchild, false}。（弹出时先处理左孩子，再右孩子，最后根）
        - 中序（左-根-右）：压入 {node->rchild, false}，压入 {node, true}，压入 {node->lchild, false}。
        - 先序（根-左-右）：压入 {node->rchild, false}，压入 {node->lchild, false}，压入 {node, true}。
