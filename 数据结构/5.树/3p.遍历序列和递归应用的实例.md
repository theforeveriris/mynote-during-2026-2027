
遍历序列的应用：表达式分析树
实例：分析表达式 a + b * (c - d) - e / f 的二叉树。

遍历输出对应表达式：

先序遍历（前缀表达式）：- + a * b - c d / e f （无需界限符，可直接计算）。

中序遍历（中缀表达式）：a + b * c - d - e / f （必须添加界限符以区分运算优先级，否则产生歧义）。

后序遍历（后缀表达式）：a b c d - * + e f / - （无需界限符，适合栈计算）。

2.4 递归应用示例：计算二叉树深度
算法思想：树的深度 = Max(左子树深度, 右子树深度) + 1。空树深度为 0。

代码实现：

c
int TreeDepth(BiTree T) {
    if (T == NULL) return 0;
    int leftDepth = TreeDepth(T->lchild);
    int rightDepth = TreeDepth(T->rchild);
    return (leftDepth > rightDepth ? leftDepth + 1 : rightDepth + 1);
}
时间复杂度：O(n)，每个结点访问一次。

空间复杂度：O(h)，h 为树高（递归调用栈深度）。
