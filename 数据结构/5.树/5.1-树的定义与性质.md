

## 1.1 树的定义

树是 n (n≥0)  个结点的有限集合。
- 当 n=0  时，称为空树（∅ ）。
- 当 n>0  时，为一棵非空树，满足：
    - 有且仅有一个特定的称为根（Root）的结点；
    - 其余结点可分为 m (m>0) 个互不相交的有限集合T1,T2,...,Tm，，其中每个集合本身又是一棵树，并称为根结点的子树（Subtree）。
- 核心理解：树是一种递归定义的数据结构。每个子树也是树，且子树之间互不相交（否则会出现一个结点有两个前驱，违背树的定义）。

其中非空树有以下特征：
- 有且仅有一个根结点；
- 没有后继的结点称为叶子结点（终端结点）；
- 有后继的结点称为分支结点（非终端结点）；
- 除根结点外，任何一个结点都有且仅有一个前驱；
- 每个结点可以有 0  个或多个后继。
- 树中不存在环，且除了根之外，每个结点入度为 1（有且仅有一个双亲）


## 2.树的术语与性质

| 术语            | 定义                        |
| ------------- | ------------------------- |
| **祖先结点**      | 从根到该结点所经分支上的所有结点          |
| **子孙结点**      | 以某结点为根的子树中的所有结点           |
| **双亲结点（父节点）** | 某结点的直接前驱                  |
| **孩子结点**      | 某结点的直接后继                  |
| **兄弟结点**      | 具有相同双亲的结点                 |
| **堂兄弟结点**     | 双亲在同一层的结点（即深度相同但父节点不同）    |
| **路径**        | 两个结点之间经过的结点序列（**只能从上往下**） |
| **路径长度**      | 路径上经过的**边的条数**            |

| 属性            | 定义             | 说明                                  |
| ------------- | -------------- | ----------------------------------- |
| **结点的层次（深度）** | 从上往下数，根为第 1 层  | 默认从 1 开始（部分教材从 0 开始，考研以王道为准，从 1 开始） |
| **结点的高度**     | 从下往上数          | 叶子高度为 1（或 0，视定义而定）                  |
| **树的高度（深度）**  | 树中结点的最大层次      | 即总共有多少层                             |
| **结点的度**      | 该结点有几个孩子（分支数）  | 叶子结点的度 = 0；非叶子结点的度 > 0              |
| **树的度**       | 树中各结点度的**最大值** | —                                   |

树在实际应用中可以分为有序树和无序树。
- 有序树：每个结点有左右顺序，左右子树的顺序是确定的。（如文件目录树、家谱）
- 无序树：每个结点没有左右顺序，左右子树的顺序是不确定的。（如集合的划分、无次序的分类）

森林（Forest）是 m (m≥0)  棵互不相交的树的集合。m=0 时称为空森林。

### 2.1 一些结论

#### 结点数=总度数+1
 
推导：除根结点外，每个结点都对应一条来自双亲的边（分支）。若有 n  个结点，则总分支数 = n−1 。而总度数 = 总分支数，故总结点数 = 总度数 + 1。

#### 度为 m 的树、m叉树第 i  层至多有m^(i-1)个结点 (i≥1) 。

直观理解：要第 i  层最多，则上一层每个结点都"生满" m  个孩子。第 1 层 m^0 = 1 个结点, 第 2 层 m^1 = m 个结点, 第 3 层 m^2 = m^2 个结点, ...。

#### 高度为 h 的 m 叉树的最多结点数

前提m 叉树，高度为 h （根为第 1 层）,即等比数列求和 m^0+m^1+m^2+...+m^h-1。此时树为满 m  叉树形态。

所以n=（m^h-1）/m-1。

#### 最少结点数

| 类型                    | 最少结点数       | 形态说明                                               |
| --------------------- | ----------- | -------------------------------------------------- |
| **高度为 $h$ 的 $m$ 叉树**  | $h$         | 每层只有一个结点（退化成一条链）                                   |
| **高度为 $h$、度为 $m$ 的树** | $h + m - 1$ | 必须有至少一个结点度为 $m$。构造方法：一条链保证高度 $h$，在链的某个结点下挂 $m$ 个孩子 |


#### 具有 n 个结点的 m 叉树的最小高度

要让高度最小，就要让树尽量"矮胖"，即每个结点尽量都有 m  个孩子（满 m  叉树形态）。设高度为 h ，则前 h  层最多容纳（m^h-1）/m-1个结点，前 h−1  层最多容纳（m^（h-1）-1）/m-1个结点。

所以有不等式：（m^（h-1）-1）/m-1 < n < （m^h-1）/m-1。记得hmin=log_m （n（m-1）+1）
