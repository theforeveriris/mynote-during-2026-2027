
## 1. 并查集的定义

在数据结构的逻辑结构中，元素之间的关系通常分为四类：
- 线性结构：一对一
- 树形结构：一对多
- 图结构：多对多
- 集合：元素之间仅存在“属于同一集合”的关系，别无其他联系

并查集正是用来处理集合这种逻辑结构的工具。

并查集（Union-Find Set）是一种用于处理不相交集合的结构，给定一个全集 S ，将其划分为若干个互不相交的子集 S0, S1, ..., Sk-1，它支持两种操作：
- 合并（Union）：将两个集合合并成一个集合。
- 查找（Find）：确定一个元素所属的集合。

## 2. 并查集的存储结构

同一子集中的各个元素，组织成一棵树；多个互不相交的子集，就构成了一个森林
- 每棵树代表一个集合
- 树的根节点即为该集合的代表元（标识）
- 每个节点只需记录其父节点，形成双亲表示法

使用一个整型数组 S[]（也称为 parent[] 或 fa[]），下标对应各数据元素的编号
- S[i] < 0：表示节点 i  是根节点，且 |S[i]| 可表示该集合的节点个数（或秩/高度）
- S[i] >= 0：表示节点 i  的父节点下标为 S[i]

> 有些教材用 S[i] = -1 单纯标记根，不存大小；我们此处采用负值存集合大小的写法，便于按大小合并优化

## 3. 并查集的操作实现

初始化（Init）：每个元素自成一个集合，都是根节点，S[i] = -1

```c
void Init(int S[], int n) {
    for (int i = 0; i < n; i++)
        S[i] = -1;    // 每个元素独立成集，大小为1
}
```

查操作（Find）:从节点 x  出发，沿父指针一直走到根节点（S[x] < 0 的位置）.时间复杂度：取决于树高，最坏 O(n) （退化成链）

```c
// 找 x 所属集合，返回根节点下标
int Find(int S[], int x) {
    while (S[x] >= 0)    // 循环寻找 x 的根
        x = S[x];
    return x;            // 根的 S[] 小于 0
}
```

并操作（Union）:先找到两个元素各自的根，若不同根，则将一个根的父指针指向另一个根(本质上和森林的合并相同，即为孩子兄弟表示法)

```c
// 将 x 和 y 所在集合合并
void Union(int S[], int x, int y) {
    int rootX = Find(S, x);
    int rootY = Find(S, y);
    if (rootX == rootY) return;    // 已在同一集合
    
    // 简单合并：将 rootX 挂到 rootY 下
    S[rootX] = rootY;              // 未优化，可能产生长链
}
```

## 4.优化策略

### 4.1 Union 的优化：按秩合并 / 按大小合并

防止树过高，控制 Find 的最坏情况,以按大小合并（Size Merge）为例：
- 让节点数少的树挂到节点数多的树下
- 数组 S[root] 存储的是负的节点总数，合并时比较绝对值大小

```c
void Union(int S[], int x, int y) {
    int rootX = Find(S, x);
    int rootY = Find(S, y);
    if (rootX == rootY) return;
    
    // S[root] 为负数，绝对值越大表示集合越大
    if (S[rootX] < S[rootY]) {       // X 集合更大
        S[rootX] += S[rootY];         // 更新大小
        S[rootY] = rootX;             // Y 挂到 X 下
    } else {                         // Y 集合更大或相等
        S[rootY] += S[rootX];
        S[rootX] = rootY;
    }
}
```

也可采用“按秩合并（Rank Merge）”，即比较树的高度，矮树挂高树。实际中按大小合并与按秩合并效果接近，均可保证单次 Find 均摊接近 O(logn) 

### 4.2 Find 的优化：路径压缩(Path Compression)

执行 Find(S, x) 时：
- 先找到 x  所在树的根节点 root
- 将查找路径上所有节点的父指针，全部直接指向根节点

这样下次再访问这些节点时，一步即可到达根节点。

```c
int Find(int S[], int x) {
    int root = x;
    while (S[root] >= 0) 
        root = S[root];          // 第一步：循环找到根
    
    while (x != root) {          // 第二步：压缩路径
        int t = S[x];            // t 暂存 x 的原父节点
        S[x] = root;             // x 直接挂到根节点下
        x = t;                   // 继续处理原父节点
    }
    return root;                 // 返回根节点编号
}
```

也可以递归实现：

```c
int Find(int S[], int x) {
    if (S[x] < 0) return x;           // 根节点
    return S[x] = Find(S, S[x]);      // 递归找根 + 路径压缩
}
```

| 优化策略               | Union 复杂度             | Find 复杂度              |
| ------------------ | --------------------- | --------------------- |
| 无优化                | $O(1)$                | $O(n)$                |
| 按大小/秩合并            | $O(\log n)$           | $O(\log n)$           |
| **路径压缩 + 按秩/大小合并** | **均摊 $O(\alpha(n))$** | **均摊 $O(\alpha(n))$** |

其中 α(n)  是阿克曼函数的反函数，增长极其缓慢，可以认为是常数时间。
