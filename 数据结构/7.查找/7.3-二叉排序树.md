
## 1.二叉排序树的定义与性质

二叉排序树，又称二叉查找树（BST, Binary Search Tree）,我们定义为或是空二叉树，或是具有如下性质的二叉树：
- 若左子树非空，则左子树上所有结点的关键字均小于根结点的关键字；
- 若右子树非空，则右子树上所有结点的关键字均大于根结点的关键字；
- 左、右子树又各是一棵二叉排序树（递归定义）

其性质有：
- 中序遍历二叉排序树，可以得到一个递增的有序序列。 这是二叉排序树最核心的性质，也是判断一棵二叉树是否为二叉排序树的重要依据（中序遍历结果严格递增）。
- 二叉排序树可用于元素的有序组织与搜索，是动态查找表的一种典型实现结构。
- 默认不允许树中存在两个关键字相同的结点

```c
typedef struct BSTNode {
    int key;                      // 关键字
    struct BSTNode *lchild, *rchild;   // 左、右孩子指针
} BSTNode, *BSTree;
```

实际应用中，结点除关键字 key 外通常还携带其他数据域（如卫星数据 data）；在部分题目中还会增设指向父结点的指针 parent，以便在删除操作中定位父结点。

## 2.二叉排序树的查找

若树非空，将目标值与根结点的关键字比较：
- 若相等，则查找成功；
- 若目标值小于根结点值，则在其左子树上继续查找；
- 若目标值大于根结点值，则在其右子树上继续查找；
- 若树空（走到 NULL），则查找失败。

非递归实现：
```c
BSTNode *BST_Search(BSTree T, int key) {
    while (T != NULL && key != T->key) {   // 若树空或等于根结点值，则结束循环
        if (key < T->key)
            T = T->lchild;    // 小于，则在左子树上查找
        else
            T = T->rchild;    // 大于，则在右子树上查找
    }
    return T;   // 查找成功返回结点指针；查找失败返回NULL
}
```

只使用了常数个辅助变量，最坏空间复杂度为 O(1)

递归实现：
```c
BSTNode *BSTSearch(BSTree T, int key) {
    if (T == NULL)
        return NULL;              // 查找失败
    if (key == T->key)
        return T;                 // 查找成功
    else if (key < T->key)
        return BSTSearch(T->lchild, key);   // 在左子树中找
    else
        return BSTSearch(T->rchild, key);   // 在右子树中找
}
```

递归工作栈深度取决于树高 h，最坏空间复杂度为 O(h)

两种实现的时间复杂度均取决于树高，最好 O(log₂n)，最坏 O(n)（树退化为单支链）。

递归写法代码更简洁，但存在函数调用开销；非递归写法在工程中更常用。
