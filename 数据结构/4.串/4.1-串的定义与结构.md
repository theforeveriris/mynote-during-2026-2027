
## 1.串的定义

串（String） 是由零个或多个字符组成的有限序列，一般记为: `S`=`a1a2...an`
- S ：串名
- a1a2...an ：串的值（单引号或双引号括起来的字符序列）
- n ：串的长度（字符个数）
- n=0  时的串称为空串，记为 ∅  或 ""
- 引号习惯：C/Java 通常用双引号 "Hello"，Python 单双引号均可

| 术语       | 定义                   | 示例（$T = \text{'iPhone 11 Pro Max?'}$） |
| -------- | -------------------- | ------------------------------------- |
| **子串**   | 串中任意个**连续**字符组成的子序列  | `'iPhone'`、`'Pro M'` 都是 $T$ 的子串       |
| **主串**   | 包含子串的串               | $T$ 是 `'iPhone'` 的主串                  |
| **字符位置** | 字符在串中的序号（从 **1** 开始） | `'1'` 在 $T$ 中的位置是 **8**               |
| **子串位置** | 子串的第一个字符在主串中的位置      | `'11 Pro'` 在 $T$ 中的位置为 **8**          |

注意：空串不等于空格串，空格串的长度为 n，而空串的长度为 0。

|         | 表示          | 长度 | 说明                   |
| ------- | ----------- | -- | -------------------- |
| **空串**  | `M = ""`    | 0  | 不含任何字符               |
| **空格串** | `N = "   "` | 3  | 由空格字符组成，每个空格占 **1B** |

串是一种特殊的线性表，数据元素之间呈线性关系

| 对比维度     | 线性表       | 串                        |
| -------- | --------- | ------------------------ |
| **数据对象** | 任意数据元素    | 限定为**字符集**（字母、数字、标点、中文等） |
| **操作对象** | 单个数据元素    | 通常以**子串**为增删改查的操作对象      |
| **现实意义** | 单个元素可能有意义 | 人类语言通常需**多个字符组成的序列**才有意义 |

正因为串的操作常以"子串"为单位，所以串匹配算法（如 KMP）是本章核心考点

## 2.串的存储结构

### 2.1 顺序存储

串的顺序存储与线性表的顺序存储类似，用一组地址连续的存储单元存储字符序列。

可以使用静态数组实现（定长顺序存储）实现:

```c
#define MAXLEN 255

typedef struct {
    char ch[MAXLEN];  // 每个分量存储一个字符，分配连续空间，每个 char 占 1B
    int length;       // 串的实际长度
} SString;
```

- 优点：实现简单，存取速度快
- 缺点：长度固定，超过 MAXLEN 会产生"截断"

也可以使用动态数组实现（堆分配存储）实现:

```c
typedef struct {
    char *ch;         // 按串长分配存储区，ch 指向串的基地址
    int length;       // 串的长度
} HString;

HString S;
S.ch = (char *)malloc(MAXLEN * sizeof(char));
S.length = 0;
// 用完需要手动 free(S.ch)
```

- 优点：灵活，可根据需要动态分配
- 缺点：需要手动管理内存（free）

以存储 "wangdao"（长度 7）为例，假设数组大小为 10：

| 方案          | 存储示意                               | 特点                                               |
| ----------- | ---------------------------------- | ------------------------------------------------ |
| **方案一**     | `w a n g d a o _ _ _` + `Length=7` | `ch[0]` 开始存字符，单独变量记录长度                           |
| **方案二**     | `7 w a n g d a o _ _`              | `ch[0]` 充当 Length，字符从 `ch[1]` 开始                 |
| **方案三**     | `_ w a n g d a o \0 _`             | `ch[0]` 废弃不用，以 `'\0'`（ASCII 0）作为结束标志，无 Length 变量 |
| **方案四（教材）** | `_ w a n g d a o _ _` + `Length=7` | `ch[0]` 废弃不用，字符从 `ch[1]` 开始，单独变量记录长度             |


方案四（教材采用）的优势：字符的位序与数组下标一致（第 i 个字符存放在 ch[i]），避免了方案二中 ch[0] 既当长度又当字符的混淆，也避免了方案三遍历求长度的 O(n) 开销

### 2.2 链式存储

结合链表知识，串也可采用链式存储。

可以使用单链表实现，每个节点存储一个字符，链表头指向第一个字符，链表尾指向 NULL。

```c
typedef struct StringNode {
    char ch;                   // 每个结点存 1 个字符（1B）
    struct StringNode *next;   // 指针域（4B/8B）
    //在 32 位系统中，指针是 4 字节。在 64 位系统中，指针是 8 字节
} StringNode, *String;
```
- 存储密度 = 数据本身占用空间 / 结点总空间 = 1/(1+4)=20% 
- 每个字符带一个指针，空间浪费严重。

也可以使用块链结构（多字符结点）

```c
typedef struct StringNode {
    char ch[4];                // 每个结点存多个字符（块）
    struct StringNode *next;
} StringNode, *String;
```

- 存储密度提高：一个指针对应多个字符
- 最后一个结点若未存满，可用特定字符（如 #）填充
- 实际应用（如文本编辑器）常采用块链，平衡插入删除效率与空间利用率

### 2.3 基于顺序存储的基本操作实现（教材方案四）

```c
#define MAXLEN 255
typedef struct {
    char ch[MAXLEN];  // ch[0] 废弃不用
    int length;
} SString;
```
| 操作                     | 功能说明                                  |
| ---------------------- | ------------------------------------- |
| `StrAssign(&T, chars)` | **赋值**：将串 $T$ 赋值为 `chars`             |
| `StrCopy(&T, S)`       | **复制**：由串 $S$ 复制得到串 $T$               |
| `StrEmpty(S)`          | **判空**：若 $S$ 为空串，返回 `TRUE`，否则 `FALSE` |
| `StrLength(S)`         | **求串长**：返回串 $S$ 的元素个数（即 `S.length`）   |
| `ClearString(&S)`      | **清空**：将 $S$ 置为空串（`length = 0`）       |
| `DestroyString(&S)`    | **销毁**：回收串 $S$ 的存储空间（动态分配时 `free`）    |
| `Concat(&T, S1, S2)`   | **联接**：用 $T$ 返回由 $S1$ 和 $S2$ 联接而成的新串  |
