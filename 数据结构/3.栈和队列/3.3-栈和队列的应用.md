
## 1.栈的应用——括号匹配

问题背景:编译器在词法/语法分析阶段必须检查源代码中的括号是否成对出现、类型是否一致。例如 C 语言中 int x = 10*(20*(1+1)-(3-2)); 若括号不匹配，编译器会报错。

核心思想：利用栈的 LIFO(Last In First Out) 特性.最后出现的左括号最先被匹配（Last In First Out）,每扫描到一个右括号，就需要“消耗”（出栈）一个最近的左括号,我们选择遍历表达式中的每个字符：
- 遇到左括号（{、[、(）：入栈。
- 遇到右括号（}、]、)）：
    - 若栈空 → 匹配失败（右括号“单身”，无左括号可匹配）。
    - 若栈顶左括号与当前右括号类型不匹配（如栈顶是 {，当前是 )）→ 匹配失败。
    - 若类型匹配 → 栈顶左括号出栈（完成一对匹配）。
- 遍历结束后：
    - 若栈空 → 所有括号两两配对，匹配成功。
    - 若栈非空 → 有左括号未匹配（左括号“单身”），匹配失败。


## 2.栈的应用——表达式求值

表达式由操作数、运算符、界限符（括号）三部分组成。波兰数学家发现：通过改变运算符位置，可以不用界限符也能无歧义地表达运算顺序。

| 表达式类型     | 英文名称                          | 运算符位置       | 示例      |
| --------- | ----------------------------- | ----------- | ------- |
| **中缀表达式** | Infix Notation                | 两个操作数**中间** | `a + b` |
| **后缀表达式** | Reverse Polish Notation (RPN) | 两个操作数**后面** | `a b +` |
| **前缀表达式** | Polish Notation               | 两个操作数**前面** | `+ a b` |

> 后缀表达式又称逆波兰式，前缀表达式又称波兰式，由波兰数学家 Jan Łukasiewicz 提出。

| 中缀表达式           | 后缀表达式           | 前缀表达式           |
| --------------- | --------------- | --------------- |
| `a + b`         | `a b +`         | `+ a b`         |
| `a + b - c`     | `a b + c -`     | `- + a b c`     |
| `a + b - c * d` | `a b + c d * -` | `- + a b * c d` |


如中缀表达式转后缀表达式:
- 根据运算符优先级和结合性，确定中缀表达式中各个运算符的运算顺序。
- 选择下一个要处理的运算符，按照 「左操作数 右操作数 运算符」 的方式组合成一个新的操作数。
- 若还有运算符未处理，重复步骤 2。

```
((15 ÷ (7 - (1 + 1))) × 3) - (2 + (1 + 1))
----
((15 ÷ (7 - (1 + 1))) × 3) (2 + (1 + 1)) -
----
(15 (7 - (1 + 1))÷) 3 × 
2 1 1 + + -
----
15 7 (1 + 1) - ÷ 3 ×
2 1 1 + + -
---
15 7 1 1 + - ÷ 3 ×
2 1 1 + + -
---
15 7 1 1 + - ÷ 3 × 2 1 1 + + -
```

中缀表达式中的括号（界限符）反映了计算的先后顺序；而前缀/后缀表达式通过运算符位置直接体现顺序，因此不需要括号

## 3.栈的应用——递归

程序运行时，操作系统使用函数调用栈（Call Stack）管理函数调用：
- LIFO 特性：最后被调用的函数最先执行结束。
- 每次函数调用时，栈中保存：
    - 调用返回地址（调用结束后回到哪里继续执行）
    - 实参（传入的参数值）
    - 局部变量

示例：main() → func1() → func2()
- 调用顺序：main → func1 → func2（依次压栈）
- 返回顺序：func2 → func1 → main（依次弹栈）

### 3.1 递归算法的本质

递归算法适合解决这样的问题：可以把原始问题转换为属性相同、但规模更小的子问题。

递归包含两个要素：

| 要素             | 作用          | 示例（阶乘）                  |
| -------------- | ----------- | ----------------------- |
| **递归体**        | 描述如何分解问题    | `n × factorial(n-1)`    |
| **递归出口（边界条件）** | 终止递归，防止无限循环 | `n = 0` 或 `n = 1` 时返回 1 |

```c
// 阶乘函数
factorial(n) = n × factorial(n-1)   (n > 1)
factorial(1) = 1
factorial(0) = 1

// 斐波那契数列函数
Fib(n) = Fib(n-1) + Fib(n-2)   (n > 1)
Fib(1) = 1
Fib(0) = 0
```

- 递归调用时，函数调用栈可称为 “递归工作栈”。
- 进入一层递归：将该层所需信息（参数、局部变量、返回地址）压入栈顶。
- 退出一层递归：从栈顶弹出相应信息。
- 递归算法的空间复杂度与递归深度成正比（每层占用一个栈帧）。
- 风险：太多层递归可能导致 栈溢出（Stack Overflow）。
- 优化：可以自定义栈将递归算法改造成非递归算法（迭代实现），从而规避系统栈溢出。

## 4.队列的应用

队列的核心特性是 FIFO（First In First Out，先进先出）,故而可以实现:

树的层次遍历
- 按层次从上到下、同一层从左到右依次访问树的每个节点。
- 算法：根节点入队 → 队头出队并访问 → 将其左右子节点依次入队 → 重复直至队空。

图的广度优先遍历（BFS）
- 从起始顶点出发，先访问所有邻接顶点，再依次访问这些邻接顶点的邻接顶点。
- 用队列保存待访问顶点，保证“先被发现的顶点先被扩展”。

FCFS 调度策略
- First Come First Service（先来先服务）。
- 当多个进程争抢有限的系统资源时，按到达顺序排队服务，可用队列实现。
