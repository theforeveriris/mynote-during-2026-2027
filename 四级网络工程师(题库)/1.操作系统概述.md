
## 1.操作系统本质与定位

操作系统是计算机系统中的一个系统软件，位于硬件之上、支撑软件之下。

核心职责：有效地组织和管理计算机系统中的硬件和软件资源，合理组织计算机工作流程，控制程序的执行，并向用户提供各种服务功能，使用户能灵活、方便、有效地使用计算机，并使整个计算机系统高效运行。
- "合理" 的含义：公平对待不同用户程序，不发生"死锁"和"饥饿"
- "高效" 的含义：在资源有限的情况下，能够有效利用资源，实现程序的快速执行和响应。
- "动态" 的含义：能够根据系统负载和用户需求，动态调整资源分配和程序执行。

| 视角         | 作用                      |
| ---------- | ----------------------- |
| **应用角度**   | 提供**人机交互接口**（命令输入和系统调用） |
| **软件开发角度** | 软件开发的基础平台               |
| **安全保护角度** | 第一道安全防线                 |
| **系统发展角度** | 虚拟机和扩展机                 |

操作系统的基本特征：

- 并发性（Concurrency）
    - 执行期间具有相互制约关系
    - 程序与计算不再一一对应（一个程序可对应多个进程）
    - 结果不再现——并发过程失去封闭性
    - 宏同微交：宏观上同时执行，微观上交替执行
- 共享性（Sharing）
    - 共享资源包括：CPU、内外存储器、外部设备
    - 注意：磁带机、投影仪、扫描仪为独占设备
    - 同时共享，多个进程可同时访问，如硬盘、可重入代码
    - 互斥共享，同一时间只能一个进程访问，如临界区、中断服务程序
- 随机性（异步性 / Asynchronism）
    - 不能对运行程序及硬件设备的情况作出假定
    - 何时退出？假死？中断？关机？重启？——均不可预测

## 2.操作系统的基本功能

| 功能模块           | 管理对象            | 具体内容                                          |
| -------------- | --------------- | --------------------------------------------- |
| **进程管理**       | CPU             | 进程控制（创建、撤销、状态转换）、进程同步（同步/互斥）、进程间通信（信息交换）、进程调度 |
| **存储管理**       | 内存资源            | 回收与分配内存、存储保护（防止越界）、内存扩充（虚拟技术）                 |
| **文件管理**       | 文件系统            | 文件存储空间管理（创建/删除/命名）、文件目录管理、文件系统安全性（读写/存取权限）    |
| **设备管理**       | I/O设备（除CPU和内存外） | 外部设备分配、故障处理；涉及技术：中断技术、通道技术、虚拟设备技术、缓冲技术        |
| **用户接口（作业管理）** | 用户交互            | 提供命令接口、程序接口、图形界面                              |

## 3.操作系统的分类和常见操作系统

常见操作系统：
- Windows —— 微软桌面操作系统
- Unix —— 多用户多任务操作系统鼻祖
- DOS —— 磁盘操作系统（单用户单任务）
- Linux —— 多用户多任务操作系统（基于Unix）
    - Debian系列（如Ubuntu、Kali Linux）
        - Ubuntu系列（如Kubuntu4.04、Kubuntu18.04）
    - Red Hat系列（如CentOS、RHEL）
    - Fedora系列（如Fedora 34、Fedora 35）
    - Arch Linux系列（如Arch Linux）
    - Gentoo系列（如Gentoo Linux）
- MacOS —— 多用户多任务操作系统（基于Unix）
- Android —— 移动操作系统（基于Linux）
- iOS —— 移动操作系统（基于Unix）（部分基于Apple的Unix）
- BSD —— 多用户多任务操作系统（基于Unix）（部分基于FreeBSD、OpenBSD、NetBSD等）

按页面使用环境和功能特征分类：
- 批处理系统（Batch Processing System）
    - 单道批处理系统（Single-Program Batch Processing System），内存中仅有一道作业运行
    - 多道批处理系统（Multi-Program Batch Processing System），内存中可以有多个道作业运行，效率和吞吐量较高，**但缺少人机交互性**
    - 指令分为特权指令和一般指令,特点：成批处理、资源利用率高
- 分时系统（Time-Sharing System）
    - 多路性：多用户共同使用系统
    - 交互性：用户可与系统交互
    - 独占性：用户感觉独占整个系统
    - 及时性：响应时间较短
- 实时系统（Real-Time System）
    - 多路性、及时性、交互性、可靠性
    - 具有过载防护能力
    - 交互式系统：用户交互式地向系统提出命令请求，系统接受每个用户的命令，采用时间片轮转方式处理服务，并通过交互方式在终端上向用户显示结果。
    - 适用于交互式操作系统的调度算法：多级反馈队列、时间片轮转、高优先级优先

按计算机体系结构分类:

| 类型          | 特点                                                    |
| ----------- | ----------------------------------------------------- |
| **个人操作系统**  | 面向个人用户                                                |
| **网络操作系统**  | 主从关系明显；有限制共享资源                                        |
| **分布式操作系统** | 统一配置，所有主机使用一个操作系统；资源共享；相互通信；**透明性**；**自治性**（地位平等）；可靠性 |
| **嵌入式操作系统** | 成本低，资源受限                                              |


操作系统结构如下:

| 结构类型             | 说明                                               | 特点                                                |
| ---------------- | ------------------------------------------------ | ------------------------------------------------- |
| **整体式结构**        | 功能划分成多个模块                                        | 结构简单，但模块间耦合度高                                     |
| **层次式结构**        | 单向调用，同层不调用                                       | 结构清晰，便于调试和维护                                      |
| **微内核结构（C/S结构）** | 大多数OS功能由用户进程实现；分割成多个部分，每一部分只处理一方面的功能（文件服务、进程服务等） | 高可靠性、高灵活性、适合分布式处理、可移植性强、融入面向对象技术；**但效率低，不适合频繁通信** |


> 微内核具备的功能：线程调度、虚拟存储、消息传递、设备驱动、内核原语操作、中断处理（屏蔽中断）

## 4.指令

特权指令（Privileged Instructions）
- 包括：输出指令、停机指令等
- 只有在监控程序才能执行特权指令
- 只能在内核状态（管态）下运行
- 例如：屏蔽中断、关闭中断

一般指令（Non-privileged Instructions）
- 在用户态（目态）下运行
- 在管态下也可以执行
- 例如：关机、读文件、设置时间

> 如果用户程序在用户态（目态）执行特权指令，则引起访管中断，这也是 CPU 由用户态向核心态转换的方法。

## 5.资源相关概念

临界资源（Critical Resource）
- 一次仅允许一个进程使用的资源
- 访问临界资源的代码段称为**临界区（Critical Section）**

可重入代码（Reentrant Code）
- 又称纯代码（Pure Code）
- 可被多个进程同时共享执行的代码
- 在运行过程中不允许任何修改
- 例如：硬盘、内存中的可重入代码

不可重用资源
- 时间片：每个进程在 CPU 上运行的时间段片
- 硬件时钟到时：每个进程在 CPU 上运行的时间段

## 6.三类用户接口

| 接口类型            | 说明                           | 示例                                          |
| --------------- | ---------------------------- | ------------------------------------------- |
| **命令接口**        | 提供一组命令供用户间接/直接操作             | Shell命令、DOS命令                               |
| **程序接口（系统调用）**  | 操作系统提供给编程人员的**唯一接口**，供用户程序使用 | `open()`（文件操作）、`fork()`（进程控制）、`write()`（输出） |
| **图形界面接口（GUI）** | 图标、菜单、窗口，直观易懂                | Windows桌面、macOS桌面；终端窗口采用命令行                 |

> 系统调用是操作系统内核提供给用户程序的接口，是用户程序请求操作系统服务的唯一途径。

## 7.设备分配算法中的数据结构

设备分配涉及四张表，分配顺序如下：系统设备表（SDT） → 设备控制表（DCT） → 控制器控制表（COCT） → 通道控制表（CHCT）

| 表名         | 英文                              | 作用           |
| ---------- | ------------------------------- | ------------ |
| **系统设备表**  | System Device Table (SDT)       | 记录系统中全部设备的情况 |
| **设备控制表**  | Device Control Table (DCT)      | 记录每台设备的特性及状态 |
| **控制器控制表** | Controller Control Table (COCT) | 记录每个控制器的状态   |
| **通道控制表**  | Channel Control Table (CHCT)    | 记录每个通道的状态    |


## 8.程序状态字（PSW）

PSW（Program Status Word）：专门的寄存器，用于指示处理器状态。

| 字段           | 说明        |
| ------------ | --------- |
| **CPU工作状态码** | 指明管态/目态   |
| **条件码**      | 指令执行结果的状态 |
| **中断屏蔽码**    | 是否允许中断    |


| 标志       | 全称                        | 含义       |
| -------- | ------------------------- | -------- |
| **CF**   | Carry Flag                | 有进位      |
| **ZF**   | Zero Flag                 | 结果为零     |
| **SF**   | Sign Flag                 | 符号位      |
| **OF**   | Overflow Flag             | 溢出       |
| **TF**   | Trap Flag                 | 陷阱（单步执行） |
| **IF**   | Interrupt Flag            | 中断屏蔽     |
| **VIF**  | Virtual Interrupt Flag    | 虚拟中断     |
| **VIP**  | Virtual Interrupt Pending | 虚拟中断待决   |
| **IOPL** | I/O Privilege Level       | I/O特权级别  |
