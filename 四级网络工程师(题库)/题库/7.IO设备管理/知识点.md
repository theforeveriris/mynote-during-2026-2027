# IO设备管理

## 考点速记

1. 按信息交换/组织单位划分，设备分为块设备和字符设备；块设备以块为单位传输数据，如硬盘、磁盘、磁带、SSD 盘、U 盘、存储阵列、光盘阵列、适配卡等；字符设备以字符为单位传输数据，如键盘、打印机、触摸屏、手写板、鼠标、摄像头、终端等。
2. 按使用特性划分，设备可分为输入设备（键盘、鼠标、摄像头、手写板、触摸屏、扫描仪等）、输出设备（显示屏、打印机、绘图机、投影机等）、存储设备、通信设备等。
3. 设备还可分为独占设备、共享设备、虚拟设备等类型。

### 二、设备表与设备管理数据结构知识点

1. 设备管理中用于管理和分配设备的设备表，核心作用是建立逻辑设备与物理设备之间的对应关系。
2. 设备分配的主要数据结构包括系统设备表（SDT）、设备控制表（DCT）、控制器控制表（COCT），分配顺序为：系统设备表→设备控制表→控制器控制表。
3. 系统设备表（SDT）：存放设备的名称、标识等基础信息。
4. 设备控制表（DCT）：存放设备的忙/闲标志、设备特征等状态和属性信息。
5. 此外设备管理相关数据结构还包括通道控制表（CHCT）。

### 三、I/O 控制方式知识点 I/O 控制方式核心特征 CPU 参与度适用设备核心组成部件缺失关键部件程序直接控制方式 CPU 不断轮询设备状态寄存器完成位，直到设备完成操作高，全程参与查询，CPU 与外设串行工作键盘、鼠标等低速字符设备状态寄存器、数据寄存器、控制寄存器设备触发器中断控制方式 CPU 启动外设后继续执行主程序，设备就绪后发中断请求，CPU 响应处理I/O 中，仅在设备中断时参与，实现 CPU 与外设并行键盘、打印机等字符设备数据寄存器、控制寄存器、触发寄存器独立状态寄存器 DMA 方式 DMA 控制器接管总线，数据在内存与I/O 设备间直接传输，无需CPU 中转低，仅初始化和结束时参与，数据传输与CPU 完全并行磁盘、硬盘、磁带等块设备源地址寄存器、目标地址寄存器、传输计数器通道控制器通道控制方式引入独立于CPU 的通道（有专属指令/程序），统一管理外设并完成数据传送极低，仅下达指令，全程由通道自主处理各类高速外设、多设备批量传输通道控制器、数据寄存器、地址译码器源地址寄存器


### 四、设备管理的核心目的与主要任务知识点

1. 操作系统设置设备管理功能的核心主要目的是方便用户使用设备。
2. 设备管理的核心任务包括：通过缓冲技术匹配高、低速/不同速度的外部设备；通过虚拟技术提高设备并发度；通过协调技术避免设备冲突；通过接口技术为用户操作系统其他部分提供一致、易于使用的系统调用；保证系统安全正确地使用设备；匹配设备性能、安全使用设备等；并非以单纯加速数据传输、提高设备运行效率或并行性为核心任务。
3. 设备管理模块不负责的工作：处理缺页中断、处理器超频运行、添加内存条、关闭处理器核心等（此类属于内存管理、CPU 管理范畴）；负责的工作包括进程申请各类外设（绘图仪、打印机、扫描仪、光驱等）、串行/并行数据转换、将外设输入信息送入内存等。

### 五、设备管理相关技术及作用知识点（一）缓冲技术  核心目的：匹配高速和低速设备的传输速度，缓解不同设备间传输速度的差距，提高低速设备的使用效率，进而提升I/O 性能。  缓冲区类型包括单缓冲区、双缓冲区、缓冲池，高速缓存不属于设备管理的缓冲区类型。  缓冲池管理的核心重点是实现进程访问缓冲区的同步。  设备无关软件层会通过缓冲区匹配不同速度的设备。（二）虚拟技术  核心目的是提高设备并发度，通过虚拟设备技术（如SPOOLing）将独占设备改为共享设备，提升I/O 性能。（三）中断技术  核心目的是提高设备效率，实现CPU 与外设的并行工作。（四）SPOOLing 技术  属于虚拟设备技术，可破坏死锁的互斥条件，将独占设备转换为共享设备，提高设备利用率；SPOOLing 系统是联机I/O 系统，并非脱机I/O 系统。（五）设备独立（无关）技术  设立设备独立层的核心目的：屏蔽I/O 设备驱动的多样性，便于用户使用，为用户提供一致的操作接口。  设备名（如com1）到实际物理设备的映射工作，在设备独立层完成。


### 六、I/O 软件层次结构知识点 I/O 软件分为四层，其中与设备无关的系统软件（设备独立层）是核心层，功能及边界如下：（一）核心功能

1. 为用户提供一致的系统调用，对设备统一进行命名；
2. 提供与设备无关的逻辑块、存储读写的物理块；
3. 为设备提供缓冲区/缓存空间，通过缓冲区匹配不同速度的设备；
4. 对用户屏蔽出错来源，向用户报告出错处理情况；
5. 通过库函数传递调用参数。（二）非该层功能  配置I/O 设备的寄存器、配置I/O 设备的中断参数、建立SPOOLing 系统等（此类属于设备驱动层或硬件相关层功能）。

### 七、提升I/O 性能的方法知识点

1. 应用缓冲技术，匹配不同设备传输速度，减少速度差距；
2. 应用异步I/O 技术，使CPU 不必阻塞等待I/O 结果；
3. 通过DMA 或通道部件，实现I/O 设备与CPU 的并行工作；
4. 应用虚拟设备技术，将独占设备改为共享设备；多核技术、多级存储架构、设备独立软件的接口提供，并非提升I/O 性能的核心方法。

### 八、死锁与进程调度相关知识点（一）死锁相关

1. 死锁产生的必要条件包括：互斥、不可剥夺、请求和保持、循环等待；循环等待指多个进程之间形成互相等待的资源依赖关系，如进程P1 等待P2 的信号，P2 等待 P1 的数据。
2. 死锁预防方法：  破坏互斥条件：引入SPOOLing 技术；  破坏不可剥夺条件：让阻塞进程放弃拥有的资源；  破坏请求和保持条件：一次性申请所需的全部资源；  破坏循环等待条件：让进程按序申请资源。  死锁检测与恢复方法：杀死进程并收回其占有的资源；银行家算法属于死锁避免算法，按序分配、一次性分配属于死锁预防算法。（二）进程调度相关
1. 进程饥饿现象：指进程因优先级较低而长时间得不到调度，无法执行。
2. 计算机系统资源分类：  可重用资源：可被多次使用，如内存；  不可重用资源：使用后即消耗/ 释放，如时钟中断；  临界资源：需互斥访问的共享资源；共享资源：可被多个进程访问的资源。

### 九、I/O 设备与系统运行的基础知识点

1. 不同的I/O 设备可以并行工作，是计算机系统高效运行的基础。
2. 并非只有I/O 设备能产生有效的中断源，系统其他部件也可产生中断。
3. 中断处理过程中，并非必须屏蔽新中断，可根据需求设置中断嵌套。
4. 用户控制外部设备的命令传递途径：用户应用层→设备独立层→设备驱动层→设备硬件。

## 设备分类

1. 按信息交换单位 块设备：以数据块为单位，磁盘、磁带、U 盘、SSD、存储/显示/网络适配卡。 字符设备：以字符为单位，键盘、打印机、触摸屏、手写板、鼠标、终端。
2. 按使用特性 输入设备：键盘、鼠标、手写板、摄像头、触摸屏。 输出设备：显示器、打印机、绘图机、投影机。
3. 按共享属性：独占设备、共享设备、虚拟设备。 独占设备：打印机、扫描仪、时钟发生器、绘图机、读卡器。 共享设备：硬盘、磁带机。
4. 设备表的作用：建立逻辑设备与物理设备之间的对应关系。

## 设备管理目的与任务

1. 主要目的：方便用户使用设备。
2. 采用中断技术目的：提高设备效率。
3. 核心任务 匹配高速CPU 与低速I/O 设备（缓冲技术）。 提高设备并发度（虚拟技术）。 避免设备冲突，统一接口，提供一致系统调用。 保证系统安全、正确使用设备。
4. 不负责工作：处理缺页中断、处理器超频、添加内存条、关闭CPU 核心。

## I/O 控制方式

1. 程序直接控制：CPU 循环查询设备状态，效率低。设备触发器不是其组成； 关键部件：设备状态寄存器、地址总线和数据总线、设备控制寄存器、设备数据 缓冲区、地址译码器； 传送结构：控制寄存器、数据寄存器、状态寄存器、地址译码器。
2. 中断方式：CPU 启动设备后继续运行，设备就绪发中断，键盘常用。状态寄存器不 是其组成。 关键部件：中断控制器、地址总线和数据总线、设备控制器； 传送结构：中断请求触发器、中断屏蔽触发器、控制寄存器、数据寄存器、地址 译码器。
3. DMA 方式：CPU 不参与数据传输，直接内存-设备交换，磁盘常用。通道控制器不 是其组成。 关键部件：DMA 控制器、地址总线和数据总线。 传送阶段：传送的前中后三阶段。
4. 通道方式：专用处理器统一管理外设，完全解放CPU。源地址寄存器不是其组成方 式。 关键部件：通道控制器、地址总线和数据总线、设备控制器、通道程序代码。 传送结构：通道控制器、地址总线和数据总线、设备控制器、通道程序代码。
5. 通道的类型：字节多路通道、数组多路通道、选择通道；
6. I/O 技术：缓冲技术、设备分配技术、SPOOLing 技术、DMA 与通道技术。

## 缓冲技术

1. 作用：匹配高速与低速设备，提高设备效率。
2. 类型：单缓冲、双缓冲、缓冲池；高速缓存不属于I/O 缓冲。
3. 缓冲池：重点实现进程访问缓冲区的同步。

## I/O 软件层次（从上到下）

1. 用户级I/O 软件→设备无关层→设备驱动层→中断处理层→设备硬件层。
2. 设备独立层（核心） 逻辑设备↔物理设备映射。 统一命名、统一系统调用、屏蔽设备差异。 错误处理、提供逻辑块和物理块、缓冲区管理。
3. 设备驱动层：与硬件交互，控制寄存器、执行设备操作。
4. 命令流向：用户应用层→设备独立层→设备驱动层→设备硬件。

## 设备管理数据结构

1. 系统设备表SDT：记录设备名称、标识、类型、进程号、全局信息、设备控制表 DCT 指针。
2. 设备控制表DCT：记录设备忙/闲、类型、标识、特征、状态、控制器控制表COCT 指针。
3. 控制器控制表COCT：记录控制器标识、忙/闲标记、等待队列首指针、通道控制表 CHCT 指针。
4. 通道控制表CHCT：记录通道标识、忙/闲标记、等待队列首指针、控制器控制表 COCT 指针。
5. 分配顺序：系统设备表（SDT）→设备控制表（DCT）→控制器控制表（COCT）。

## 提高I/O 性能的方法

缓冲技术：匹配速度差。

异步I/O：CPU 不等待I/O 结果。

DMA/通道：CPU 与I/O 并行。

虚拟设备技术：独占→共享，提高并发。


## 死锁与饥饿

1. 饥饿：低优先级进程长期得不到调度。
2. 死锁：进程互相等待资源，无限僵持。
3. 死锁预防 破坏互斥：SPOOLing 技术。 破坏不可剥夺：阻塞则主动释放资源。 破坏请求与保持：一次性申请所有资源。 破坏循环等待：按序申请资源。 Spooling 组成：输入井和输出井、输入缓冲区和输出缓冲区、输入进程和输出进程。
4. 死锁检测恢复：杀死进程，回收资源。
