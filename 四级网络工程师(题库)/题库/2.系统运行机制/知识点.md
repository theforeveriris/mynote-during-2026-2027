# 系统运行机制

## 考点速记

1. 内核态专属操作：屏蔽中断、关中断操作只能在操作系统内核态下执行；修改内核时钟指令、改变处理器状态等操作也必须在管态（系统态）下执行。
2. 访管中断的触发场景：用户程序在用户态下使用特权指令、调用操作系统提供的文件读写等功能时，首先执行的指令是访管指令，会引发访管中断。
3. 内核态与用户态的定义：是CPU 运行时的状态标志，用于保障操作系统运行安全；内核态（管态）可执行全部指令（特权指令+非特权指令），用户态（目态）仅能执行非特权指令（如算术运算指令）。
4. 状态转换方式：处理器从系统态到用户态（内核态到目态）的转换通过修改程序状态字（PSW）实现；用户进程从用户态转变为内核态需使用访管指令。
5. 系统调用与一般过程调用的差异：①状态归属：系统调用时调用程序在用户态、被调用程序在核心态，过程调用的调用程序和被调用程序均在用户态；②转换机制：系统调用需通过陷入机制实现状态切换，过程调用直接执行；③返回机制：系统调用返回前需运行调度程序，过程调用直接返回；④嵌套使用：二者均支持嵌套使用； ⑤调用限制：系统调用不允许直接调用，过程调用允许直接调用。
6. 系统调用的相关特性：①功能边界：不包含查找数据库信息、查找数组最大值、数据类型转换、求解常数等用户业务逻辑功能；②分类：open()属于文件操作类系统调用；③本质：是操作系统提供给用户程序的服务，可看作“扩充”的机器指令； ④使用前提：用户使用时需先执行访管指令，将目态切换为管态。
7. 系统调用的参数与返回值传递：①有效传递方式：通过寄存器、堆栈、指令自带传递；②无效传递方式：通过变量、管道传递；③返回值传递：通过专用堆栈区传递。
8. 处理器寄存器的可见性：①用户可见寄存器：数据寄存器、地址寄存器、条件码寄存器；②用户不可见寄存器：程序计数器（处理器下一条执行的指令）、指令寄存器、程序状态字寄存器。
9. 程序状态字（PSW）的包含内容：包含进位标志位（CF）、陷阱标志位（TF）、CPU 工作状态码（S）📌<sup>已订正：IF 在本条被重复列为「中断使能位」与「中断屏蔽码」两个字段；上位笔记 1.操作系统概述.md 的 PSW 表中 IF 即中断屏蔽</sup>、条件码（C）、中断屏蔽码（IF）、结果为零标志位（ZF）、符号标志位（SF）、虚拟中断标志位（VIF）、溢出标志位（OF）、虚拟中断待决标志位（VIP）、IO 特权级别位（IOPL）等；不包含保护位（P）、修改位（M）、访问位（R）、驻留位（A）、有效位（A）、运行位（X）、写禁止位（W）、只读位（R）。
10. 处理器运行状态表述：处理器运行时的状态为管态或目态（对应内核态或用户态）。
11. 用户态执行特权指令的后果：用户程序在用户态下取到特权指令时，处理器会停止执行并产生“非法操作”事件。
12. 中断响应顺序的影响因素：中断优先级会影响中断响应的先后顺序。
13. I/O 中断的判定：数据传送完毕、设备出错、键盘输入、光盘读取出错等属于I/O 中断；指令错误不属于I/O 中断。
14. 用户程序关闭中断响应的前提：需首先发起访管中断。
15. 中断相关核心概念定义：①中断请求：外部I/O 设备向处理器发出的信号，（中断控制器向处理器发出的信号）；②中断断点：正在运行程序的暂停点；③中断响应：处理器暂停当前程序转而进入中断处理程序的过程；④中断源：引起中断的设备或事件；⑤中断向量：中断处理程序入口地址；⑥中断字：中断请求的编号。
16. 中断向量表的构成：每一个中断向量由程序状态字（PSW）和指令计数器组成，中断处理程序的入口地址存放在中断向量表中。
17. 中断与异常的区别：①引发原因：中断由外部事件引发，异常由正在执行的指令引发；②典型案例：中断包括串口数据到达、时钟中断、控制台命令、网卡数据缓冲区满、用户按鼠标左键、计时器归零等；异常包括被零除、程序访问变量不在内存、缺页故障、算术溢出、内存保护出错、目态程序执行特权指令等。
18. 中断系统的实现方式：由硬件和软件相互配合实现。
19. DMA 系统的功能实现：DMA 数据传输工作由硬件电路完成。
20. 时钟中断的典型场景：处理系统“心跳”、激活“看门狗”属于时钟中断。
21. 多道程序设计技术的作用：提高CPU 的利用率。
22. 交互式系统的时间片设置：若用户数为100，要求响应时间≤100ms，忽略其他开销，时间片应≤1ms。
23. 用户动态请求和释放系统资源的方式：通过系统调用实现。
24. 与当前运行进程相关的中断类型：程序性中断与当前运行的进程有关。进程和程序的核心区别：①动态性：进程是动态运行的，程序是静态存在的；②组成：进程由指令代码、数据和进程控制块（PCB）组成，程序不包含PCB；③管理主体：进程由操作系统管理，程序由用户管理📌<sup>已订正：与题库第 78 题冲突（该题 A 项「程序由用户管理」为错误项）</sup>；④并发执行：仅进程可并发执行。

## CPU 运行状态（核心概念）

1. 状态类型：内核态（管态）、用户态（目态），本质是CPU 运行时的状态标志。
2. 状态权限。📌<sup>已订正：句末多余空格</sup>内核态：可执行全部指令（特权指令+ 非特权指令），如屏蔽中断、关中断、修 改内核时钟、改变处理器状态。 用户态：仅可执行非特权指令（如算术运算、数据读写），禁止执行特权指令。
3. 状态转换。 用户态→内核态：通过访管指令（用户程序请求系统服务时触发）、系统调用陷入 机制。 内核态→用户态：通过修改程序状态字（PSW）实现。
4. 违规处理：用户态执行特权指令会触发“非法操作” 事件。

## 特权指令与非特权指令

1. 特权指令（仅内核态可执行）：屏蔽中断、关中断、修改内核时钟、设置控制寄存 器、切换栈指针、改变处理器状态。
2. 非特权指令（内核态+ 用户态均可执行）：算术运算、数据寄存器操作、置移位 方向标志、取数指令、移位指令。

## 中断与异常（核心机制）

1. 关键概念 中断源：引起中断的设备或事件（如网卡、打印机）。 中断请求：中断控制器向CPU 发出的触发信号。 中断断点：当前运行程序的暂停位置。 中断响应：CPU 暂停当前程序，转而执行中断处理程序的过程。📌<sup>已订正：括注讲的是「屏蔽中断」而非「中断响应」，错置于本条下（同文件第 14 行已单列「关闭中断响应需先发起访管中断」）</sup> 中断向量：中断处理程序的入口地址，存储在中断向量表中。 中断优先级：影响中断响应顺序，优先级高的先处理。 中断字：中断请求的编号。
3. 中断处理相关 中断系统由硬件+ 软件配合实现，中断处理程序入口地址存于中断向量表。
4. I/O 中断 输入设备：键盘输入、鼠标点击、串口数据到达。 输出设备：打印机缺纸、光盘读取出错、数据传送完毕。 硬件故障：存储器校验出错、设备控制器故障。
5. 时钟中断：与系统运转相关，如处理系统“心跳”、激活“看门狗”。

## 系统调用（用户与内核的接口）

1. 核心特征 调用程序（用户态）→被调用程序（内核态），通过陷入机制实现状态切换。 本质是“扩充的机器指令”，为用户程序提供操作系统服务（如文件操作、进程 控制）。 支持嵌套使用，调用结束后需运行调度程序再返回原程序（与一般过程调用的区 别）。
3. 参数传递方式 支持方式：寄存器传递、堆栈传递、指令自带传递。 不支持方式：变量传递、管道传递、共享文件传递、结构体传递、全局变量传 递、临时文件传递。 返回值传递：通过专用堆栈区实现。
4. 系统调用功能分类 支持功能：文件操作（open/close）、进程控制（创建/ 终止进程、进程休眠）、 通信传输（进程间消息传递、共享内存交换）、临界区互斥锁、目录创建。 不支持功能：查找数据库信息、数组最大值求解、整型→浮点型转换、求解自然 底数e / 摩尔常数M。

## CPU 核心工作与相关部件

1. CPU 组成核心部件：运算器、控制器、寄存器、高速缓存（不含内存）。
2. CPU 核心工作：取指令、执行指令、设置CPU 状态、响应中断请求（不含进程切 换、刷新RAM）。
3. DMA 机制：直接内存访问，由硬件电路完成数据传输，不占用CPU 资源。

## 多选核心汇总

1. CPU 状态刻画：系统态（内核态）、用户态（目态）（不含阻塞态、就绪态、运行 态，后三者是进程状态）。
2. PSW 包含内容：CPU 工作状态码、中断屏蔽码、条件码、陷阱标志位、IO 特权级 别（不含禁止缓存码、访问权限码）。
3. CPU 核心部件：运算器、控制器、寄存器、高速缓存。
4. 中断事件：时钟中断、输入/ 输出中断、控制台中断、硬件故障中断。
5. 异常事件：算术溢出、被零除、缺页故障。

## 多道程序设计技术

1. 核心作用：提高CPU 利用率（通过多程序交替占用CPU，减少空闲时间）。
2. 非直接作用：不直接加快程序运行速度、不保证程序正确性、不减少设备损耗。
