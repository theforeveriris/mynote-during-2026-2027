# Internet基础

## 考点速记

1. Internet 组成：核心组成包括通信线路、路由器、主机、信息资源；路由器是网络间连接桥梁，主机是信息资源载体，集线器不参与IP 协议运行，无法实现异构网络互联。
2. 以太网物理层标准  1000BASE-LX：支持单模光纤，单根光纤最大传输长度5000m；100BASE-FX 支持光纤传输。  IEEE 802.3u：最大传输速率100Mbps；IEEE 802.3 定义CSMA/CD 机制。  100BASE-TX、1000BASE-T、1000BASE-CX 支持屏蔽双绞线（STP）。📌<sup>已订正：介质描述笼统，应指明屏蔽双绞线（上位笔记 7.局域网技术.md）</sup>
3. 无线局域网（IEEE 802.11）：默认电源管理模式为主动模式；AP 通过定期广播信标帧让无线主机发现自身。
4. 交换机带宽计算：半双工端口带宽为端口速率，全双工端口为速率×2，总带宽为所有端口带宽之和。
5. IP 地址与子网划分  子网掩码计算：通过掩码与IP 地址按位与得到网络号，剩余为主机号；如 255.255.255.224、255.255.255.240 为常用子网掩码，需判断同一子网的IP 地址范围。  广播地址：直接广播地址为目标网络号+ 主机号全1，有限广播地址固定为 255.255.255.255；发送广播时源地址为发送主机自身IP。  回送地址：IPv4 的127.0.0.1 用于本地进程通信，IPv6 的0:0:0:0:0:0:0:1 为回送地址。  IPv6：地址128 位，基本头长度40 字节；版本字段为4 比特，值为0110；地址可零压缩，连续0 段用：：表示，且仅能出现一次。
6. IP 数据报  报头格式：报头长度字段以32 位双字为单位，无选项和填充时值为5（对应20 字节）；总长度= 报头长度+ 数据字段长度；标识字段在分片后保持不变，片偏移以8 字节为单位计算。  服务特点：不可靠、无连接、尽最大努力投递，无QoS 保证，不保证报文可靠接收，相同源目地址的报文可能经不同路径传输，路由器不可随意丢弃数据报。  分片与重组：由路由器分片，目的主机负责重组，MTU 规定一个帧最多携带的数据量。  选项：包括严格源路由（指定完整路径）、松散源路由（指定关键路由器）、记录路由（记录途经路由器IP）、时间戳（记录途经路由器时间）。
7. 路由相关  路由表：最长匹配原则，默认路由掩码为0.0.0.0、目的地为0.0.0.0，无匹配路由时使用。  路由协议：RIP 使用向量- 距离算法，存在慢收敛问题（解决对策：保持、毒性逆转、水平分割）；OSPF 使用链路- 状态算法，无慢收敛问题；IGMP 是组播组管理协议，非路由协议，IGMPv2 有快速离开机制，IGMPv3 可指定接收特定组播源报文。  路由器功能：核心为路径选择，连接不同物理网络，屏蔽物理网络差异，转发IP 数据报；接收到首部校验错误的IP 数据报时直接抛弃。
8. ARP 协议：用于获取IP 地址与物理地址的对应关系；请求报文为广播方式，响应报文为单播方式；主机访问不同网段主机时，需先发送ARP 请求获取网关MAC 地址。
9. ICMP 协议：差错报文伴随出错数据报抛弃产生，包含故障数据报部分数据，目的地址为出错报文源地址，无传输优先权；重定向报文用于通知主机非优路径。
10. 网络接入技术  传统调制解调器：通过电话网接入，最高速率56kbps，需数模转换。  ADSL：基于电话线路，非对称（上下行速率不同），需调制解调，适合家庭用户。  HFC：基于有线电视网络，非对称，需调制解调，与有线电视网发展密切相关，适合家庭用户。  共性：ADSL、HFC、传统电话接入均需调制解调器，且ADSL 和HFC 数据传输均可为非对称方式。
11. 传输层协议  TCP：面向连接，三次握手建立连接，四次挥手释放连接；通过窗口机制进行流量控制，重传机制保证可靠性；端口为16 位二进制数。  UDP：无连接，无流量控制和重传机制，端口为16 位二进制数；二者均运行于传输层。
12. · NAT 技术：解决IPv4 地址短缺问题，提高内网安全性；分为静态NAT、动态 NAT、NAPT（多内网主机共用一个公网IP，基于端口区分）；内网主机访问外网时，外网返回报文的源地址为目标外网主机IP，内网主机发送报文的源地址被转换为 NAT 设备公网IP。
13. IP 组播：使用D 类IP 地址（最高4 位1110），组播组成员动态，发送方不必是组成员，非成员也可向组播组发送信息，路由器仅向有组成员的接口转发组播报文。
14. 域名系统（DNS）：提高解析效率的方法：本地域名服务器开始解析、本地主机域名高速缓冲、使用非权威性解析响应；减小资源记录TTL 值会降低解析效率。
15. VLAN：同一交换机上的主机处于不同VLAN 时，无法直接通信（如ping 不通）。
16. IP 协议基础：运行于互联层，定义IP 数据报格式、寻址和路由、分片和重组，屏蔽物理网络差异，向传输层提供统一服务；不定义MAC 地址、以太帧、IEEE 802.11 帧格式，不规定路由器硬件实现方法。
17. IPv4 与IPv6 对比：版本字段均为4 比特，IPv4 值为0100（4），IPv6 值为0110 （6）；IPv4 地址32 位，IPv6 地址128 位。

## 答题技巧

1. win7 系统：A 和B 处于不同子网。Unix 系统;A 和B 处于不同VLAN 中。
2. 计算机A、B 的IP 地址：10.0.0.10；默认路由：10.0.0.1。
3. 计算机E、F 的IP 地址：12.0.0.20；默认路由：12.0.0.1。
4. MAC 地址是b 就选主机C，MAC 地址是c 就选主机B，c 和b 都有选主机D。

## Internet 组成与结构

1. Internet 四部分：通信线路、路由器、主机、信息资源。
2. 核心连接设备：路由器（Router），用于连接异构网络，进行路径选择。
3. 主机：信息资源载体，包含PC、手机、平板；交换机/集线器不属于主机。
4. 从用户视角：信息资源网；从设计视角：IP 互联网（不统一规定物理地址）。
5. Internet 使用IP 协议。

## 以太网标准与传输介质

1. IEEE·802.3：定义CSMA/CD 机制。
2. IEEE·802.3u：快速以太网，100Mbps。
3. 1000BASE-LX：单模光纤，最长5000m。
4. 100BASE-FX：支持光纤介质。
5. 交换机总带宽计算：半双工端口速率直接累加，全双工×2。

## 无线局域网（WLAN）

1. AP·信标帧：定期广播，让无线主机发现网络。
2. IEEE·802.11 默认电源模式：主动模式。

## 接入技术（ADSL/HFC/电话拨号）

1. ADSL：非对称（上下行速率不同）；电话线路；需要调制解调。
2. HFC：非对称速率；有线电视网络；需要调制解调，采用共享信道传输方式。
3. 传统电话拨号：最高速率56kbps。

## IP 协议核心特性

1. 三大特点：不可靠的数据投递服务、面向无连接的传输服务、尽最大努力投递服务。
2. 不提供可靠传输；「不可靠」并不意味着 IP 软件可以随意丢弃报文。📌<sup>已订正：语义倒置，易误读为 IP 可随意丢弃（题库第 97 题 A 项为错项）</sup>
3. 作用：运行在互连层，屏蔽底层物理网络差异，向传输层提供统一服务，具有层次结构，标识互联网设备到互联网的连接。📌<sup>已订正：句尾串接、表述残缺（上位笔记 8.Internet基础.md）</sup>
4. IP 定义内容：数据报格式、寻址、路由、分片重组；不定义硬件/以太帧/MAC。

## IPv4 地址与子网

1. 直接广播地址：主机位全1。
2. 有限广播地址：255.255.255.255，向本地网络广播时使用。
3. IPv4 地址长度32 位。
4. 回送地址：127.0.0.1（本机进程通信）。
5. 组播地址：又称D 类IP 地址，最高4 位1110，成员是动态的并且任意时间可退出 组播组，非组播成员可以发送数据报。
6. IPv4 组播路由协议：DVMRP、MOSPF、PIM。📌<sup>已订正：三者属组播路由协议，非泛指组播协议（上位笔记 8.Internet基础.md）</sup>
7. 子网判断：IP 与掩码按位与结果相同则同子网。
8. VLAN 隔离：不同VLAN 即使同交换机也无法直接通信。

## IP·数据报格式

1. 版本字段：IPv4=4（0100），IPv6=6（0110），版本字段占用的位数都是4 比特。
2. 报头长度：值=5，报头长度=20 字节；
3. 总长度：报头+数据。
4. 头部校验和域：只校验报头，不校验数据区。
5. 标识字段：同一数据报分片后，各分片的标识字段与原 IP 数据报相同。📌<sup>已订正：表述重复残缺</sup>
6. 目的主机：负责分片后重组。
7. 片偏移：以8 字节为单位。

## ICMP 协议

1. 差错报文：伴随抛弃出错IP 数据报产生，不享受高优先级、可靠性。
2. 重定向报文：路由器通知主机使用更优路径。
3. 目的不可达、源抑制、参数问题、超时报文。

## ARP 协议

1. 功能：IP→MAC 地址解析。
2. 请求报名：广播方式；响应报文：单播方式。
3. 高速缓存：减少广播，提高解析效率。
4. 计时器：保证ARP 表项的有效性。

## 路由协议

1. RIP：向量-距离（V-D）算法，通过跳数度量；
2. RIP 解决慢收敛问题策略。 水平分割：不从接收接口发回该路由。 毒性逆转：把不可达路由标记为16 跳发回。 保持对策：一段时间不更新坏路由。 触发更新：路由变化立即发送，不等30 秒。
3. OSPF：链路-状态（L-S）算法，无环路，OSPF 通常比RIP 收敛快，复杂度高。
4. 默认路由：掩码0.0.0.0，无匹配路由时使用。
5. RIP、OSPF：都适用于动态互联网环境、多路径互联网环境；OSPF 适用大规模互联 网环境。

## IPv6

1. 基本头固定长度：40 字节。
2. IPv6 地址长度128 位。
3. 地址类型：单播地址、组播地址、任播地址、特殊地址。
4. 回送地址：::1。
5. 路由扩展头：指定转发路径。
6. IPv6 研究动机：基于IPv4 地址空间不足，IPv4 性能可以提高，IPv4 地址配置繁琐、 IPv4 的QoS 机制提供的功能有限。

## NAT 技术

1. 作用：缓解IPv4 地址不足，提高内网安全，不可以加速P2P 应用数据传输。
2. 类型：静态NAT、动态NAT 和网络地址端口转换NAPT。
3. NAPT：多内网主机共享1 个公网IP（端口区分）。
4. 外出源IP：替换为NAT 公网IP；回复目的IP：不变。

## 组播组管理

1. CGMP、IGMP。
2. IGMP：组播组管理协议，非路由协议；负责成员的加入或退出工作。 IGMPv1:定义了基本的组成员查询和报告过程。 IGMPv2：在IGMPv1 基础上加了组成员快速离开机制。 IGMPv3：目前最常用的，可指定是否接收组播源。 IGMP·Snooping：二层设备优化组播转发。

## 传输层协议

1. TCP：面向连接、三次握手、窗口进行流量控制、可靠传输，重发解决可靠性问题， 采用自适应的RTT 计算方法，RTT 的值不同。
2. UDP：面向无连接、不可靠、开销小、运行于传输层。
3. 端口号：16 位二进制。

## IP 选项

1. 严格源路由：必须走指定完整路径。
2. 松散源路由：必须经过指定路由。
3. 记录路由：记录经过的路由器IP。
4. 时间戳：记录经过时间。

## MTU（最大传输单元）

1. 规定一个帧可携带的最大数据量。
2. 超过MTU 则IP 分片，目的主机重组。
