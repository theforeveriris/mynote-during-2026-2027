# 网络技术基础

## 考点速记

1. 操作系统核心特征：随机性（如内核进程切换具有随机性，陷阱调用、设备申请、时钟维护无随机性）
2. 操作系统核心管理功能：处理器管理、存储器管理、外设（显卡等）管理；不包含 IP 地址上网资格管理、病毒查杀
3. 经典操作系统分类及特性  Unix 系统：典型分时多用户系统，最初针对小型机，首个版本为汇编语言编写；代表产品有Solaris、HP-UX、AIX；非微软开发，无统一公司维护，COSE 组织推动其标准化  Linux 系统：开源系统，核心为内核，可提供图形界面，多主体维护；代表产品有 Debian、Red Hat、Ubuntu（Ubuntu 非Unix）  Windows 系统：微软开发，带图形界面，不开源，支持网络功能；代表版本有Vista、 Windows7/8/XP/NT/Server2003，其中NT/Server2003 适用于服务器端，非Unix 变种
4. Linux 系统核心组成：内核是核心部分，区别于外壳、X 桌面、Web 服务器等组件

### 二、计算机网络发展与经典网络

1. 网络发展里程碑：ARPANET（美国国防部资助，分组交换技术核心成果，资源子网+ 通信子网二级结构，互联网基础，非无线自组网，最初4 个节点，IMP 为早期转发节点）；第一阶段核心是分组交换技术，计算机与通信技术结合
2. 网络分类及典型技术  广域网（WAN）：覆盖≥100 公里，电信部门组建，核心交换技术为研究重点，拓扑多用网状，组网技术有X.25、ATM、帧中继；不使用蓝牙，非双绞线为主要传输介质  城域网（MAN）：覆盖城市范围，综合业务数据网，政府/ 电信组建，FDDI 为早期主流组网技术，英文缩写非CAN，非卫星信道为骨干  局域网（LAN）：典型技术有Ethernet、Token Ring、Token Bus；Ethernet 为总线型，CSMA/CD 介质访问控制，帧为传输单元，共享介质易冲突  个人区域网（PAN）：无线通信技术为主，覆盖范围最小；典型技术有Bluetooth、 ZigBee、IEEE 802.15.4、6LoWPAN；不包含WDM、IEEE 802.16
3. 经典网络技术：ALOHANET 是随机争用型介质访问控制方法的起源；FDDI 为光纤传输，早期城域网技术，双向环网结构

### 三、网络体系结构与参考模型

1. OSI 参考模型：ISO 制定，7 层结构，低层为高层提供服务，高层屏蔽低层实现，同节点同等层功能相同，不同节点层次结构一致；各层核心功能：物理层：传输介质实现比特流透明传输，最底层数据链路层：将有差错物理线路转为无差错数据链路网络层：路由选择、数据传输路径选择，不做介质访问控制；传输层📌<sup>已订正：两层功能串接、缺标点与主语（同句后半截「传输层」被吞）</sup>：不同应用进程端到端通信，提供分布式进程通信会话层/ 表示层/ 应用层：会话管理、数据格式变换、网络应用提供
2. TCP/IP 参考模型：IETF 制定，层次少于OSI，低层为高层服务；核心层次及功能：  主机- 网络层：对应OSI 物理层+ 数据链路层，最底层非物理层  互联层：对应OSI 网络层，处理IP 分组，实现路由选择  传输层：对应OSI 传输层，端到端可靠服务，支持TCP（面向连接）、UDP（无连接），无路由选择功能  应用层：最高层，相邻层为传输层
3. 模型核心原则：分层结构，上层使用相邻下层服务，每层包含多种协议

### 四、网络拓扑结构

1. 星型拓扑：中心节点集中控制，所有通信经中心节点，中心节点为可靠性瓶颈
2. 环型拓扑：节点闭合环路，无中心节点，数据顺序传输，传输延时固定，WLAN 非该拓扑，节点故障影响整个环，有节点退出机制
3. 总线型拓扑：共享传输介质，节点广播发送数据，需解决介质访问控制，非树形拓扑的扩展
4. 树形拓扑：按层次组织节点连接，非共享叶子结点，是总线拓扑的扩展
5. 网状拓扑：节点连接无规律，无中心节点，需执行路径选择，结构复杂，传输延时不固定，为当前广域网主流拓扑
6. 拓扑核心特性：环型延时固定，星型有中心瓶颈，网状无规则，总线型共享介质

### 五、网络交换技术

1. 线路交换：通信双方预先建立物理连接
2. 虚电路交换：预先建立逻辑连接（临时），数据分组沿虚电路传输，无需重复路由选择，分组无需携带源/ 目的地址，接收顺序与发送顺序一致
3. 数据报交换：存储转发方式，无需预先建立连接，分组需携带源/ 目的地址，同一报文的分组可经不同路径传输，接收顺序可能与发送顺序不一致

### 六、网络协议

1. 协议三要素：语法（控制信息的结构/ 格式定义）、语义、时序（事件实现顺序）
2. 协议层次与分类：网络层协议代表为IP、ICMP；传输层协议为TCP、UDP；应用层协议如FTP
3. 协议核心特性：开放标准，独立于特定硬件，不依赖特定操作系统，有统一网络地址分配方案

### 七、无线网络与物联网

1. 无线自组网（Ad hoc）：对等结构，无固定基站/ 基础设施，节点可移动，英文缩写非WSN，可用于军事领域
2. 无线传感器网（WSN）：特殊的无线自组网，节点以传感器为主，自组织形成网络，拓扑动态可变，数据可多跳传输，用于采集物理世界信息，可用于军事领域，非互联网形成基础
3. 物联网（IoT）：基于Internet 技术，利用传感器等感知技术获取信息，非仅物与物互联，是智能信息系统
4. 无线技术分类：  个人区域网：Bluetooth、ZigBee、IEEE 802.15.4  城域网/ 广域无线：IEEE 802.16（覆盖范围最大）  无线局域网（WLAN）：可采用红外、跳频扩频、窄带微波、直接序列扩频技术  扩频技术：跳频扩频可使用专用ISM 频段，通信双方频段一致

### 八、网络性能指标与计算

1. 数据传输速率：单位为bps（比特/ 秒）；换算关系：1Kbps=10³bps，1Mbps=10⁶ bps，1Gbps=10⁹bps，1Tbps=10¹²bps
2. 奈奎斯特准则：二进制信号，最大传输速率= 2× 信道带宽（Hz），如5000Hz 带宽对应10kbps
3. 误码率：二进制数据在通信系统中传错的概率，衡量正常传输状态的可靠性，与系统造价相关；电话线误码率高于光纤

### 九、典型网络设备与节点

1. WSN 节点：传感器节点负责采集信息，区别于服务器、管理器、网关、中继器、路由器节点
2. 物联网设备：传感器节点实现物理世界信息的自动获取
3. ARPANET 设备：IMP 为通信子网早期转发节点

## 计算机网络发展与分类

1. 网络发展关键技术：第一阶段核心为分组交换技术，ARPANET 是互联网的基础，为广域网（美国国防部资助，非无线自组网，提出资源子网+通信子网二级结构）📌<sup>已订正：漏字，读来不通</sup>ARPANET 通信子网转发节点：IMP。
2. 计算机网络定义：核心特征是网络资源共享，联网计算机需遵循相同协议，无明确 主从关系。
3. 网络按覆盖范围分类（从小到大）：个人区域网（PAN）、局域网（LAN）、城域网 （MAN）、广域网（WAN），各类型核心特征与组网技术。 广域网(WAN)：ARPANET，组网技术含X.25、ATM、帧中继。 城域网(MAN)：覆盖城市范围，政府或电信公司建立、综合业务传输，FDDI 为早期 主流组网技术。 局域网(LAN)：Ethernet、Token·Ring、Token·Bus。 个人区域网(PAN)：基于蓝牙、ZigBee（IEEE-802.15.4），ZigBee 也用于无线传感 器网，WDM 不用于个人区域网。
4. 特殊网络： 无线自组网（Ad·hoc）：无固定基站、无基础设施，节点对等、可移动。 无线传感器网（WSN）：特殊自组网，节点为传感器，自组织、多跳传输，拓扑动 态变化、传感器节点实现物理世界信息自动获取，采集信息。 物联网：基于Internet，利用传感器获取物理信息，非仅物物互联。 宽带城域网：互联多种网络，支持综合业务，由政府/电信公司组建。

## 网络体系结构与参考模型

1. OSI 参考模型：由ISO 制定，七层结构，（应用层、表示层、会话层、传输层、网 络层、数据链路层、物理层）低层为高层提供服务，高层屏蔽低层实现，同节点同 等层功能相同，不同节点层次一致。
2. TCP/IP 参考模型：由IETF 制定，四层结构（应用层、传输层、互联层、主机-网络 层），层次少于OSI 模型。
3. 两大模型层对应关系： TCP/IP 传输层↔OSI 传输层。 TCP/IP 互联层↔OSI 网络层。 TCP/IP 主机-网络层↔OSI 物理层与数据链路层。
4. 模型核心层功能： 物理层：通过传输介质实现透明比特流传输。 数据链路层：将有差错物理线路转换为无差错数据链路。 网络层（OSI）/互联层（TCP/IP）：路由选择、路径选择，IP 分组处理，非介质访 问控制。 传输层：提供可靠端到端通信、分布式进程通信，支持TCP（面向连接）/UDP（无 连接），无路由选择功能。 应用层：提供各类网络应用。

## 操作系统基础

1. 操作系统核心特征：随机性（内核进程切换）。
2. 操作系统核心管理功能：处理器、存储器、显卡等硬件资源管理；不含IP 地址分 配、病毒查杀等功能。
3. 经典操作系统分类与特性： Unix 系统：Solaris、HP-UX、AIX 为其版本，分时多用户结构，首个版本由汇编编 写，非微软开发。 Linux 系统：开源，核心为内核，Debian、Red·Hat 为其版本，非单一公司维护。 Windows 系统：微软开发，图形界面，非开源，Vista 是该系统，支持网络功能（如 Windows·NT/Server·2003）Windows·NT 是不对等结构。
4. Linux 系统核心组成：内核是核心部分，区别于外壳、桌面等组件。

## 网络协议与数据交换

1. 网络协议三要素：语法（控制信息结构/格式）、语义、时序（事件实现顺序）； 协议常采用层次结构，是网络数据交换的规则标准。
2. 网络层典型协议：IP、ICMP。
3. 数据交换技术： 线路交换：需建立物理连接。 虚电路交换：需预先建立逻辑连接，分组无需携带完整源/目的地址，接收分组顺 序与发送一致。 数据报交换：存储转发，无需建立连接，分组需带源/目的地址，同报文分组可经 不同路径，接收顺序可能与发送不一致。
4. 介质访问控制： 随机争用型起源于ALOHANET。 共享介质以太网（CSMA/CD）：总线型，数据传输可能冲突，结点发送前侦听总线。 环型网：令牌控制，无冲突。

## 网络拓扑结构

1. 核心拓扑类型及特征： 星型：中心结点集中控制，通信经中心结点，中心结点为可靠性瓶颈。 环型：无中心结点，节点闭合环路，数据顺序传输，延时固定，任一节点故障影响 全网，非WLAN 常用拓扑。 总线型：共享传输介质，结点广播发送数据，需解决介质访问控制。 网状：无规则连接，无中心结点，需执行路径选择，结构复杂，为当前广域网主流 拓扑；无线网状网缩写WMN。 树型：按层次组织节点，是总线拓扑的扩展。
2. 拓扑关键特性：传输延时（环型固定、网状不固定）、节点关系（网状/Ad·hoc 节点对等）、维护难度（环型维护复杂）。

## 网络性能指标与传输技术

1. 数据传输速率：单位为bps；换算关系：1Gbps=1000Mbps，1Tbps=10^12bps，1B=8bit。
2. 奈奎斯特准则：二进制信号，信道最大传输速率=2×信道带宽（Hz）。
3. 误码率：二进制数据在通信系统中传错的概率，衡量传输可靠性，与系统造价相关， 电话线误码率高于光纤。
4. 无线传输技术： 跳频扩频：可使用ISM 频段，通信双方频段协调。 无线局域网（WLAN）：可采用红外、跳频扩频、窄带微波、直接序列扩频
