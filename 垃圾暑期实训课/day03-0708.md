## 1. 继承

### 1.1 继承概述

#### 1.1.1 什么是继承？

继承是面向对象的三大特性之一，它允许一个类（子类/派生类）获取另一个类（父类/基类）的属性和方法。

**继承的好处**：
- **代码复用**：子类可以直接使用父类的属性和方法
- **扩展性**：子类可以在父类基础上添加新的属性和方法
- **层次结构**：可以建立类的层次关系，更好地组织代码

**语法**：
```java
class 子类 extends 父类 {
    // 子类的属性和方法
}
```

#### 1.1.2 继承示例

```java
// 父类：动物类
public class Animal {
    public String name;

    public void eat() {
        System.out.println(name + "吃东西");
    }
}

// 子类：狗类，继承自动物类
public class Dog extends Animal {
    // 子类特有方法
    public void bark() {
        System.out.println(name + "汪汪叫");
    }
}

// 测试类
public class Test04 {
    public static void main(String[] args) {
        Dog dog = new Dog();
        dog.name = "旺财";
        
        // 调用继承的方法
        dog.eat();   // 输出：旺财吃东西
        
        // 调用子类特有方法
        dog.bark();  // 输出：旺财汪汪叫
    }
}
```

#### 1.1.3 继承的特点

| 特点 | 说明 |
|------|------|
| 单继承 | Java只支持单继承，一个子类只能有一个直接父类 |
| 多层继承 | 支持多层继承，子类可以作为其他类的父类 |
| 传递性 | 子类继承父类的所有非private属性和方法 |
| 不能继承 | 构造方法、private成员、static成员（静态成员属于类，不是继承） |

#### 1.1.4 访问修饰符与继承

| 修饰符 | 同一类 | 同一包 | 子类 | 不同包 |
|--------|--------|--------|------|--------|
| private | √ | × | × | × |
| 默认（包访问权限） | √ | √ | × | × |
| protected | √ | √ | √ | × |
| public | √ | √ | √ | √ |

### 1.3 super关键字

#### 1.3.1 super关键字的作用

`super` 关键字用于在子类中访问父类的成员（属性、方法、构造方法）。

| 用法 | 说明 |
|------|------|
| `super.属性` | 访问父类的属性 |
| `super.方法()` | 调用父类的方法 |
| `super()` | 调用父类的构造方法 |

#### 1.3.2 访问父类属性和方法

```java
// 父类
public class Father {
    String name = "父类";

    public Father(String name) {
        this.name = name;
        System.out.println("父类构造:" + name);
    }

    public void show() {
        System.out.println("父类show");
    }
}

// 子类
public class Son extends Father {
    String name = "子类";

    public Son() {
        super("父类");  // 调用父类有参构造
    }

    public void print() {
        System.out.println(super.name);   // 访问父类name
        super.show();                     // 调用父类show方法
    }
}

// 测试类
public class Test05a {
    public static void main(String[] args) {
        Son son = new Son();
        System.out.println("子类name:" + son.name);  // 访问子类name
        son.print();
    }
}
```

**输出结果**：
```
父类构造:父类
子类name:子类
父类
父类show
```

#### 1.3.3 调用父类构造方法

```java
// 父类
public class Animal2 {
    String type = "动物";

    public Animal2(String type) {
        System.out.println("父类:" + type);
    }
}

// 子类
public class Cat extends Animal2 {
    String type = "小猫";

    public Cat() {
        super("哺乳类");  // 必须是构造方法的第一条语句
    }

    public void test() {
        System.out.println("父类type:" + super.type);
        System.out.println("子类type:" + this.type);
    }
}

// 测试类
public class Test07 {
    public static void main(String[] args) {
        Cat c = new Cat();
        c.test();
    }
}
```

**输出结果**：
```
父类:哺乳类
父类type:动物
子类type:小猫
```

**注意事项**：
- `super()` 必须是构造方法的第一条语句
- 如果子类构造方法中没有显式调用 `super()`，Java会自动调用父类的无参构造方法
- 如果父类没有无参构造方法，子类必须显式调用父类的有参构造方法

## 2. 方法重写

### 2.1 方法重写概述

#### 2.1.1 什么是方法重写？

方法重写（Override）是指子类重新定义父类中已有的方法，使得子类对象调用该方法时执行子类的实现而非父类的实现。

**方法重写的条件**：
1. 方法名相同
2. 参数列表相同（个数、类型、顺序）
3. 返回值类型相同或为其子类（Java 5及以上）
4. 访问修饰符不能比父类更严格

#### 2.1.2 方法重写示例

```java
// 父类
public class Animal3 {
    public String name;

    public void eat() {
        System.out.println(name + "吃东西");
    }

    public void shout() {
        System.out.println("动物发声");
    }
}

// 子类：重写shout方法
public class Dog extends Animal3 {
    public void bark() {
        System.out.println(name + "汪汪叫");
    }

    // 重写父类的shout方法
    @Override
    public void shout() {
        System.out.println("小狗汪汪叫");
    }
}

// 测试类
public class Test08 {
    public static void main(String[] args) {
        Animal3 a = new Animal3();
        a.shout();  // 调用父类方法：动物发声

        Dog dog = new Dog();
        dog.shout();  // 调用子类重写的方法：小狗汪汪叫
    }
}
```

#### 2.1.3 @Override注解

`@Override` 是一个注解，用于标识该方法是重写父类的方法。

**作用**：
- 编译器检查：如果方法签名与父类不匹配，编译器会报错
- 代码可读性：明确标识该方法是重写方法

#### 2.1.4 方法重写的注意事项

1. **私有方法不能被重写**：父类的private方法对子类不可见
2. **静态方法不能被重写**：静态方法属于类，不是实例方法
3. **final方法不能被重写**：final修饰的方法是最终方法，不能被修改
4. **构造方法不能被重写**：构造方法是特殊方法，不能被继承和重写

## 3. 多态

### 3.1 多态概述

#### 3.1.1 什么是多态？

多态是面向对象的三大特性之一，指同一个方法调用可以根据对象的实际类型产生不同的行为。

**多态的条件**：
1. 存在继承关系
2. 子类重写父类方法
3. 父类引用指向子类对象

**语法**：
```java
父类类型 引用变量 = new 子类类型();
```

#### 3.1.2 多态示例

```java
// 父类
package com.huaishida.test0708.pro2;

public class Animal4 {
    public void shout() {
        System.out.println("动物发声");
    }
}

// 子类：Cat
package com.huaishida.test0708.pro2;

public class Cat extends Animal4 {
    @Override
    public void shout() {
        System.out.println("小猫喵喵叫");
    }
}

// 子类：Dog
package com.huaishida.test0708.pro2;

public class Dog extends Animal4 {
    @Override
    public void shout() {
        System.out.println("小狗汪汪叫");
    }
}

// 测试类
package com.huaishida.test0708.pro2;

public class Test22 {
    public static void main(String[] args) {
        // 父类引用指向子类对象
        Animal4 a1 = new Cat();
        Animal4 a2 = new Dog();

        // 调用shout方法，实际执行的是子类的实现
        a1.shout();  // 输出：小猫喵喵叫
        a2.shout();  // 输出：小狗汪汪叫
    }
}
```

#### 3.1.3 多态的好处

1. **代码灵活性**：可以编写通用代码，适配不同类型的对象
2. **扩展性**：添加新的子类不需要修改原有代码
3. **解耦合**：降低代码之间的依赖关系

### 3.2 多态的应用：图形面积计算

```java
// 父类：Shape
package com.huaishida.test0708.pro2;

public class Shape {
    public double getArea() {
        System.out.println("计算图形的面积");
        return 0.0;
    }
}

// 子类：Circle
package com.huaishida.test0708.pro2;

public class Circle extends Shape {
    private double r;

    public Circle(double r) {
        this.r = r;
    }

    @Override
    public double getArea() {
        return 3.14 * r * r;
    }
}

// 子类：Rect
package com.huaishida.test0708.pro2;

public class Rect extends Shape {
    private double w, h;

    public Rect(double w, double h) {
        this.w = w;
        this.h = h;
    }

    @Override
    public double getArea() {
        return w * h;
    }
}

// 测试类
package com.huaishida.test0708.pro2;

public class Test3 {
    public static void main(String[] args) {
        Rect rect = new Rect(10, 20);
        System.out.println("矩形的面积是：" + rect.getArea());  // 输出：200.0

        Circle circle = new Circle(10);
        System.out.println("圆形的面积是：" + circle.getArea());  // 输出：314.0
    }
}
```

### 3.3 多态中的成员访问

#### 3.3.1 成员变量的访问

在多态中，成员变量的访问取决于引用变量的类型，而不是对象的实际类型。

```java
class Parent {
    int x = 10;
}

class Child extends Parent {
    int x = 20;
}

public class Test {
    public static void main(String[] args) {
        Parent p = new Child();
        System.out.println(p.x);  // 输出：10（访问的是父类的x）
    }
}
```

#### 3.3.2 成员方法的访问

在多态中，成员方法的调用取决于对象的实际类型（运行时多态）。

```java
class Parent {
    void show() {
        System.out.println("Parent show");
    }
}

class Child extends Parent {
    void show() {
        System.out.println("Child show");
    }
}

public class Test {
    public static void main(String[] args) {
        Parent p = new Child();
        p.show();  // 输出：Child show（调用的是子类的show方法）
    }
}
```

### 3.4 向下转型

#### 3.4.1 什么是向下转型？

向下转型是将父类引用转换为子类类型。

**语法**：
```java
子类类型 变量 = (子类类型) 父类引用;
```

#### 3.4.2 向下转型示例

```java
Animal4 a = new Dog();  // 向上转型（自动）

// 向下转型（需要显式转换）
Dog dog = (Dog) a;
dog.bark();  // 调用子类特有方法
```

#### 3.4.3 instanceof运算符

`instanceof` 用于判断一个对象是否是某个类（或其子类）的实例。

```java
if (a instanceof Dog) {
    Dog dog = (Dog) a;
    dog.bark();
} else if (a instanceof Cat) {
    Cat cat = (Cat) a;
    cat.meow();
}
```

## 课程总结

### 重点知识回顾

1. **继承**：子类获取父类的属性和方法，使用 `extends` 关键字
2. **super关键字**：访问父类的属性、方法和构造方法
3. **方法重写**：子类重新定义父类方法，使用 `@Override` 注解
4. **多态**：父类引用指向子类对象，调用方法时执行子类实现
5. **向上转型**：自动转换，父类引用指向子类对象
6. **向下转型**：显式转换，需要使用 `instanceof` 检查

### 常见错误与注意事项

1. **父类无参构造缺失**：自定义有参构造后，默认无参构造会消失
2. **super()位置错误**：必须是构造方法的第一条语句
3. **方法重写签名不匹配**：方法名、参数列表必须完全一致
4. **访问修饰符冲突**：子类重写方法的访问修饰符不能更严格
5. **向下转型异常**：需要使用 `instanceof` 检查，否则可能抛出ClassCastException

### 学习建议

1. 理解继承、封装、多态三大特性的本质
2. 多练习方法重写和多态的实现
3. 掌握super和this关键字的区别
4. 理解向上转型和向下转型的应用场景
5. 尝试使用多态设计可扩展的代码
