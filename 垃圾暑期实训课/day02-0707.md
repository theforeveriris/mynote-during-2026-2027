## 1. 集合进阶

### 1.1 ArrayList进阶：删除元素注意事项

**需求**：使用ArrayList存储学生姓名，删除长度小于3的名字。

```java
import java.util.ArrayList;

public class Test01 {
    public static void main(String[] args) {
        ArrayList<String> list = new ArrayList<>();

        list.add("张三");
        list.add("李四");
        list.add("王五五");
        list.add("赵六六");

        // 关键：从后往前遍历删除，避免元素遗漏
        for (int i = list.size() - 1; i >= 0; i--) {
            String name = list.get(i);

            if (name.length() < 3) {
                list.remove(i);
            }
        }

        System.out.println("过滤后:" + list);  // 输出：[王五五, 赵六六]
    }
}
```

**为什么要从后往前遍历？**

当我们从前往后遍历并删除元素时，会导致后续元素的索引发生变化，从而跳过某些元素：

```
原始列表：[张三, 李四, 王五五, 赵六六]
索引：     0     1      2      3

第1次循环(i=0)：删除"张三"，列表变为[李四, 王五五, 赵六六]
索引：          0       1       2

第2次循环(i=1)：此时访问的是"王五五"，跳过了"李四"！
```

**解决方案**：
- 从后往前遍历：`for (int i = list.size() - 1; i >= 0; i--)`
- 使用迭代器（Iterator）进行安全删除

### 1.2 LinkedList

`LinkedList` 是List的另一个实现类，底层基于**双向链表**实现。

#### 1.2.1 LinkedList特点

| 特性 | ArrayList | LinkedList |
|------|-----------|------------|
| 底层结构 | 动态数组 | 双向链表 |
| 查询速度 | 快（O(1)） | 慢（O(n)） |
| 增删速度 | 慢（需移动元素） | 快（只需修改指针） |
| 内存占用 | 连续内存，内存碎片少 | 每个节点额外存储指针，内存开销大 |
| 适用场景 | 读多写少 | 写多读少 |

#### 1.2.2 LinkedList常用操作

```java
import java.util.LinkedList;

public class Test02 {
    public static void main(String[] args) {
        LinkedList<Integer> link = new LinkedList<>();

        // 添加元素到末尾
        link.add(10);
        link.add(20);

        // 添加元素到头部
        link.addFirst(5);

        // 添加元素到尾部
        link.addLast(30);

        System.out.println(link);  // 输出：[5, 10, 20, 30]

        // 获取首元素
        System.out.println("首元素:" + link.getFirst());  // 输出：5

        // 获取尾元素
        System.out.println("尾元素:" + link.getLast());   // 输出：30
    }
}
```

#### 1.2.3 LinkedList特有方法

| 方法 | 功能说明 |
|------|---------|
| `addFirst(E e)` | 在列表头部添加元素 |
| `addLast(E e)` | 在列表尾部添加元素 |
| `getFirst()` | 获取首元素 |
| `getLast()` | 获取尾元素 |
| `removeFirst()` | 删除并返回首元素 |
| `removeLast()` | 删除并返回尾元素 |

### 1.3 Set集合

Set集合的特点：**无序、不可重复、无索引**。

#### 1.3.1 HashSet

`HashSet` 是Set的主要实现类，底层基于哈希表实现。

```java
import java.util.HashSet;

public class Test03 {
    public static void main(String[] args) {
        HashSet<String> set = new HashSet<>();

        set.add("苹果");
        set.add("香蕉");
        set.add("橘子");
        set.add("苹果");  // 重复元素，不会被添加

        for (String fruit : set) {
            System.out.println(fruit);
        }
    }
}
```

**输出结果**（顺序不确定，因为HashSet无序）：
```
苹果
香蕉
橘子
```

#### 1.3.2 练习：数组去重

**需求**：定义数组{10, 20, 10, 30, 20, 40}，使用Set完成去重。

```java
import java.util.HashSet;

public class Test04 {
    public static void main(String[] args) {
        int[] arr = {10, 20, 10, 30, 20, 40};

        HashSet<Integer> set = new HashSet<>();

        // 将数组元素添加到Set中，自动去重
        for (int num : arr) {
            set.add(num);
        }

        System.out.println("过滤后数据:" + set);  // 输出：[20, 40, 10, 30]
    }
}
```

**HashSet去重原理**：
1. 调用元素的 `hashCode()` 方法计算哈希值
2. 根据哈希值确定存储位置
3. 如果该位置已有元素，调用 `equals()` 方法比较是否相等
4. 相等则不添加，不相等则添加到链表或红黑树中

### 1.4 Map集合

Map是双列集合，一次存储一对键值对（key-value）。

#### 1.4.1 HashMap

`HashMap` 是Map的主要实现类，具有以下特点：
- key必须唯一，value可以重复
- 无序存储
- 允许key和value为null（key只能有一个null）

```java
import java.util.HashMap;

public class Test05 {
    public static void main(String[] args) {
        HashMap<Integer, String> map = new HashMap<>();

        // 添加键值对
        map.put(1001, "张三");
        map.put(1002, "李四");
        map.put(1003, "王五");
        map.put(1001, "赵六");  // key重复，覆盖之前的值
        map.put(1004, "张三");  // value可以重复

        // 获取值
        System.out.println(map.get(1001));  // 输出：赵六（已被覆盖）

        // 删除键值对
        map.remove(1002);

        // 判断key是否存在
        System.out.println(map.containsKey(1003));  // 输出：true

        // 遍历所有value
        for (String value : map.values()) {
            System.out.println(value);  // 输出：赵六、王五、张三
        }
    }
}
```

#### 1.4.2 HashMap常用方法

| 方法 | 功能说明 |
|------|---------|
| `put(K key, V value)` | 添加或更新键值对 |
| `get(Object key)` | 根据key获取value |
| `remove(Object key)` | 删除指定key的键值对 |
| `containsKey(Object key)` | 判断key是否存在 |
| `containsValue(Object value)` | 判断value是否存在 |
| `size()` | 获取键值对数量 |
| `values()` | 返回所有value的集合 |
| `keySet()` | 返回所有key的集合 |

#### 1.4.3 练习：字符统计

**需求**：统计字符串中每个字符出现的次数。

```java
import java.util.HashMap;

public class Test06 {
    public static void main(String[] args) {
        String str = "aabbcccdddd";

        HashMap<Character, Integer> countMap = new HashMap<>();

        for (int i = 0; i < str.length(); i++) {
            char c = str.charAt(i);

            if (countMap.containsKey(c)) {
                // 字符已存在，计数+1
                Integer value = countMap.get(c);
                value++;
                countMap.put(c, value);
            } else {
                // 字符不存在，初始化计数为1
                countMap.put(c, 1);
            }
        }
        
        System.out.println("字符统计:" + countMap);  // 输出：{a=2, b=2, c=3, d=4}
    }
}
```

## 2. 面向对象编程基础

### 2.1 面向对象概述

#### 2.1.1 什么是面向对象？

面向对象（Object-Oriented Programming, OOP）是一种编程范式，将数据和操作数据的方法封装在一起，以对象为基本单元。

**核心概念**：
- **类（Class）**：模板、蓝图，描述一类事物共同的属性和行为
- **对象（Object）**：类的实例，根据类创建出来的个体
- **属性（Attribute）**：对象的特征，如姓名、年龄、颜色等
- **方法（Method）**：对象的行为，如学习、跑步、打电话等

**类与对象的关系**：
- 类是抽象的，对象是具体的
- 一个类可以创建多个对象
- 每个对象拥有类定义的属性和方法

#### 2.1.2 现实世界类比

| 面向对象概念 | 现实世界类比 | 示例 |
|-------------|------------|------|
| 类 | 汽车设计图纸 | 汽车类 |
| 对象 | 具体的汽车 | 红色宝马、黑色奔驰 |
| 属性 | 汽车特征 | 品牌、颜色、价格 |
| 方法 | 汽车功能 | 启动、加速、刹车 |

### 2.2 类的定义与对象创建

#### 2.2.1 定义类

```java
class Student {
    // 属性（成员变量）
    String no;      // 学号
    int age;        // 年龄
    String name;    // 姓名
    String tel;     // 电话

    // 方法（成员方法）
    public void study() {
        System.out.println(name + "正在学习，今年" + age + "岁");
    }

    public void play() {
        System.out.println(name + "正在玩耍");
    }
}
```

#### 2.2.2 创建对象并使用

```java
public class Test07 {
    public static void main(String[] args) {
        // 创建对象：类名 对象名 = new 类名();
        Student stu = new Student();
        
        // 给对象属性赋值
        stu.name = "张三";
        stu.age = 20;
        stu.no = "20231204090";
        stu.tel = "13800138000";

        // 调用对象方法
        stu.study();   // 输出：张三正在学习，今年20岁
        stu.play();    // 输出：张三正在玩耍
    }
}
```

#### 2.2.3 对象创建过程

```
Student stu = new Student();

1. 声明引用变量：Student stu
   - 在栈内存中创建一个引用变量stu
   - 此时stu的值为null

2. 创建对象：new Student()
   - 在堆内存中分配空间
   - 默认初始化成员变量（数值类型为0，引用类型为null）
   - 返回对象的内存地址

3. 赋值：=
   - 将堆内存地址赋值给栈中的stu变量
   - stu指向堆中的对象
```

#### 2.2.4 多个对象的独立性

```java
public class Test07 {
    public static void main(String[] args) {
        // 创建两个独立的对象
        Student stu1 = new Student();
        Student stu2 = new Student();

        // 每个对象有独立的内存地址
        System.out.println("stu1:" + stu1);  // 输出：Student@2ff4acd0
        System.out.println("stu2:" + stu2);  // 输出：Student@38af3868

        // 给stu1赋值
        stu1.no = "001";
        stu1.age = 18;
        stu1.name = "张三";
        stu1.tel = "12345678901";

        stu1.study();  // 输出：张三正在学习，今年18岁
        stu1.play();   // 输出：张三正在玩耍

        // stu2未赋值，使用默认值
        stu2.study();  // 输出：null正在学习，今年0岁
        stu2.play();   // 输出：null正在玩耍
    }
}
```

**关键点**：每个对象在堆内存中是独立的，修改一个对象的属性不会影响另一个对象。

### 2.4 封装

#### 2.4.1 什么是封装？

封装是面向对象的三大特性之一（封装、继承、多态），它指的是：
- **隐藏内部细节**：将属性私有化，外部无法直接访问
- **对外提供安全访问入口**：通过公共的getter和setter方法访问属性
- **在接口中添加逻辑判断**：可以控制属性的赋值范围

#### 2.4.2 封装的实现步骤

1. 使用 `private` 修饰成员变量，私有化
2. 提供公共的 `getXXX()` 方法获取属性值
3. 提供公共的 `setXXX()` 方法设置属性值
4. 在setter方法中添加逻辑判断

#### 2.4.3 封装示例

```java
class Person {
    // 私有化成员变量
    private String name;
    private int age;

    // getter方法：获取name
    public String getName() {
        return name;
    }

    // setter方法：设置name
    public void setName(String name) {
        this.name = name;
    }

    // getter方法：获取age
    public int getAge() {
        return age;
    }

    // setter方法：设置age，添加逻辑判断
    public void setAge(int age) {
        if (age >= 0 && age <= 150) {
            this.age = age;
        } else {
            System.out.println("年龄不合法！");
        }
    }
}

public class Test09 {
    public static void main(String[] args) {
        Person p = new Person();

        // 通过setter方法设置属性
        p.setName("张三");
        p.setAge(20);

        // 通过getter方法获取属性
        System.out.println(p.getName() + "的年龄:" + p.getAge());  // 输出：张三的年龄:20
    }
}
```

**关键字 `this` 的作用**：
- `this` 代表当前对象的引用
- `this.name` 表示对象的成员变量name
- `this.name = name` 将方法参数name赋值给成员变量name

#### 2.4.4 封装的好处

1. **安全性**：防止外部直接修改对象状态
2. **可控性**：可以在setter中添加验证逻辑
3. **灵活性**：可以修改内部实现而不影响外部调用
4. **代码复用**：getter和setter可以被多个地方调用

### 2.5 构造方法

#### 2.5.1 什么是构造方法？

构造方法是创建对象时自动调用的方法，专门用于初始化对象的属性。

**构造方法的特征**：
1. 方法名与类名完全一致
2. 没有返回值类型（连void都不能写）
3. 一个类默认自带无参构造方法
4. 自定义有参构造方法后，默认无参构造方法会消失

#### 2.5.2 无参构造方法

```java
public class Car {
    private String brand;
    private String color;

    // 无参构造方法
    public Car() {
        System.out.println("无参构造.......");
    }

    // getter和setter方法
    public String getBrand() {
        return brand;
    }

    public void setBrand(String brand) {
        this.brand = brand;
    }

    public String getColor() {
        return color;
    }

    public void setColor(String color) {
        this.color = color;
    }

    public void show() {
        System.out.println("品牌是：" + brand + ",颜色是：" + color);
    }
}
```

#### 2.5.3 有参构造方法

```java
public class Car {
    private String brand;
    private String color;

    // 无参构造方法
    public Car() {
        System.out.println("无参构造.......");
    }

    // 有参构造方法：创建对象时直接初始化属性
    public Car(String brand, String color) {
        this.brand = brand;
        this.color = color;
        System.out.println("有参构造.......");
    }

    public void show() {
        System.out.println("品牌是：" + brand + ",颜色是：" + color);
    }
}
```

#### 2.5.4 使用构造方法创建对象

```java
public class Test01 {
    public static void main(String[] args) {
        // 使用无参构造创建对象，属性使用默认值
        Car car1 = new Car();
        car1.show();  // 输出：品牌是：null,颜色是：null

        // 使用有参构造创建对象，直接初始化属性
        Car car2 = new Car("奔驰", "红色");
        car2.show();  // 输出：品牌是：奔驰,颜色是：红色
    }
}
```

#### 2.5.5 构造方法重载

一个类可以有多个构造方法，它们的参数列表不同（参数个数、类型或顺序不同），这称为构造方法重载。

```java
public class User {
    private String name;

    // 无参构造
    public User() {
        this("默认用户");  // 调用有参构造
    }

    // 有参构造
    public User(String name) {
        this.name = name;
    }

    public void showName() {
        System.out.println("用户名是：" + this.name);
    }
}
```

**注意**：`this()` 必须是构造方法的第一条语句。

## 课程总结

### 重点知识回顾

1. **ArrayList删除元素**：从后往前遍历，避免元素遗漏
2. **LinkedList**：底层双向链表，增删快、查询慢
3. **HashSet**：无序、不可重复，基于哈希表实现
4. **HashMap**：双列集合，key唯一、value可重复
5. **类与对象**：类是模板，对象是实例
6. **封装**：private私有化属性，通过getter/setter访问
7. **构造方法**：初始化对象属性，方法名与类名一致

### 常见错误与注意事项

1. **ArrayList正向删除陷阱**：会导致元素遗漏
2. **空指针异常**：访问未赋值的引用类型会抛出NullPointerException
3. **忘记写break**：switch语句中会导致case穿透
4. **构造方法名错误**：必须与类名完全一致
5. **缺少无参构造**：自定义有参构造后，默认无参构造会消失

### 学习建议

1. 理解面向对象的核心思想：封装、继承、多态
2. 多练习类的定义和对象的创建
3. 掌握封装的实现方式和好处
4. 理解构造方法的作用和重载规则
