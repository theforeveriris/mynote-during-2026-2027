## 1. 数据类型与运算符

### 1.1 Java数据类型概述

Java是一种**强类型语言**，所有变量在使用前必须声明其数据类型。Java提供了8种基础数据类型：

| 类型分类 | 数据类型 | 字节数 | 取值范围 | 默认值 |
|---------|---------|-------|---------|--------|
| 整数型 | byte | 1 | -128 ~ 127 | 0 |
| | short | 2 | -32768 ~ 32767 | 0 |
| | int | 4 | -2^31 ~ 2^31-1 | 0 |
| | long | 8 | -2^63 ~ 2^63-1 | 0L |
| 浮点型 | float | 4 | ±3.4×10^38 | 0.0f |
| | double | 8 | ±1.7×10^308 | 0.0 |
| 字符型 | char | 2 | '\u0000' ~ '\uffff' | '\u0000' |
| 布尔型 | boolean | 1 | true / false | false |

### 1.2 变量声明与赋值

```java
public class Test1 {
    public static void main(String[] args){
        // 变量声明格式：数据类型 变量名 = 变量值;
        int id = 1001;           // 整数类型
        String name = "jack";    // 字符串类型（引用类型）
        double score = 95.5;     // 双精度浮点类型
        boolean isOk = true;     // 布尔类型
        
        // 赋值运算符 =
        int i = 10;
        double pi = 3.14;
    }
}
```

**关键点说明**：
- 变量声明时必须指定数据类型
- 变量名应遵循驼峰命名法（首字母小写，后续单词首字母大写）
- `String` 是引用类型，不是基本数据类型

### 1.3 算术运算符

```java
public class Test1 {
    public static void main(String[] args){
        int a = 10;
        int b = 3;
        
        // 基本算术运算
        System.out.println(a + " + " + b + "=" + (a+b));  // 加法：13
        System.out.println(a + " - " + b + "=" + (a-b));  // 减法：7
        System.out.println(a + " * " + b + "=" + (a*b));  // 乘法：30
        System.out.println(a + " / " + b + "=" + (a/b));  // 除法：3（整数除法取整）
        System.out.println(a + " % " + b + "=" + (a%b));  // 取模（求余）：1
    }
}
```

**注意事项**：
- 整数除法 `/` 会舍去小数部分，只保留整数
- 取模运算 `%` 的结果符号与被除数一致
- 当需要精确小数计算时，应使用 `double` 类型

### 1.4 自增自减运算符

```java
public class Test1 {
    public static void main(String[] args){
        int a = 10;
        
        a++;  // 后置自增：a = a + 1，先用后加
        System.out.println("a=" + a);  // 输出：11
        
        int c = a++;  // 后置自增参与运算：先赋值给c，再自增
        System.out.println("c=" + c);  // 输出：11（c获得的是自增前的值）
        System.out.println("a=" + a);  // 输出：12（a已经自增）
        
        int d = ++a;  // 前置自增参与运算：先自增，再赋值给d
        System.out.println("d=" + d);  // 输出：13（d获得的是自增后的值）
        System.out.println("a=" + a);  // 输出：13
    }
}
```

**核心区别**：
- **后置自增/自减**（`a++`、`a--`）：先使用变量原值，再进行自增/自减操作
- **前置自增/自减**（`++a`、`--a`）：先进行自增/自减操作，再使用变量新值

### 1.5 比较运算符

```java
public class Test1 {
    public static void main(String[] args){
        int num1 = 20;
        int num2 = 10;
        
        boolean result1 = num1 > num2;   // 大于：true
        boolean result2 = num1 < num2;   // 小于：false
        
        // 其他比较运算符：>=（大于等于）、<=（小于等于）、==（等于）、!=（不等于）
    }
}
```

**重要提示**：
- 比较运算符的结果是 `boolean` 类型（`true` 或 `false`）
- 比较两个引用类型是否相等时应使用 `equals()` 方法，而非 `==`

### 1.6 逻辑运算符

```java
public class Test1 {
    public static void main(String[] args){
        int num1 = 20;
        int num2 = 10;
        
        // && 逻辑与：所有条件都为true时结果才为true
        boolean result3 = (num1 > 5) && (num2 < 15);  // true && true = true
        
        // || 逻辑或：至少有一个条件为true时结果为true
        boolean result4 = (num1 > 5) || (num2 < 15);  // true || true = true
        
        // ! 逻辑非：取反
        boolean result5 = !(num1 > 5);  // !true = false
    }
}
```

**短路求值特性**：
- `&&`：第一个条件为false时，第二个条件不会执行
- `||`：第一个条件为true时，第二个条件不会执行

## 2. 分支结构

### 2.1 分支结构概述

分支结构用于根据不同条件执行不同的代码块。Java提供以下分支语句：

| 语句类型 | 适用场景 | 特点 |
|---------|---------|------|
| if | 单一条件判断 | 最基础的分支结构 |
| if-else | 二选一 | 条件满足执行一个分支，否则执行另一个 |
| if-else if | 多选一 | 多个条件依次判断 |
| switch | 固定等值匹配 | 适合状态码、月份等固定值匹配 |

### 2.2 if语句（单分支）

```java
public class Test2 {
    public static void main(String[] args) {
        // 单分支：只判断一个条件
        int score = 70;
        if (score >= 60) {
            System.out.println("及格");  // 条件满足时执行
        }
        // 条件不满足时跳过，继续执行后续代码
    }
}
```

### 2.3 if-else语句（双分支）

```java
public class Test2 {
    public static void main(String[] args) {
        // 双分支：二选一
        int age = 17;
        if (age >= 18) {
            System.out.println("成年");
        } else {
            System.out.println("未成年");  // 输出：未成年
        }
    }
}
```

### 2.4 if-else if语句（多分支）

```java
public class Test2 {
    public static void main(String[] args) {
        // 多分支：多选一，条件按顺序判断
        int score2 = 85;
        if (score2 >= 90) {
            System.out.println("优秀");
        } else if (score2 >= 80) {
            System.out.println("良好");
        } else if (score2 >= 70) {
            System.out.println("中等");   // 输出：中等
        } else if (score2 >= 60) {
            System.out.println("及格");
        } else {
            System.out.println("不及格");
        }
    }
}
```

**注意事项**：
- 条件按从上到下的顺序判断，一旦某个条件满足，后续条件不再判断
- 必须确保逻辑覆盖所有可能的情况（通常用else作为兜底）

### 2.5 switch语句

```java
public class Test2 {
    public static void main(String[] args) {
        // switch：固定等值匹配，适合状态码等场景
        int status = 2;
        switch (status) {
            case 1:
                System.out.println("待支付");
                break;  // 跳出switch
            case 2:
                System.out.println("已支付");  // 输出：已支付
                break;
            case 3:
                System.out.println("已发货");
                break;
            default:
                System.out.println("无效状态");
                break;
        }
    }
}
```

**关键点**：
- `break` 语句用于跳出switch，避免"穿透"到下一个case
- `default` 用于处理所有case都不匹配的情况
- Java 7及以上支持String类型的switch

## 3. 循环结构

### 3.1 循环结构概述

循环结构用于重复执行一段代码，直到满足终止条件。Java提供三种循环语句：

| 循环类型 | 适用场景 | 特点 |
|---------|---------|------|
| for | 已知循环次数 | 初始化、条件、更新在同一行，结构清晰 |
| while | 未知循环次数 | 先判断条件再执行，可能一次都不执行 |
| do-while | 至少执行一次 | 先执行再判断条件，至少执行一次 |

### 3.2 for循环

```java
public class Test3 {
    public static void main(String[] args) {
        // for循环：适合已知循环次数的场景
        // 格式：for(初始化表达式; 条件表达式; 更新表达式)
        for (int i = 1; i <= 5; i++) {
            System.out.println("第" + i + "条数据");  // 输出第1~5条数据
        }
    }
}
```

**执行流程**：
1. 初始化表达式 `int i = 1`（只执行一次）
2. 判断条件 `i <= 5`
3. 条件满足时执行循环体
4. 执行更新表达式 `i++`
5. 回到步骤2，直到条件不满足

### 3.3 while循环

```java
public class Test3 {
    public static void main(String[] args) {
        // while循环：适合未知循环次数的场景
        int count = 1;
        while (count <= 3) {
            System.out.println("读取第" + count + "行");  // 输出第1~3行
            count++;  // 必须手动更新计数，避免无限循环
        }
    }
}
```

**注意**：必须在循环体内更新条件变量，否则会导致无限循环。

### 3.4 break语句：跳出循环

```java
public class Test3 {
    public static void main(String[] args) {
        // break：终止整个本层循环
        int j = 1;
        for (; j <= 10; j++) {
            if (j == 5) {
                System.out.println("终止整个本层循环");
                break;  // 跳出循环，后续循环不再执行
            }
            System.out.println("j=" + j);  // 输出：1 2 3 4
        }
    }
}
```

### 3.5 continue语句：跳过本次循环

```java
public class Test3 {
    public static void main(String[] args) {
        // continue：跳过本次循环，继续下一次循环
        int k = 1;
        for (; k <= 10; k++) {
            if (k == 5) {
                System.out.println("终止本层循环的本次循环，后续循环继续");
                continue;  // 跳过本次循环体剩余部分
            }
            System.out.println("k=" + k);  // 输出：1 2 3 4 6 7 8 9 10（跳过5）
        }
    }
}
```

**break与continue的区别**：
- `break`：终止整个循环，循环不再继续
- `continue`：跳过当前迭代，继续下一次迭代

## 4. 综合练习

### 4.1 练习1：素数判断

**需求**：输入一个整数n（1-100），遍历n以内的奇数，判断每个奇数是否为素数，并分别打印奇数素数和奇数非素数。

```java
import java.util.Scanner;
public class Test4 {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.println("请输入一个整数：");
        int n = scanner.nextInt();

        for (int i = 1; i <= n; i++) {
            // 跳过所有偶数
            if (i % 2 == 0) {
                continue;
            }
            
            // 1不是素数，直接跳过
            if (i == 1) {
                System.out.println(i + "是奇数，不是素数");
                continue;
            }

            // 判断素数：默认是素数
            boolean isPrime = true;
            for (int j = 2; j < i; j++) {
                if (i % j == 0) {
                    isPrime = false;  // 能被整除，不是素数
                    break;  // 提前退出循环
                }
            }

            if (isPrime) {
                System.out.println(i + "是奇数，也是素数");
            } else {
                System.out.println(i + "是奇数，但不是素数");
            }
        }
    }
}
```

**输入输出示例**：
```
输入：5
输出：
1是奇数，不是素数
3是奇数，也是素数
5是奇数，也是素数
```

### 4.2 练习2：银行密码校验

**需求**：设定正确密码为123456，用户最多输入3次。输入错误提示剩余次数，输入正确提示登录成功，3次错误锁定账户。

```java
import java.util.Scanner;

public class PasswordCheck {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int password = 123456;

        for (int i = 1; i <= 3; i++) {
            System.out.println("请输入密码：");
            int pwd = scanner.nextInt();
            
            if (password != pwd) {
                int left = 3 - i;  // 计算剩余次数
                if (left == 0) {
                    System.out.println("密码错误3次，账户锁定");
                } else {
                    System.out.println("密码错误，还剩" + left + "次机会");
                }
                continue;  // 继续下一次循环
            }
            
            System.out.println("密码正确，欢迎进入系统");
            break;  // 正确后退出循环
        }
    }
}
```

**输入输出示例**：
```
输入：111111 → 输出：密码错误，还剩2次机会
输入：222222 → 输出：密码错误，还剩1次机会
输入：333333 → 输出：密码错误3次，账户锁定
```

### 4.3 练习3：判断当月天数

**需求**：输入年份和月份，判断当月天数。注意闰年的判断规则。

```java
import java.util.Scanner;

public class Calendar {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        while (true) {
            System.out.println("输入年份(当输入0退出)：");
            int year = scanner.nextInt();
            
            if (year == 0) {
                System.out.println("退出程序");
                break;  // 退出循环
            }

            System.out.println("请输入月份:");
            int month = scanner.nextInt();
            int day = 0;
            
            switch (month) {
                // 31天的月份
                case 1:
                case 3:
                case 5:
                case 7:
                case 8:
                case 10:
                case 12:
                    day = 31;
                    break;
                // 30天的月份
                case 4:
                case 6:
                case 9:
                case 11:
                    day = 30;
                    break;
                // 2月需要判断闰年
                case 2:
                    // 闰年判断规则：能被4整除但不能被100整除，或者能被400整除
                    if (year % 4 == 0 && year % 100 != 0 || year % 400 == 0) {
                        day = 29;  // 闰年2月29天
                    } else {
                        day = 28;  // 平年2月28天
                    }
                    break;
            }
            
            System.out.println(year + "年" + month + "月有" + day + "天");
        }
    }
}
```

**闰年判断规则**：
1. 能被4整除但不能被100整除
2. 或者能被400整除

## 5. 数组

### 5.1 数组概述

数组是存储**相同数据类型**元素的容器，具有以下特点：
- **长度固定**：创建后不能改变长度
- **存储有序**：元素按顺序存储，通过下标访问
- **下标从0开始**：第一个元素下标为0，最后一个元素下标为`length - 1`
- **查询速度快**：通过下标直接访问，时间复杂度O(1)
- **增删效率低**：需要手动移动元素

### 5.2 数组的声明与初始化

```java
public class Test7 {
    public static void main(String[] args) {
        // 方式1：先声明，后分配内存
        int[] arr1;
        arr1 = new int[3];  // 分配3个int类型的空间
        
        // 方式2：声明时分配内存
        double[] arr2 = new double[2];
        
        // 方式3：声明时直接赋值（静态初始化）
        String[] arr3 = {"张三", "李四", "王五"};
        
        // 给数组元素赋值
        arr1[0] = 10;
        arr1[1] = 20;
        arr1[2] = 30;
        
        arr2[0] = 1.1;
        arr2[1] = 2.2;
    }
}
```

### 5.3 数组的遍历

```java
public class Test7 {
    public static void main(String[] args) {
        int[] arr1 = {10, 20, 30};
        double[] arr2 = {1.1, 2.2};
        
        // 获取数组长度
        System.out.println("arr1的长度是：" + arr1.length);  // 输出：3
        
        // 方式1：普通for循环，通过下标遍历

            System.out.println("arr1[" + i + "] = " + arr1[i]);
        }
        
        // 方式2：增强for循环（foreach），直接获取元素值
        for (double element : arr2) {
            System.out.println("元素 = " + element);
        }
    }
}
```

### 5.4 练习：数组求和与最大值

```java
public class Test8 {
    public static void main(String[] args) {
        int[] arr = {12, 45, 7, 89, 23};
        int sum = 0;
        int max = arr[0];  // 假设第一个元素是最大值

        for (int i = 0; i < arr.length; i++) {
            sum += arr[i];  // 累加求和
            
            if (arr[i] > max) {
                max = arr[i];  // 更新最大值
            }
        }

        System.out.println("数组总和:" + sum);         // 输出：176
        System.out.println("数组的最大值:" + max);     // 输出：89
    }
}
```

## 6. 集合

### 6.1 集合概述

集合是Java提供的**长度可变**的容器，相比数组具有以下优势：
- 长度可动态调整（自动扩容）
- 提供丰富的增删改查方法
- 只能存储引用类型（基本类型自动装箱）

Java集合分为两大体系：

| 体系 | 特点 | 主要实现类 |
|------|------|-----------|
| Collection（单列集合） | 一次存储一个元素 | List、Set |
| Map（双列集合） | 一次存储一对键值对（key-value） | HashMap、TreeMap |

### 6.2 List集合

List集合的特点：**有序、可重复、有索引**。

#### 6.2.1 ArrayList

`ArrayList` 是List的主要实现类，底层基于数组实现，查询速度快。

```java
import java.util.ArrayList;

public class Test10 {
    public static void main(String[] args) {
        // 创建ArrayList，存储String类型
        ArrayList<String> list = new ArrayList<>();

        // 添加元素
        list.add("张三");
        list.add("王五");
        list.add("王五");  // 允许重复
        list.add("赵六");
        list.add("孙七");

        // 获取集合大小
        System.out.println("集合的长度:" + list.size());  // 输出：5

        // 获取指定索引的元素
        System.out.println("获取索引为2的元素:" + list.get(2));  // 输出：王五

        // 修改指定索引的元素
        list.set(1, "李四四");

        // 删除指定索引的元素
        list.remove(3);

        // 遍历方式1：普通for循环
        for (int i = 0; i < list.size(); i++) {
            System.out.println("list[" + i + "] = " + list.get(i));
        }

        // 遍历方式2：增强for循环
        for (String element : list) {
            System.out.println("element = " + element);
        }
    }
}
```

**输出结果**：
```
集合的长度:5
```

## 课程总结

### 重点知识回顾

1. **数据类型**：Java是强类型语言，8种基础数据类型（byte、short、int、long、float、double、char、boolean）
2. **运算符**：算术运算符、比较运算符、逻辑运算符、自增自减运算符
3. **分支结构**：if、if-else、if-else if、switch语句的使用场景
4. **循环结构**：for、while循环，以及break和continue的区别
5. **数组**：长度固定、下标从0开始、查询快但增删慢
6. **集合**：长度可变、提供丰富操作方法、分为Collection和Map两大体系

### 常见错误与注意事项

1. **整数除法陷阱**：`5 / 2` 结果是2而非2.5，需要使用浮点类型
2. **数组下标越界**：访问 `arr[arr.length]` 会抛出 `ArrayIndexOutOfBoundsException`
3. **无限循环**：while循环中忘记更新条件变量会导致无限循环
4. **switch穿透**：case分支中忘记写break会导致执行后续case
5. **ArrayList删除元素**：正向遍历删除会导致元素遗漏，应从后往前遍历

### 学习建议

1. 多做练习题，加深对语法的理解
2. 注意代码规范，养成良好的编程习惯
3. 理解每个知识点的应用场景，而不仅仅是记住语法
4. 尝试将所学知识应用到实际项目中
