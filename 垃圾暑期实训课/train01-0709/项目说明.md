# 校园电竞社团管理系统

## 项目简介

本系统是一个基于 Java 的命令行应用程序，用于管理校园电竞社团的 LOL 和王者荣耀两类游戏赛事。系统实现了选手管理、战队管理、赛事创建、积分统计和选手黑名单管控等基础功能。

## 技术栈

- **语言**: Java 8+
- **运行方式**: 命令行控制台程序
- **数据存储**: 内存存储（ArrayList、HashMap、HashSet）

## 文件结构

```
train01-0709/
├── Operate.java          # 管理员操作接口
├── AbstractPlayer.java   # 选手抽象父类
```

## 类结构设计

### 1. 接口与抽象类

| 类/接口 | 类型 | 说明 |
|---------|------|------|
| Operate | 接口 | 定义管理员标准业务行为：创建对局、统计积分、拉黑选手 |
| AbstractPlayer | 抽象类 | 统一抽取编号、姓名、年龄、黑名单状态，定义抽象方法 showInfo() |

### 2. 子类

| 类 | 继承/实现 | 独有属性 | 功能 |
|----|-----------|----------|------|
| Gamer | 继承 AbstractPlayer | 擅长游戏、所属战队ID | 查看信息、加入/退出战队、查询参赛记录 |
| MatchAdmin | 继承 AbstractPlayer + 实现 Operate | 无 | 创建对局、统计积分、查询全部记录、拉黑选手 |

### 3. 实体类

| 类 | 属性 | 规则 |
|----|------|------|
| Team | 编号、名称、游戏、积分、队员集合 | 单队最多5人 |
| MatchRecord | 编号、对战双方、双方积分、比赛结果 | 胜利+3分，平局各+1分 |

## 功能模块

### 选手功能

1. **查看个人信息**：显示基础身份信息 + 擅长游戏 + 所属战队
2. **加入战队**：三层校验（黑名单拦截、已有战队拦截、战队满员拦截）
3. **退出战队**：清空自身战队标识
4. **查询个人参赛记录**：筛选本人所属战队参与的全部比赛

### 管理员功能

1. **创建比赛对局**：输入两支战队ID和比赛结果，自动更新积分并生成记录
2. **按游戏分类统计积分**：遍历输出每款游戏下所有战队及总积分
3. **查询系统全部对局记录**：展示所有比赛记录
4. **拉黑/解除拉黑选手**：修改选手黑名单状态

## 数据容器

| 容器 | 类型 | 用途 |
|------|------|------|
| teams | ArrayList | 存储全部战队 |
| players | ArrayList | 存储全部玩家（选手+管理员） |
| matchRecords | HashMap | 存储所有对局记录（key为对局编号） |

## 积分规则

- **胜利战队**：+3 积分
- **平局**：两队各 +1 积分
- **失败战队**：无积分

## 战队人数限制

单支战队最多容纳5名选手，满员后无法新增选手。

## 黑名单规则

- 被拉黑的选手无法加入战队
- 被拉黑的选手无法参与赛事
- 管理员可随时解除拉黑状态
